對數函數及其圖形

學校博物館社去參觀一個考古展，解說牌寫著：「這塊木炭的碳-14 只剩原本的 30%，推估距今約一萬年。」筱葳好奇這個數字怎麼算出來的。這一節把 log 畫成函數圖形，看它和指數函數的鏡像關係，用單調性比較大小與解不等式，最後整理出處理「按比例成長」問題的通用模型。情境例子為原創設計。

指數函數輸入「次數」、輸出「倍數」；對數函數剛好反過來，輸入「倍數」、輸出「次數」。兩者是同一個關係的正反兩面，所以圖形也是彼此的鏡像。對數函數長得很慢——x 從 1 變成 1000，log x 只從 0 變成 3——這正是它適合用來描述地震規模、音量分貝、酸鹼值的原因。

與指數函數互為反函數

把 x 和 y 對調，就是沿著 y = x 翻過去

觀察 → 規律

點 (2, 4) 在 y = 2ˣ 上，因為 2² = 4；點 (4, 2) 在 y = log₂x 上，因為 log₂4 = 2。每一點都是坐標對調：

(a, b) 在 y = 2ˣ 上 ⟺ b = 2ᵃ ⟺ a = log₂b ⟺ (b, a) 在 y = log₂x 上

點 (a, b) 與 (b, a) 對稱於直線 y = x，所以兩條圖形也對稱於 y = x。像這樣「把輸入、輸出對調」得到的兩個函數，稱為互為反函數。

比較大小與不等式

同底比真數，不同底找一個中間值

規律
單調性的應用（M、N > 0）
a > 1：logₐM > logₐN ⟺ M > N
0 < a < 1：logₐM > logₐN ⟺ M < N（不等號反向）
用一用：不同底數比較

比較 log₂3、log₃5、3／2 的大小。

底數不同，不能直接比。技巧是把 3／2 也寫成同底的對數，再兩兩比較：

3／2 = log₂(2^(3／2)) = log₂√8，而 3 = √9 > √8 ⟹ log₂3 > 3／2 3／2 = log₃(3^(3／2)) = log₃√27，而 5 = √25 < √27 ⟹ log₃5 < 3／2 ∴ log₃5 < 3／2 < log₂3
用一用：對數不等式

解 log1/2(x − 1) > −2。

真數限制：x − 1 > 0 ⟹ x > 1 −2 = log1/2((1／2)^(−2)) = log1/24 log1/2(x − 1) > log1/24，底數小於 1 不等號反向：x − 1 < 4 ⟹ x < 5 和真數限制取交集：1 < x < 5

兩個步驟缺一不可：先寫真數大於 0，再看底數決定不等號方向，最後取交集。

按比例成長模型

知道「多久變幾倍」，就能算任何時刻

規律 → 公式

「每經過固定時間 T，數量就變成 r 倍」的現象，都可以用同一個式子描述：

按比例成長（衰減）模型
y(t) = y₀・r^(t／T)
y₀：初始量　r：每經過 T 時間的倍數（r > 1 成長，0 < r < 1 衰減）
求時間：t = T・logr(y／y₀) = T・log(y／y₀) ／ log r

2-1 的咖啡因是 r = 1／2、T = 5 小時；2-2 的追蹤人數是 r = 1.5、T = 1 個月。問「多少」用指數算，問「多久」就用對數算。

情境：碳-14 定年

生物死亡後，體內碳-14 每 5730 年減半。展場的木炭碳-14 剩下原本的 30%，這塊木炭大約是多久以前的？（log 2 ≈ 0.3010，log 3 ≈ 0.4771）

y／y₀ = (1／2)^(t／5730) = 0.3 t = 5730 × log 0.3 ／ log(1／2) log 0.3 = log 3 − 1 ≈ −0.5229 log(1／2) = −log 2 ≈ −0.3010 t ≈ 5730 × 0.5229 ／ 0.3010 ≈ 5730 × 1.737 ≈ 9950（年）

所以解說牌說「約一萬年」是對的。若剩 25%，則剛好是兩個半衰期 11460 年；30% 比 25% 多一點，時間就短一點，合理。

情境：翻倍要幾年？

某城市人口每年成長 7%。人口大約幾年會翻倍？（log 1.07 ≈ 0.0294）

1.07ⁿ = 2 ⟹ n = log 2 ／ log 1.07 ≈ 0.3010 ／ 0.0294 ≈ 10.2（年）

金融業常用的「72 法則」：年成長率 r%，翻倍時間約 72 ÷ r 年（7% 時約 10.3 年）。它就是 n = log 2 ／ log(1 + r%) 的近似值。

收進工具箱：2-3 對數函數及其圖形

對數函數是指數函數的鏡像；在應用題裡，指數回答「變成多少」，對數回答「要多久」。

名稱內容

練習題

1圖形

函數 y = log₂(x − 3) + 1 的定義域、漸近線、與 x 軸的交點各是什麼？

參考答案
定義域：x − 3 > 0 ⟹ x > 3 漸近線：x = 3（y = log₂x 往右移 3、往上移 1） y = 0：log₂(x − 3) = −1 ⟹ x − 3 = 1／2 ⟹ 交點 (7／2, 0)
2比較大小

比較 a = log₃2、b = log₂3、c = log₄9 的大小。

參考答案
c = log₄9 = log2²3² = log₂3 = b a = log₃2 < log₃3 = 1，b = log₂3 > log₂2 = 1 ∴ a < b = c
3不等式

解 log₂(x + 2) ≤ 3。

參考答案
真數：x + 2 > 0 ⟹ x > −2 底數 2 > 1：x + 2 ≤ 2³ = 8 ⟹ x ≤ 6 取交集：−2 < x ≤ 6
4成長模型

某培養液中的酵母菌每 3 小時變成 2 倍。從 500 個開始，大約幾小時後會超過 6000 個？（log 2 ≈ 0.3010，log 3 ≈ 0.4771）

參考答案
500 × 2^(t／3) > 6000 ⟹ 2^(t／3) > 12 t／3 > log 12 ／ log 2 = (2 log 2 + log 3) ／ log 2 ≈ 1.0791 ／ 0.3010 ≈ 3.585 t > 10.76，大約 10.8 小時後
5成長模型

一台新機車價值 9 萬元，每年價值變成前一年的 80%。幾年後價值會首次低於 3 萬元？（log 2 ≈ 0.3010，log 3 ≈ 0.4771）

參考答案
9 × 0.8ⁿ < 3 ⟹ 0.8ⁿ < 1／3 兩邊取 log（log 0.8 < 0，除過去不等號反向）： n > log(1／3) ／ log 0.8 = (−log 3) ／ (3 log 2 − 1) ≈ (−0.4771) ／ (−0.0970) ≈ 4.92 ∴ 第 5 年後首次低於 3 萬元
