直線方程式及其圖形

從無障礙坡道的法規坡度出發，推出斜率、直線方程式、直線的平移，以及兩條直線之間的關係。情境例子是重新設計的原創內容。

這一節把「兩點之間的陡緩程度」抽象成一個數字——斜率，再用它寫出整條直線的方程式，最後討論直線的平移，以及兩條直線之間平行、垂直的關係。

直線的斜率

坡道多陡才合格？

情境

建築法規規定，公共場所的無障礙坡道，坡度不能超過 1/12（也就是每垂直上升 1 公分，水平長度至少要有 12 公分）。工地師傅蓋了一段坡道，起點在地面 (0,0)，終點在 (300,20)（單位：公分）。這段坡道合格嗎？

觀察

要判斷「陡不陡」，關鍵是「垂直上升量」跟「水平前進量」的比值。從 (0,0) 走到 (300,20)：

垂直上升量 Δy = 20 − 0 = 20 水平前進量 Δx = 300 − 0 = 300 坡度 = Δy／Δx = 20／300 = 1／15

因為 1/15 < 1/12（分母越大，坡度越平緩），這段坡道比法規要求更平緩，合格。

規律 → 公式：斜率

把「坡度」這個概念一般化，用坐標平面上任意兩點 A(x₁,y₁)、B(x₂,y₂)（x₁≠x₂）定義斜率：

m = (y₂−y₁) ／ (x₂−x₁)

斜率的正負與大小，直接對應圖形的陡緩與方向：

斜率 m圖形意義
m > 0由左往右上升（越大越陡）
m < 0由左往右下降（絕對值越大越陡）
m = 0水平線
不存在鉛直線（x₁=x₂，垂直地面）

法規講的「1/12」其實就是斜率的絕對值上限：|m|≤1/12。師傅蓋的坡道斜率 m=1/15≈0.067，比上限 1/12≈0.083 小，所以合格；斜率的分母越大（同樣上升高度，水平距離越長），坡道越平緩越安全。

用一用

另一段坡道從 (0,0) 到 (150,15)，合格嗎？

m = (15−0)／(150−0) = 15／150 = 1／10

1/10 > 1/12（分母較小，坡度較陡），超過法規上限，不合格，必須把坡道加長或降低高度。

直線方程式

怎麼寫出整條坡道的路徑？

情境

工地師傅想在圖面上，用一個方程式表示「恰好等於法規上限坡度」的坡道路徑，這樣只要代入任何一個水平位置 x，就能立刻查出這個位置的坡道高度該蓋多高，不用每次都重新畫圖。

觀察

已知坡道起點 (0,0)，斜率 m=1/12。坐標平面上任何一點 (x,y)，只要跟起點連線的斜率也是 1/12，就會落在同一條坡道上：

(y−0)／(x−0) = 1／12　　⟹　　y = x／12

更一般地，如果直線通過已知點 (x₁,y₁)、斜率為 m，同樣的推理給出：

規律 → 公式
點斜式（已知一點與斜率）
y − y₁ = m(x − x₁)

把點斜式展開整理，可以化成幾種常見形式：

斜截式（已知斜率 m 與 y 截距 b）
y = mx + b
一般式（a, b 不同時為 0）
ax + by + c = 0
截距式（已知 x 截距 a、y 截距 b，且 a≠0, b≠0）
x／a + y／b = 1

鉛直線（斜率不存在）沒辦法寫成斜截式或截距式（若鉛直線不過原點，它沒有 y 截距），但可以寫成一般式，例如 x=5 就是 1·x+0·y−5=0；這也是一般式比其他形式更「萬用」的原因。

用一用

另一段坡道通過點 (50,10)，斜率為 1/10，求它的方程式，並化成一般式；如果這條坡道的 x 截距是 −50、y 截距是 5，寫出它的截距式。

點斜式：y−10 = (1/10)(x−50) 展開：y−10 = x/10 − 5 斜截式：y = x/10 + 5 一般式：x − 10y + 50 = 0 截距式（x截距−50，y截距5）：x／(−50) + y／5 = 1
直線的平移

扶手要架在坡道正上方，方程式怎麼變？

情境

設計單位想在原本的坡道（y=x/12）正上方 1 公尺處，加裝一條同坡度的扶手；另外，整條坡道又計畫整體往右平移 2 公尺（起點從 (0,0) 移到 (2,0)）。扶手跟新坡道的方程式該怎麼寫？

觀察

把一條直線「垂直移動」，代表每個點的 y 坐標都加上同一個數；把它「水平移動」，代表每個點的 x 坐標都加上同一個數。扶手比坡道整體高 1，所以扶手上每一點的 y 都是坡道對應點的 y 再加 1：

坡道：y = x/12 扶手（往上移 1）：y = x/12 + 1

新坡道則是整條線往右移 2，也就是「原本 x 位置」現在要用「新 x 減 2」去代入：

新坡道：y = (x−2)／12　（起點：x=2 時 y=0，符合 (2,0)）
規律 → 公式

設 h,k>0，直線 y=mx+b：

平移方式新方程式
向上平移 ky = mx + b + k
向下平移 ky = mx + b − k
向右平移 hy = m(x − h) + b
向左平移 hy = m(x + h) + b

關鍵是：垂直平移直接對常數項加減；水平平移則是把方程式裡的 x 換成「x 減去（向右）」或「x 加上（向左）」平移量——很多人會弄反方向，可以代一個具體點驗證，例如新坡道令 x=2 應該要得到起點的 y=0。平移不會改變斜率，兩條直線仍然互相平行。

兩直線的關係

新路要跟主幹道平行，還是垂直？

情境

都市計畫中，主幹道的方程式是 y=2x+3。現在要規劃一條新的巷道，通過點 (4,1)，並且要跟主幹道垂直（方便設計十字路口）。新巷道的方程式該怎麼寫？

觀察

兩條直線的「平行」與「垂直」，本質上都是斜率之間的關係。想像把主幹道的方向繞原點旋轉 90°：斜率會從 m 變成 −1/m（正負對調、倒數）。可以驗證：主幹道斜率 2，垂直方向的斜率是 −1/2，兩者相乘 2×(−1/2)=−1。

規律 → 公式
兩線平行、垂直的判定（斜率 m₁、m₂ 皆存在時）
平行：m₁ = m₂　　　　垂直：m₁ · m₂ = −1

用這個規律解決一開始的問題：主幹道斜率 m₁=2，垂直的新巷道斜率 m₂=−1/2，再用點斜式代入通過的點 (4,1)：

y − 1 = −(1/2)(x − 4) y = −x/2 + 2 + 1 新巷道方程式：y = −x/2 + 3

如果兩條路的斜率都不存在（都是鉛直線），也視為互相平行；一條鉛直線與一條水平線則必定互相垂直，這兩種情況不能直接套用「m₁m₂=−1」，因為鉛直線沒有斜率。下一節會接著討論這兩條路實際交會在哪裡、以及跟這條主幹道相關的距離問題。

換你動手做

1情境

某段坡道從 (0,0) 到 (400,30)，是否符合「坡度不超過 1/12」的法規？

查看解答
m = 30/400 = 3/40 = 0.075 1/12 ≈ 0.083，0.075 < 0.083，合格
2代數

求通過 (2,−1)、斜率為 3 的直線方程式（化為一般式）。

查看解答
y−(−1) = 3(x−2) y+1 = 3x−6 一般式：3x−y−7 = 0
3代數

直線 y=3x 向下平移 2、再向左平移 1，求新方程式。

查看解答
向下移 2：y=3x−2 再向左移 1（x 換成 x+1）：y=3(x+1)−2=3x+1
4情境

主幹道方程式 y=−2x+5，另一條巷道要與它平行，且通過 (1,1)，求巷道方程式。

查看解答
平行，斜率相同：m=−2 y−1 = −2(x−1) y = −2x+3

給筱葳的話

這一節的核心心法是：先把「陡不陡」抽象成斜率這個數字，再用它寫出整條直線的方程式；平移、平行、垂直，都只是斜率跟截距的加減乘除運算。下一節（2-2）會接著討論兩條路實際交會在哪裡、離馬路多遠才安全，以及怎麼用不等式表示「哪一邊可以蓋房子」。
