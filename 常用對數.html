常用對數

依照筱葳課本章節重新編寫：從細菌繁殖「要幾小時才會超過一百萬隻」開始，反推出常用對數的定義，再學會用它估計超大數字的位數。

「指數」開頭那個每小時分裂成兩倍的細菌，其實還有一個問題沒問完：如果從 1 隻細菌開始，要經過幾個小時，數量才會超過一百萬隻？這種未知數卡在指數位置的方程式，正是這一節「對數」要解決的問題。

PART 1 ・ 常用對數

細菌要經過幾小時，才會超過一百萬隻？

情境

還記得那個每小時分裂成兩倍的細菌嗎？從 1 隻開始，經過 n 小時後，數量會變成 2ⁿ 隻。現在反過來問：數量要超過一百萬隻，至少要經過幾個小時？也就是要解方程式 2ⁿ=1000000——問題是，未知數 n 卡在指數的位置，目前學過的指數律完全幫不上忙。

要解開這種「未知數卡在指數位置」的方程式，需要指數的反向操作——這個反向操作，就是這一節要學的對數。

觀察

要解 2ⁿ=1000000，關鍵是先搞懂「10 的幾次方等於 2」——因為 10 是我們最熟悉的計數底數。每一個正數 a 都可以寫成 10ˣ 的形式（x 可以是小數），可以用逐步逼近的方式夾出這個 x：

10⁰ = 1　　　10¹ = 10　　（2 介於中間，x 介於 0、1 之間） 10⁰·³ ≈ 1.995262315　　（比 2 小一點，x 要再大一點） 10⁰·³⁰² ≈ 2.004472000　　（比 2 大一點，x 落在 0.3 與 0.302 之間） 10⁰·³⁰¹ ≈ 1.999861800　　（比 2 小一點，繼續夾……） 10⁰·³⁰¹¹ ≈ 2.000322200 10⁰·³⁰¹⁰³≈ 1.999999769　　（已經非常接近 2）

這樣不斷夾下去，可以找到一個唯一的 x≈0.30103……，滿足 10ˣ=2。

規律 → 定義

把「滿足 10ˣ=2 的這個 x」直接取名字，記作 log 2（讀作「log 2」）。一般化：

常用對數的定義
設 a 為正數，滿足 10ˣ=a 的實數 x，稱為 a 的常用對數，記作 x=log a，其中 a 稱為真數；也就是說 10^(log a) = a 恆成立。

换句话说，log a 就是在問：「10 要自乘幾次，才會等於 a？」而 log 和「10 的次方」互為反向操作：

73 = 10^(log 73)　　　　10^(log 5566) = 5566　　　　log(10ᵃ) = a（a 為任意實數）

實際計算 log 2 不需要真的一步步去夾，計算機上的 log 鍵可以直接算出更精確的值：log 2 ≈ 0.301029996，通常取 log2≈0.301 就夠用。

回到情境：細菌要幾小時才超過一百萬隻？

現在有了 log，就能解開一開始的方程式 2ⁿ=1000000。兩邊同取 log：

log(2ⁿ) = log(1000000) n·log2 = log(10⁶) = 6 n = 6/log2 ≈ 6/0.301 ≈ 19.93（小時）

大約 19.93 小時後，細菌數量恰好超過一百萬隻；如果只能整點時間培養，就要等滿 20 個小時。這就是「對數」的威力：能直接把卡在指數位置的未知數解出來，不用一個一個小時去試。

PART 2 ・ 對數的大小

log 每增加 1，代表變成 10 倍

觀察

把幾個 10 的整數次方排在一起看：

log 1 = 0 log 10 = 1 log 100 = 2 log 1000 = 3 log 10000 = 4

每次 a 變成 10 倍，log a 就剛好增加 1。這代表「log」把乘法的世界，壓縮成加法的世界——原本要乘 10 倍才能移動的距離，在 log 的世界裡只需要「加 1」。

用一用①：log 的差，對應倍數關係

已知 log a=2.7，log b=1.7，a 是 b 的幾倍？

a = 10^(log a) = 10^2.7　　　b = 10^(log b) = 10^1.7 a/b = 10^2.7 / 10^1.7 = 10^(2.7-1.7) = 10¹ = 10

a 是 b 的 10 倍——一般地，只要知道兩個數的 log 差是多少，不用真的算出兩個數，就能直接知道它們差幾倍：log 差 k，倍數就是 10ᵏ。

用一用②：估計位數（多位數）

已知 log a=2.342，a 大概長什麼樣子（幾位數）？

因為 2<2.342<3，而 log 是嚴格遞增的（a 越大 log a 也越大），所以：

log 100 < log a < log 1000 2 < 2.342 < 3 ⟹ 100 < a < 1000

a 介於 100 到 1000 之間，也就是一個 3 位數。一般化：

若正整數 N 滿足 n ≤ log N < n+1（n 為整數），則 N 是 (n+1) 位數。

同樣的想法也能用在小於 1 的小數上。已知 log a=-2.8：

log 0.001 < log a < log 0.01 -3 < -2.8 < -2 ⟹ 0.001 < a < 0.01

a 介於 0.001 到 0.01 之間，也就是小數點後第 2 位才第一次出現不是 0 的數字。

用一用③：兩個數相乘後的位數

a 是 5 位數，b 已知 log a=4.8、log b=2.5，ab 是幾位數？

log(ab) = log a + log b = 4.8 + 2.5 = 7.3 7 ≤ 7.3 < 8　⟹　ab 是 7+1 = 8 位數

這裡直接用到「log(ab)=log a+log b」這個關係（本質上就是指數律 10ᵐ·10ⁿ=10ᵐ⁺ⁿ 反過來看），不需要真的把 a、b 相乘出來，就能知道乘積大概有幾位數。

回到情境：細菌培養久一點，多的是幾倍？

同一種細菌（每小時倍增），甲培養皿已經培養了 30 小時，乙培養皿培養了 40 小時（起始隻數相同）。乙的細菌數量是甲的幾倍？

甲：數量 = 2³⁰，log(2³⁰) = 30×log2 ≈ 30×0.301 = 9.03 乙：數量 = 2⁴⁰，log(2⁴⁰) = 40×log2 ≈ 40×0.301 = 12.04 log(乙)−log(甲) = 12.04−9.03 = 3.01 ⟹ 乙/甲 = 10^3.01 ≈ 1023（倍）

只多培養 10 小時，數量卻多了一千多倍——這就是指數成長「差一點時間，差很多數量」的威力，而 log 讓我們不用真的算出 2³⁰、2⁴⁰ 這種天文數字，就能直接算出兩者的倍數關係。

延伸：其他也用對數尺度的例子

化學上的 pH 值定義為 pH = -log[H⁺]（[H⁺] 是氫離子濃度），所以 pH 每差 1，氫離子濃度就差 10 倍；地震規模、聲音的分貝（dB）也都是用類似的對數尺度定義。凡是「原始數字的範圍太懸殊」的現象，幾乎都會看到對數的身影。

收進工具箱：1-4 常用對數

上面每一條都已經自己推導過一次，收錄在這裡，需要時隨時查。

用途公式
定義10ˣ=a（a>0） ⟺ x=log a，且 10^(log a)=a
特殊值log 1=0，log 10=1，log(10ᵃ)=a
大小關係a 每變成 10 倍，log a 增加 1；log 遞增（a 越大 log a 越大）
位數估計（≥1 的數）n≤log N<n+1 ⟹ N 是 (n+1) 位數
小數估計（<1 的數）-n≤log a<-(n-1) ⟹ a 的小數點後第 n 位才第一次出現非 0 數字
乘積的位數log(ab) = log a + log b（本質是指數律的反向操作）

換你動手做

1代數

把 22、10^(log 0.123) 分別用另一種等價的方式寫出來。

查看解答
22 = 10^(log 22) 10^(log 0.123) = 0.123
2代數

求 log 1000，以及 log 0.01（提示：0.01=10⁻²）。

查看解答
log 1000 = log(10³) = 3 log 0.01 = log(10⁻²) = -2
3情境

已知 log a=4.3，log b=5.3，b 是 a 的幾倍？

查看解答
log b − log a = 5.3−4.3 = 1　⟹　b/a = 10¹ = 10
b 是 a 的 10 倍。
4代數

已知 log a=1.2，log b=1.9，求 a²b 是幾位數。

查看解答
log(a²b) = 2log a + log b = 2.4+1.9 = 4.3 4 ≤ 4.3 < 5　⟹　a²b 是 5 位數
5情境

續「指數」的鈷-60 問題：(1/2)^(n/5.2714)=0.12，已知 log2≈0.301，求 n（精確到小數點後一位）。

查看解答
兩邊取 log：(n/5.2714)×log(1/2) = log 0.12 log(1/2) = -log2 ≈ -0.301 log 0.12 = log(12/100) = log12-2 = (log4+log3)-2 ≈ (0.602+0.477)-2 = -0.921 (n/5.2714)×(-0.301) = -0.921 n/5.2714 ≈ 3.06 n ≈ 16.1（年）
6代數

判斷對錯：a>0 時，10^(2 log a) = a²；a>0 時，1/a = 10^(-log a)。

查看解答
都正確。
10^(2 log a) = (10^(log a))² = a² 10^(-log a) = 1/10^(log a) = 1/a
7情境

已知 log a=4.5，下列何者最接近 a 的大小？(A) 90000　(B) 70000　(C) 50000　(D) 30000　(E) 10000

查看解答
10^4.5 = 10⁴×10^0.5 = 10000×√10 ≈ 10000×3.162 ≈ 31623，最接近 (D) 30000。
8情境

某水溶液的氫離子濃度是 10⁻¹·²（莫耳/公升），已知 pH=-log[H⁺]，求這杯溶液的 pH 值。

查看解答
pH = -log(10⁻¹·²) = -(-1.2) = 1.2

給筱葳的話

指數在回答「10 連乘幾次」，對數則是反過來問「要連乘幾次，才能拼出這個數」——兩者是同一件事的正反面。細菌的爆炸性成長、地震規模、pH 值、分貝，這些看似不相關的現象，骨子裡都是同一個工具：把差距懸殊到不方便比較的數字，壓縮成方便閱讀、方便相減比較的尺度。

這份教材裡最實用的兩個結論，值得背熟：log 的差對應倍數關係（log a − log b = k ⟹ a/b=10ᵏ），以及位數估計（正整數 N 的位數 = ⌊log N⌋+1）。
