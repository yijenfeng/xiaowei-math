數A 第四冊・第四章 矩陣・4-1

高斯消去法與矩陣

園遊會結束，測量社攤位賣了三樣東西：飲料、點心和紀念品。帳本只記了三個總數：一共賣出 150 件、收入 8200 元，而且飲料比點心多賣 30 杯。三樣各賣多少？這是三個未知數的聯立方程式。這一節把方程組寫成一張數字表——矩陣，再用一套固定的步驟「高斯消去法」把它解開，並判斷方程組有唯一解、無解或無限多解。情境例子為原創設計。

解二元一次方程組時，我們用加減消去法消掉一個未知數。三元一次方程組也一樣，只是要消兩輪。高斯消去法把這個過程變成一套標準流程，而且發現：消去時真正在變的只有係數和常數，x、y、z 這些字母只是「位置標籤」。把字母拿掉，只留下數字表格，就是矩陣。

矩陣與增廣矩陣

把字母拿掉，只留數字

情境

飲料每杯 40 元、點心每份 60 元、紀念品每個 100 元。設三樣分別賣出 x、y、z 件，列出方程組。

x + y + z = 150 x − y = 30 40x + 60y + 100z = 8200　→ 除以 20：2x + 3y + 5z = 410

把每個方程式的係數和常數排成一列：

增廣矩陣：1111501−1030235410
矩陣名詞
由數排成的長方形表格稱為矩陣；橫的叫列，直的叫行
m 列 n 行的矩陣稱為 m × n 矩陣；上面的增廣矩陣是 3 × 4
係數矩陣：只有係數的部分（3 × 3）；增廣矩陣：係數矩陣再加上常數那一行

每一列代表一個方程式，每一行代表同一個未知數的係數。第二式沒有 z，要記得補 0。

列運算

三種不會改變答案的操作

規律

解方程組時，有三種操作不會改變解：兩式互換、一式乘以非零數、一式加上另一式的倍數。對應到增廣矩陣，就是三種列運算：

基本列運算
1. 兩列互換（記作 R₂ ↔ R₃）
2. 某列乘以非零數 k（記作 kR₁）
3. 某列加上另一列的 k 倍（記作 R₂ + kR₁ → R₂）

這和 3A、4A 學過的「行列式性質」很像：第 3 種列運算不改變行列式的值。列運算是之後所有矩陣計算的基本工具。

高斯消去法

先消成「階梯形」，再從下往上代回

第一輪：消掉第一行下方的數
1111501−1030235410 R₂ − R₁ → R₂，R₃ − 2R₁ → R₃ 1111500−2−1−120013110
第二輪：消掉第二行下方的數
R₂ ↔ R₃（讓第二列的領頭數是 1，比較好算） 1111500131100−2−1−120 R₃ + 2R₂ → R₃ 111150013110005100

這種左下角全是 0 的樣子稱為階梯形。最後一列就是 5z = 100。

代回
5z = 100 ⟹ z = 20 y + 3z = 110 ⟹ y = 50 x + y + z = 150 ⟹ x = 80 ∴ 飲料 80 杯、點心 50 份、紀念品 20 個 檢查：80 − 50 = 30 ✓，3200 + 3000 + 2000 = 8200 ✓

也可以繼續用列運算，把係數矩陣化成「對角線是 1、其他是 0」的樣子，答案直接出現在最後一行：100800105000120——這稱為簡化階梯形。

解的三種情形

消到最後出現 0 = 0 或 0 = 1

無限多解

解 x + y + z = 6、x + 2y + 3z = 14、2x + 3y + 4z = 20。

11161231423420 → R₂ − R₁、R₃ − 2R₁ → 111601280128 R₃ − R₂ → 111601280000 最後一列是 0 = 0（恆成立），只剩兩個有效方程式 令 z = t：y = 8 − 2t，x = 6 − y − z = −2 + t 解為 (x, y, z) = (−2 + t, 8 − 2t, t)，t 為任意實數
無解

若把第三式改成 2x + 3y + 4z = 21 呢？

同樣的步驟，最後一列變成 0001，也就是 0 = 1，矛盾 ⟹ 無解
幾何意義
階梯形的最後結果解三個平面（2-1）
每列都有領頭數唯一解交於一點
出現 0 = 0 的列（無矛盾）無限多解交於一直線（或重合成一平面）
出現 0 = 非零數無解沒有共同交點

每個三元一次方程式都是空間中的一個平面，方程組的解就是三個平面的共同點。無限多解的參數式 (−2 + t, 8 − 2t, t)，正是 2-2 學過的空間直線。

練習題

1高斯消去

用高斯消去法解 x + 2y − z = 3、2x + y + z = 6、x − y + 2z = 3。

參考答案
12−1321161−123 R₂ − 2R₁、R₃ − R₁ → 12−130−3300−330 R₃ − R₂ → 最後一列 0000 ⟹ 無限多解。第二列：−3y + 3z = 0 ⟹ y = z 令 z = t：y = t，x = 3 − 2t + t = 3 − t 解 (3 − t, t, t)，t 為任意實數（例如 t = 2 時為 (1, 2, 2)）
2唯一解

解 x + y + z = 6、x + 2y + 3z = 14、x + 4y + 9z = 36。

參考答案
R₂ − R₁、R₃ − R₁ → 1116012803830 R₃ − 3R₂ → 111601280026 z = 3，y = 8 − 6 = 2，x = 6 − 2 − 3 = 1
3依參數判斷

方程組 x + y + 2z = 4、2x + 3y + 5z = 9、x + 2y + 3z = k 有解，求 k，並寫出解。

參考答案
R₂ − 2R₁、R₃ − R₁ → 11240111011k−4 R₃ − R₂ → 最後一列 000k−5 有解 ⟺ k = 5（此時無限多解） 令 z = t：y = 1 − t，x = 4 − (1 − t) − 2t = 3 − t 解 (3 − t, 1 − t, t)
4應用

社團採購原子筆（每支 10 元）、筆記本（每本 25 元）、尺（每把 15 元）共 20 件，花 300 元，原子筆數量是尺的 2 倍。三樣各買多少？

參考答案
x + y + z = 20，10x + 25y + 15z = 300，x − 2z = 0 x = 2z 代入：3z + y = 20，35z + 25y = 300 y = 20 − 3z ⟹ 35z + 500 − 75z = 300 ⟹ z = 5 原子筆 10 支、筆記本 5 本、尺 5 把

參考答案
