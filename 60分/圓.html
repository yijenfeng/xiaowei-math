圓與直線

灑水器能噴到半徑 5 公尺內的草地，一條步道會不會被噴濕？這就是「圓和直線的關係」。這一頁練圓的方程式、配方找圓心半徑，以及用「圓心到直線的距離」判斷相交、相切、相離。

直線與圓：115 數B 3 題（含混合題，易）114 數A 3 題115 數A 2 題

這一頁要學會：

  • 寫出圓的方程式；把一般式配方找圓心與半徑
  • 用 d（圓心到直線距離）和 r 比較，判斷位置關係
  • 求弦長、切線
必背

圓心、半徑、距離

圓的方程式
(x − h)² + (y − k)² = r²：圓心 (h, k)，半徑 r
一般式 x² + y² + dx + ey + f = 0 ⟹ 配方
直線與圓（d = 圓心到直線的距離）
d < r 相交兩點；d = r 相切；d > r 相離
弦長 = 2√(r² − d²)
解題步驟

例題

例 1：配方

求圓 x² + y² − 6x + 4y − 12 = 0 的圓心與半徑。

  1. x 項配方：x² − 6x = (x − 3)² − 9
  2. y 項配方：y² + 4y = (y + 2)² − 4
  3. 整理：(x − 3)² + (y + 2)² = 12 + 9 + 4 = 25
圓心 (3, −2)，半徑 5
例 2：位置關係與弦長

直線 3x + 4y + 6 = 0 和上面的圓是什麼關係？若相交，弦長多少？

d = |3 × 3 + 4 × (−2) + 6|／5 = |7|／5 = 1.4 d = 1.4 < r = 5 ⟹ 相交兩點 弦長 = 2√(25 − 1.96) = 2√23.04 = 2 × 4.8 = 9.6
例 3：相切求參數

直線 x + y = k 和圓 x² + y² = 8 相切，求 k。

圓心 (0, 0)，r = √8 = 2√2 d = |0 + 0 − k|／√2 = 2√2 ⟹ |k| = 4 ⟹ k = 4 或 −4
常見陷阱
  • (x + 2)² 的圓心坐標是 −2，不是 +2。
  • 配方後右邊必須大於 0 才是圓；等於 0 是一個點，小於 0 沒有圖形。
  • 相切通常有兩個答案（兩條平行的切線），別漏掉負的那個。

練習題

1寫方程式

寫出圓心 (−1, 4)、半徑 3 的圓方程式。

參考答案
(x + 1)² + (y − 4)² = 9
2配方

求圓 x² + y² + 2x − 8y + 8 = 0 的圓心與半徑。

參考答案
(x + 1)² + (y − 4)² = −8 + 1 + 16 = 9 ⟹ 圓心 (−1, 4)，半徑 3
3位置關係

判斷直線 x − y + 4 = 0 和圓 x² + y² = 4 的關係。

參考答案
d = 4／√2 = 2√2 ≈ 2.83 > 2 ⟹ 相離
4弦長

求直線 y = 3 被圓 x² + y² = 25 截出的弦長。

參考答案
d = 3 ⟹ 弦長 = 2√(25 − 9) = 8
5切線

求圓 x² + y² = 25 在點 (3, 4) 的切線方程式。

參考答案
切線垂直半徑：半徑斜率 4／3 ⟹ 切線斜率 −3／4 y − 4 = −(3／4)(x − 3) ⟹ 3x + 4y = 25
