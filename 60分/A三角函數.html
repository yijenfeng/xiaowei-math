三角函數：週期、和角、疊合

摩天輪轉一圈 20 分鐘，高度上上下下——這就是三角函數。這一頁只練基本題最常用的四件事：弧度換算、讀出振幅與週期、和角與二倍角、疊合求最大最小值。

114 數A 第 5、10 題115 數A 第 11 題數A 專屬

這一頁要學會：

  • π = 180°；扇形弧長 rθ、面積 (1／2)r²θ
  • y = a sin(bx + c) + d 的振幅 |a|、週期 2π／|b|
  • 和角、二倍角公式；a sinx + b cosx 的最大值 √(a² + b²)
必背

四組公式

弧度與扇形
π 弧度 = 180°；弧長 s = rθ；面積 A = (1／2)r²θ（θ 用弧度）
圖形
y = a sin(bx + c) + d：振幅 |a|，週期 2π／|b|，最大 d + |a|，最小 d − |a|
cos 同理；tan 的週期是 π／|b|
和角與二倍角
sin(α ± β) = sinα cosβ ± cosα sinβ；cos(α ± β) = cosα cosβ ∓ sinα sinβ
sin2θ = 2sinθ cosθ；cos2θ = 1 − 2sin²θ = 2cos²θ − 1
疊合
a sinx + b cosx = r sin(x + φ)，r = √(a² + b²)
最大值 r，最小值 −r
解題步驟

例題

例 1：讀圖形參數

求 y = 3sin(2x − π／3) + 1 的週期、最大值、最小值。

週期 2π／2 = π 最大 1 + 3 = 4，最小 1 − 3 = −2
例 2：和角

求 sin75°。

sin(45° + 30°) = (√2／2)(√3／2) + (√2／2)(1／2) = (√6 + √2)／4
例 3：疊合求極值

求 f(x) = 3sinx − 4cosx + 2 的最大值與最小值。

  1. r = √(9 + 16) = 5 ⟹ 3sinx − 4cosx 介於 −5 到 5
  2. 再加 2
最大 7，最小 −3
常見陷阱
  • 週期公式是 2π 除以 x 前面的係數，和外面的 a 無關。
  • 疊合的最大值 √(a² + b²) 只適用於 sin 和 cos 的「x 相同」。
  • cos2θ 有三種寫法，題目給 sinθ 就用 1 − 2sin²θ。

練習題

1弧度

扇形半徑 6、圓心角 120°，求弧長與面積。

參考答案
120° = 2π／3；弧長 4π，面積 (1／2) × 36 × 2π／3 = 12π
2週期

求 y = −2cos(x／3) 的週期與值域。

參考答案
週期 2π ÷ (1／3) = 6π；值域 −2 ≤ y ≤ 2
3和角

求 cos15°。

參考答案
cos(45° − 30°) = (√6 + √2)／4
4二倍角

θ 為銳角，sinθ = 3／5，求 sin2θ、cos2θ。

參考答案
cosθ = 4／5；sin2θ = 24／25；cos2θ = 1 − 18／25 = 7／25
5疊合

求 √3 sinx + cosx 的最大值，以及在 0 ≤ x < 2π 中何時發生。

參考答案
= 2sin(x + π／6)，最大值 2，發生在 x + π／6 = π／2 ⟹ x = π／3
