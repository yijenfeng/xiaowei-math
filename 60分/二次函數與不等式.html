二次函數與多項式不等式

飲料一杯定價 x 元，利潤是 −(x − 50)² + 900——定價多少賺最多？這一頁練兩件事：用配方找二次函數的最大最小值，以及用「找根、畫數線」解多項式不等式。

多項式函數：114 數A 第 13 題（易）114、115 數A 各 2 題115 數B 2 題

這一頁要學會：

  • 配方求頂點、最大值或最小值（含有範圍限制時）
  • 判別式判斷圖形和 x 軸的交點數
  • 解二次與高次不等式
必背

頂點、判別式、數線

二次函數 y = ax² + bx + c
配方：y = a(x − h)² + k，頂點 (h, k)，h = −b／2a
a > 0 開口向上，頂點是最小值；a < 0 開口向下，頂點是最大值
判別式 D = b² − 4ac：D > 0 交 x 軸兩點；D = 0 相切；D < 0 不相交
解不等式（首項係數為正）
(x − α)(x − β) < 0 ⟺ α < x < β（夾在兩根中間）
(x − α)(x − β) > 0 ⟺ x < α 或 x > β（兩根外面），α < β
解題步驟

例題

例 1：有範圍的最大最小值

求 f(x) = x² − 4x + 1 在 0 ≤ x ≤ 5 的最大值與最小值。

  1. 配方：f(x) = (x − 2)² − 3，頂點 (2, −3)，開口向上
  2. 頂點 x = 2 在範圍內 ⟹ 最小值 −3
  3. 最大值在離頂點最遠的端點：x = 5（離 2 有 3）比 x = 0（離 2 有 2）遠
最小值 f(2) = −3，最大值 f(5) = 25 − 20 + 1 = 6
例 2：二次不等式

解 x² − x − 6 ≤ 0。

(x − 3)(x + 2) ≤ 0，兩根 −2、3，要「≤ 0」⟹ 夾在中間 −2 ≤ x ≤ 3
例 3：高次不等式

解 (x + 1)(x − 2)(x − 4) > 0。

  1. 根由小到大：−1、2、4，標在數線上
  2. 最右邊（x > 4）一定是正的，往左每過一個根就變號：＋、−、＋、−
  3. 取正的區間
x > 4：＋　2 < x < 4：−　−1 < x < 2：＋　x < −1：− 解：−1 < x < 2 或 x > 4
常見陷阱
  • 首項係數是負的，先兩邊乘 −1（不等號變向）再解。
  • 有範圍時，最小值不一定在頂點——頂點不在範圍內就看端點。
  • 重根（例如 (x − 1)²）經過時不變號。

練習題

1頂點

求 y = −2x² + 8x − 3 的頂點與最大值。

參考答案
y = −2(x − 2)² + 5 ⟹ 頂點 (2, 5)，最大值 5
2判別式

y = x² + kx + 4 的圖形和 x 軸相切，求 k。

參考答案
D = k² − 16 = 0 ⟹ k = 4 或 −4
3二次不等式

解 2x² − 5x − 3 > 0。

參考答案
(2x + 1)(x − 3) > 0 ⟹ x < −1／2 或 x > 3
4應用

利潤 P(x) = −x² + 100x − 1600（x 為定價），定價多少時利潤最大？最大利潤是多少？

參考答案
P = −(x − 50)² + 900 ⟹ 定價 50 元，最大利潤 900 元
5高次不等式

解 x(x − 3)(x + 2) ≤ 0。

參考答案
根 −2、0、3；由右往左：＋、−、＋、− ≤ 0：x ≤ −2 或 0 ≤ x ≤ 3
