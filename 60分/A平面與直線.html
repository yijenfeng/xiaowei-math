空間中的平面與直線

斜掛的布幕是一個平面，無人機的航線是一條直線：它什麼時候穿過布幕？離布幕多遠？這一頁練平面方程式、直線參數式，以及交點、夾角、距離三種基本計算。

115 數A 第 19 題（混合題，易）114 數A 第 14 題數A 專屬

這一頁要學會：

  • 平面：一點 + 法向量；過三點用外積找法向量
  • 直線：一點 + 方向向量，寫成參數式
  • 直線與平面交點、兩平面夾角、點到平面距離
必背

平面、直線、距離

平面（法向量 (a, b, c)，過 (x₀, y₀, z₀)）
a(x − x₀) + b(y − y₀) + c(z − z₀) = 0，整理成 ax + by + cz = d
直線（方向 (p, q, r)，過 (x₀, y₀, z₀)）
(x₀ + pt, y₀ + qt, z₀ + rt)
距離與夾角
點到平面：|ax₀ + by₀ + cz₀ − d|／√(a² + b² + c²)
兩平面夾角：cosθ = ±(n₁・n₂)／(|n₁||n₂|)
解題步驟

例題

例 1：過三點的平面

求過 A(1, 0, 0)、B(0, 2, 0)、C(0, 0, 3) 的平面。

法向量 = AB × AC = (6, 3, 2) 過 A：6(x − 1) + 3y + 2z = 0 ⟹ 6x + 3y + 2z = 6
例 2：直線與平面交點

直線 (1 + 2t, 2 + t, 2t) 與平面 2x + y + 2z = 22 的交點。

  1. 參數式代入平面：2 + 4t + 2 + t + 4t = 22
  2. 9t + 4 = 22 ⟹ t = 2
交點 (5, 4, 4)
例 3：點到平面距離

求 (2, 3, 4) 到 6x + 3y + 2z = 6 的距離。

|12 + 9 + 8 − 6|／√49 = 23／7
常見陷阱
  • 平面方程式的係數就是法向量；直線的參數係數是方向向量，別搞混。
  • 點到平面距離公式要先寫成 ax + by + cz = d，再減 d。
  • 直線方向和平面法向量垂直（內積 0）時，直線和平面平行（或在平面上）。

練習題

1平面

求過 (1, −2, 3)、法向量 (2, 1, −1) 的平面。

參考答案
2(x − 1) + (y + 2) − (z − 3) = 0 ⟹ 2x + y − z = −3
2距離

求 (1, 2, 3) 到 2x − y + 2z = 10 的距離。

參考答案
|2 − 2 + 6 − 10|／3 = 4／3
3交點

求直線 (1 + t, 2 − t, 3 + 2t) 與平面 x + y + z = 10 的交點。

參考答案
6 + 2t = 10 ⟹ t = 2 ⟹ (3, 0, 7)
4夾角

求平面 x + z = 1 與 y + z = 2 的夾角。

參考答案
cosθ = ±1／2 ⟹ 60° 或 120°
5寫直線

寫出過 A(1, −1, 2)、B(3, 0, 5) 的直線參數式。

參考答案
方向 (2, 1, 3) ⟹ (1 + 2t, −1 + t, 2 + 3t)
