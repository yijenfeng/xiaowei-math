數據分析

老師把全班成績「每人加 5 分」或「乘以 1.2」，平均和標準差會怎麼變？這一頁練一維數據（平均、標準差、伸縮平移）和二維數據（相關係數、迴歸直線）最常考的觀念。

115 數B 第 10 題（易）114 數A 第 12 題115 數A 第 9 題

這一頁要學會：

  • 算平均數、標準差
  • 資料 y = ax + b 時，平均、標準差、相關係數怎麼變
  • 迴歸直線：斜率 = r × (σy／σx)，一定通過 (x̄, ȳ)
必背

一維與二維

平均數與標準差
μ = (x₁ + … + xₙ)／n；σ = √((x₁−μ)² + … + (xₙ−μ)²)／n
也可以用 σ² = (x₁² + … + xₙ²)／n − μ²
伸縮平移 y = ax + b
μy = aμx + b；σy = |a|σx（加減不影響標準差）
相關係數：a > 0 不變，a < 0 變號
迴歸直線（y 對 x）
y − ȳ = r・(σy／σx)・(x − x̄)
−1 ≤ r ≤ 1；r 越接近 ±1，點越接近一直線
解題步驟

例題

例 1：平均與標準差

5 位同學的小考分數：6、7、8、9、10。求平均與標準差。

μ = 40／5 = 8 偏差平方：4、1、0、1、4，和 = 10 σ = √(10／5) = √2 ≈ 1.41
例 2：調分

全班平均 60、標準差 10。老師用「新分數 = 1.2 × 原分數 + 10」調分。新的平均和標準差是多少？

新平均 = 1.2 × 60 + 10 = 82 新標準差 = 1.2 × 10 = 12（加 10 不影響）
例 3：迴歸直線

讀書時數 x 與分數 y：x̄ = 5、σx = 2，ȳ = 70、σy = 12，相關係數 r = 0.8。求迴歸直線，並預測讀 8 小時的分數。

斜率 = 0.8 × 12／2 = 4.8 y − 70 = 4.8(x − 5) ⟹ y = 4.8x + 46 x = 8：y = 38.4 + 46 = 84.4
常見陷阱
  • 每人加分：平均跟著加，標準差不變。
  • 乘以負數：標準差乘的是絕對值，相關係數會變號。
  • 相關係數接近 0 只代表「沒有直線關係」，不代表完全沒關係。

練習題

1平均與標準差

資料 2、4、4、4、6 的平均與標準差。

參考答案
μ = 20／5 = 4；偏差平方 4、0、0、0、4，和 8 σ = √(8／5) ≈ 1.26
2伸縮平移

x 的平均 20、標準差 3。y = −2x + 5，求 y 的平均與標準差。

參考答案
平均 −2 × 20 + 5 = −35；標準差 2 × 3 = 6
3相關係數

x 與 y 的相關係數為 0.6。u = 3x + 1、v = −y + 2，求 u 與 v 的相關係數。

參考答案
3 > 0 不變號，−1 < 0 變號 ⟹ −0.6
4迴歸直線

x̄ = 10、ȳ = 50、σx = 4、σy = 6、r = −0.5。求 y 對 x 的迴歸直線。

參考答案
斜率 = −0.5 × 6／4 = −0.75 y − 50 = −0.75(x − 10) ⟹ y = −0.75x + 57.5
5觀念

判斷對錯：「迴歸直線一定通過 (x̄, ȳ)。」

參考答案
對。代入 x = x̄ 得 y = ȳ。
