指數與常用對數

細菌每小時分裂一次，24 小時後有 2²⁴ 隻——這是幾位數？這一頁練指數律的計算、常用對數的運算，以及學測最愛考的「位數」與「首位數字」。

這一頁要學會：

  • 指數律：同底相乘指數相加、次方的次方指數相乘
  • 用 log 2、log 3 算出其他對數值
  • 用 log 判斷位數、首位數字
必背

指數律與對數

指數律（a > 0）
aᵐ・aⁿ = a^(m+n)；aᵐ ÷ aⁿ = a^(m−n)；(aᵐ)ⁿ = a^(mn)
a⁰ = 1；a^(−n) = 1／aⁿ；a^(1／n) = ⁿ√a
常用對數
log x = y ⟺ 10ʸ = x
log(MN) = log M + log N；log(M／N) = log M − log N；log Mᵖ = p log M
常用值：log 2 ≈ 0.3010，log 3 ≈ 0.4771，log 5 = 1 − log 2 ≈ 0.6990
位數
正整數 N 的位數 = (log N 的整數部分) + 1
解題步驟

例題

例 1：指數計算

計算 8^(2／3) × 4^(−1／2)。

先全部化成 2 的次方： 8^(2／3) = (2³)^(2／3) = 2²，4^(−1／2) = (2²)^(−1／2) = 2^(−1) 2² × 2^(−1) = 2¹ = 2
例 2：位數

2²⁴ 是幾位數？（log 2 ≈ 0.3010）

  1. 取 log：log 2²⁴ = 24 × 0.3010 = 7.224
  2. 整數部分 7 ⟹ 位數 = 7 + 1 = 8
2²⁴ = 10^7.224，介於 10⁷ 和 10⁸ 之間 ⟹ 8 位數
例 3：首位數字

承上，2²⁴ 的最高位數字是多少？（log 3 ≈ 0.4771）

看小數部分 0.224： log 1 = 0 < 0.224 < 0.3010 = log 2 ⟹ 10^0.224 介於 1 和 2 之間 ⟹ 首位數字是 1 （驗證：2²⁴ = 16777216 ✓）
常見陷阱
  • log(M + N) 不能拆成 log M + log N。
  • 小數的 log 是負數：log 0.02 = log 2 − 2 ≈ −1.699。
  • 位數要「整數部分 + 1」，不要忘了加 1。

練習題

1指數

計算 27^(2／3) ÷ 9^(1／2)。

參考答案
3² ÷ 3¹ = 3
2對數

已知 log 2 ≈ 0.3010、log 3 ≈ 0.4771，求 log 12 和 log 1.5。

參考答案
log 12 = 2 log 2 + log 3 ≈ 1.0791 log 1.5 = log 3 − log 2 ≈ 0.1761
3位數

3³⁰ 是幾位數？（log 3 ≈ 0.4771）

參考答案
30 × 0.4771 = 14.313 ⟹ 15 位數
4首位數字

承上題，3³⁰ 的首位數字是多少？（log 2 ≈ 0.3010）

參考答案
小數部分 0.313 介於 log 2 = 0.301 與 log 3 = 0.477 之間 ⟹ 首位數字 2
5比較大小

比較 2³⁰ 和 3²⁰ 的大小。

參考答案
2³⁰ = (2³)¹⁰ = 8¹⁰，3²⁰ = (3²)¹⁰ = 9¹⁰ ⟹ 2³⁰ < 3²⁰
