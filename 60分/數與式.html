數與式：絕對值與根式

筱葳和朋友約在捷運站中間點碰面，「離 3 號出口不超過 2 站」這種描述，寫成數學就是 |x − 3| ≤ 2。這一頁只練兩件事：絕對值不等式怎麼解、根式怎麼化簡與有理化。這通常是考卷的第 1、2 題，應該穩拿。

115 數B 第 1 題（易）115 數A 第 2 題數A・數B 共同

這一頁要學會：

  • 絕對值的意義：數線上的距離
  • 解 |x − a| < r、|x − a| > r 型的不等式
  • 根式化簡、分母有理化、估計根式大小
必背

三條公式就夠用

絕對值（r > 0）
|x − a| < r ⟺ a − r < x < a + r（離 a 不到 r）
|x − a| > r ⟺ x < a − r 或 x > a + r（離 a 超過 r）
根式
√a・√b = √ab；√(k²a) = k√a（k > 0）
有理化：1／(√a + √b) = (√a − √b)／(a − b)
解題步驟

例題

例 1：絕對值不等式

解 |2x − 5| ≤ 7，並求整數解有幾個。

  1. 去掉絕對值：−7 ≤ 2x − 5 ≤ 7
  2. 三邊同加 5：−2 ≤ 2x ≤ 12
  3. 三邊同除 2：−1 ≤ x ≤ 6
整數解：−1, 0, 1, …, 6，共 8 個
例 2：距離的意義

數線上點 P(x) 到 A(1) 和 B(7) 的距離和為 10，求 x。

|x − 1| + |x − 7| = 10 AB = 6 < 10，所以 P 在 AB 外面，多出來的 4 兩邊各分 2： x = 1 − 2 = −1 或 x = 7 + 2 = 9
例 3：根式化簡與估計

化簡 1／(√5 − √3)，並判斷它介於哪兩個連續整數之間。

分子分母同乘 (√5 + √3)： (√5 + √3)／(5 − 3) = (√5 + √3)／2 √5 ≈ 2.236，√3 ≈ 1.732 ⟹ (2.236 + 1.732)／2 ≈ 1.984 ⟹ 介於 1 和 2 之間
常見陷阱
  • |x − a| > r 的答案是「兩段」，不是一段。
  • 不等式兩邊乘除負數要變號：−2x < 6 ⟹ x > −3。
  • √(a + b) ≠ √a + √b，例如 √(9 + 16) = 5 ≠ 7。

練習題

1絕對值

解 |x + 2| < 4。

參考答案
−4 < x + 2 < 4 ⟹ −6 < x < 2
2絕對值

解 |3x − 1| ≥ 5。

參考答案
3x − 1 ≤ −5 或 3x − 1 ≥ 5 ⟹ x ≤ −4／3 或 x ≥ 2
3整數解

滿足 |x − 3| ≤ 4 的整數 x 共有幾個？總和是多少？

參考答案
−1 ≤ x ≤ 7，共 9 個；總和 = (−1 + 7) × 9 ÷ 2 = 27
4根式

化簡 √50 − √18 + √8。

參考答案
5√2 − 3√2 + 2√2 = 4√2
5有理化

化簡 2／(√7 + √5)。

參考答案
2(√7 − √5)／(7 − 5) = √7 − √5
