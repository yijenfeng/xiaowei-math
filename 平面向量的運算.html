平面向量的運算

定向越野進入第二關：選手手上只有兩種提示卡，一種寫「右 1、上 2」，一種寫「右 1、下 1」，要自己決定各用幾張，才能剛好走到檢查點。這一節延續測量社的定向越野，學習向量的加減法與係數積、判斷平行與三點共線，並用「線性組合」與「分點公式」描述平面上任何一個位置。情境例子為原創設計。

數字可以加減乘除，向量也有自己的運算規則。好消息是：一旦寫成坐標，向量的加減和係數積都只是「x 和 x 算、y 和 y 算」。但每個運算背後都有清楚的幾何意義——接著走、倒著走、走幾倍遠——掌握這些意義，才能在沒有坐標的題目裡也用得上向量。

向量的加法

先走一段、再走一段，等於直接走過去

情境

筱葳先照提示卡 a = (4, 1) 走，接著照提示卡 b = (2, 4) 走。她和起點的總位移是多少？

把第二段的始點接在第一段的終點，從最初的起點指向最後的終點，就是兩向量的和：

a + b = (4 + 2, 1 + 4) = (6, 5)
向量加法
三角形法：AB + BC = AC
坐標：(x₁, y₁) + (x₂, y₂) = (x₁ + x₂, y₁ + y₂)
觀察 → 規律：平行四邊形法

先走 b 再走 a，會走到同一個終點：a + b = b + a（交換律）。兩條路線圍成一個平行四邊形，a + b 就是它的對角線。這叫平行四邊形法，適合處理「兩個力同時作用」的情況。

情境：渡河

定向越野的最後一段要划橡皮艇過一條 2 公里寬的河。船頭一直朝正對岸，靜水船速 4 公里／時；河水往右流，流速 3 公里／時。船實際的速度是多少？到對岸時會被沖下游多遠？

船速 (0, 4) + 水速 (3, 0) = 實際速度 (3, 4) 實際速率 = √(9 + 16) = 5（公里／時） 過河時間 = 河寬 ÷ 垂直分量 = 2 ÷ 4 = 0.5（小時） 被沖下游 = 3 × 0.5 = 1.5（公里）

過河時間只看「垂直於河岸」的分量，和水流無關。這就是把向量拆成兩個分量分開處理的好處。

減法與係數積

減一個向量，就是加它的反向量

規律 → 公式
減法與係數積
a − b = a + (−b)；坐標：(x₁ − x₂, y₁ − y₂)
ka = (kx, ky)：長度變成 |k| 倍；k > 0 同向，k < 0 反向

3-1 學過的 AB = OB − OA，就是向量減法的例子：從 A 走到 B，等於「先從 A 退回原點，再從原點走到 B」。

用一用
a = (2, −1)，b = (−1, 3) 2a − 3b = (4, −2) − (−3, 9) = (7, −11) |a − b| = |(3, −4)| = 5

向量運算滿足和數字一樣的規則：交換律、結合律、分配律 k(a + b) = ka + kb。所以可以像解一元一次方程式一樣移項，例如 2x + a = b ⟹ x = (b − a)／2。

平行與三點共線

一個是另一個的倍數，就是平行

規律 → 公式

兩個非零向量方向相同或相反，就說它們平行。由係數積的意義：

平行條件（a = (x₁, y₁)、b = (x₂, y₂) 皆非零）
a ∥ b ⟺ a = tb（t 為實數）⟺ x₁y₂ − x₂y₁ = 0

x₁y₂ − x₂y₁ = 0 其實就是 x₁／x₂ = y₁／y₂（分量成比例）交叉相乘的寫法，好處是分母為 0 時也能用。這個式子在 3-4 會以「二階行列式」的身分再次登場。

情境：三個檢查點在一直線上？

檢查點 A(1, 1)、B(3, 4)、C(7, k)。若三點在同一條直線上，k 是多少？

A、B、C 共線 ⟺ AB ∥ AC AB = (2, 3)，AC = (6, k − 1) 2(k − 1) − 6 × 3 = 0 ⟹ k − 1 = 9 ⟹ k = 10
線性組合

兩張不平行的提示卡，就能走到任何地方

情境

第二關只有兩種提示卡：a =「右 1、上 2」= (1, 2)，b =「右 1、下 1」= (1, −1)。檢查點在 (5, 4)，要各用幾張？

設用 x 張 a、y 張 b：x(1, 2) + y(1, −1) = (5, 4) x + y = 5 2x − y = 4 相加：3x = 9 ⟹ x = 3，y = 2 ∴ 3 張 a 卡、2 張 b 卡：3a + 2b = (5, 4)
規律 → 定理
平面向量的線性組合
若 a、b 不平行，則平面上任一向量 v 都可唯一表示成 v = xa + yb

如果 x、y 允許是分數或負數（倒著走、走半張），兩張不平行的卡可以組合出平面上的每一個點，而且組合方式只有一種。但若兩張卡平行（例如 (1, 2) 和 (2, 4)），就只能在一條直線上來回，永遠離不開那條線。

分點公式

用向量重新推出分點公式

情境

補給站要設在 A(1, 2) 到 B(7, 5) 的直線步道上，且離 A 的距離是離 B 的 2 倍（AP : PB = 2 : 1）。補給站 P 在哪裡？

P 在 AB 上、走了全程的 2／3：

OP = OA + (2／3)AB = OA + (2／3)(OB − OA) = (1／3)OA + (2／3)OB P = (1／3)(1, 2) + (2／3)(7, 5) = (1／3 + 14／3, 2／3 + 10／3) = (5, 4)
規律 → 公式
分點公式（P 在線段 AB 上，AP : PB = m : n）
OP = (n／(m + n))OA + (m／(m + n))OB
三角形 ABC 的重心 G：OG = (1／3)(OA + OB + OC)

係數要「交叉」：靠近 A 的那一份比例 m，配給 B；這和數學1的分點坐標公式完全一樣。更一般的結論是：OP = sOA + tOB 且 s + t = 1 時，P 一定在直線 AB 上。

收進工具箱：3-2 平面向量的運算

寫成坐標後，向量運算就是分量各自運算；平行看倍數，共線看平行，任何向量都能用兩個不平行的向量組合出來。

名稱內容
加法AB + BC = AC；(x₁, y₁) + (x₂, y₂) = (x₁+x₂, y₁+y₂)
減法AB = OB − OA
係數積k(x, y) = (kx, ky)，長度 |k| 倍
平行a = tb ⟺ x₁y₂ − x₂y₁ = 0
三點共線AB ∥ AC
線性組合a、b 不平行時，v = xa + yb 有唯一解
分點公式AP : PB = m : n ⟹ OP = (nOA + mOB)／(m + n)

練習題

1運算

a = (3, −2)，b = (−1, 4)，求 a + 2b 與 |a − b|。

參考答案
a + 2b = (3 − 2, −2 + 8) = (1, 6) a − b = (4, −6)，長度 √(16 + 36) = √52 = 2√13
2平行

若 (k, 3) 與 (4, k + 4) 平行，求 k。

參考答案
k(k + 4) − 4 × 3 = 0 ⟹ k² + 4k − 12 = 0 ⟹ (k + 6)(k − 2) = 0 k = 2 或 k = −6
3共線

A(−1, 2)、B(2, 3)、C(8, k) 三點共線，求 k。

參考答案
AB = (3, 1)，AC = (9, k − 2) 3(k − 2) − 9 × 1 = 0 ⟹ k = 5
4線性組合

把 (7, 0) 表示成 x(1, 2) + y(2, −1)。

參考答案
x + 2y = 7，2x − y = 0 ⟹ y = 2x x + 4x = 7 ⟹ x = 7／5，y = 14／5
5分點與重心

A(2, −1)、B(−4, 8)。(1) P 在 AB 上且 AP : PB = 1 : 2，求 P。(2) 再取 C(5, 11)，求三角形 ABC 的重心。

參考答案
(1) P = (2／3)A + (1／3)B = (4／3 − 4／3, −2／3 + 8／3) = (0, 2) (2) G = ((2 − 4 + 5)／3, (−1 + 8 + 11)／3) = (1, 6)

下一步：兩個向量「乘」起來

向量能加、能減、能乘一個數，那兩個向量能不能相乘？物理課的「功」給了答案：拉行李箱時，只有順著前進方向的那部分力真的在做事。在 3-3「平面向量的內積」，我們會把這個想法變成內積的定義，用它算夾角、判斷垂直、求正射影，並得到兩個重要的不等式。
