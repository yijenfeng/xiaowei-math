數A 第四冊・第一章 空間向量・1-4

外積、體積與行列式

燈光秀的舞台上掛著一面斜放的三角形布幕，燈光師想從「正面」打光，需要一個垂直布幕的方向；道具組則想知道一個歪斜的展示櫃能裝多少東西。這一節學習向量的第二種乘法——外積，它能直接造出垂直向量、算出面積；再把 3A 的二階行列式升級成三階，用來算體積、判斷共平面。情境例子為原創設計。

內積把兩個向量變成一個數，外積則把兩個向量變成一個新的向量：它同時垂直於原本的兩個向量，長度剛好等於兩者張出的平行四邊形面積。外積只在三維空間有意義，它的每個分量都是一個二階行列式；而把外積再和第三個向量做內積，就得到三階行列式——平行六面體的體積。

外積

同時垂直兩個向量的方向

情境

布幕上有兩個方向 a = (1, 2, 0) 與 b = (0, 1, 3)。燈光要垂直打在布幕上，方向向量 n = (x, y, z) 是什麼？

n 要同時和 a、b 垂直：x + 2y = 0 且 y + 3z = 0。兩個方程式、三個未知數，解有無限多組（都互相平行）。一般地解 x₁x + y₁y + z₁z = 0、x₂x + y₂y + z₂z = 0，會得到一組漂亮的解，每個分量都是二階行列式：

外積（a = (x₁, y₁, z₁)，b = (x₂, y₂, z₂)）
a × b = ( y₁z₁y₂z₂, z₁x₁z₂x₂, x₁y₁x₂y₂ )

記法：把兩個向量上下寫兩列，求第一個分量時蓋住 x 那一行，求第二個分量時蓋住 y 那一行（注意是「z、x」的順序），求第三個分量時蓋住 z 那一行。

a × b = (2 × 3 − 0 × 1, 0 × 0 − 1 × 3, 1 × 1 − 2 × 0) = (6, −3, 1) 檢查：(6, −3, 1)・(1, 2, 0) = 6 − 6 = 0 ✓ 　　　(6, −3, 1)・(0, 1, 3) = −3 + 3 = 0 ✓
外積的性質
性質
a × b 同時垂直 a 與 b，方向依右手定則（四指由 a 彎向 b，拇指方向）
|a × b| = |a||b|sinθ
b × a = −(a × b)（交換律不成立！）
a ∥ b ⟺ a × b = 0
用外積算面積

外積的長度，就是平行四邊形的面積

規律 → 公式

3A 學過平行四邊形面積 = |a||b|sinθ，而這正好是 |a × b|：

空間中的面積
平行四邊形面積 = |a × b|　　三角形面積 = (1／2)|a × b|
情境

三角形布幕的三個掛點是 A(1, 0, 0)、B(0, 2, 0)、C(0, 0, 3)（單位：公尺）。布幕面積多大？

AB = (−1, 2, 0)，AC = (−1, 0, 3) AB × AC = (2 × 3 − 0 × 0, 0 × (−1) − (−1) × 3, (−1) × 0 − 2 × (−1)) = (6, 3, 2) |AB × AC| = √(36 + 9 + 4) = 7 布幕面積 = 7／2 = 3.5（平方公尺）

同時得到布幕的法向量 (6, 3, 2)——燈光從這個方向打過去就是正面。

三階行列式

3A 的二階行列式，升級成三階

定義

三階行列式定義為「沿第一列展開」，每一項都是一個數乘上一個二階行列式：

三階行列式
a₁a₂a₃b₁b₂b₃c₁c₂c₃ = a₁b₂b₃c₂c₃ − a₂b₁b₃c₁c₃ + a₃b₁b₂c₁c₂

注意中間那項是減號。另一種常用的算法是「對角線法」：三條右下斜線的乘積相加，減去三條左下斜線的乘積——結果完全一樣，但只適用於三階。

123014560 = 1(1 × 0 − 4 × 6) − 2(0 × 0 − 4 × 5) + 3(0 × 6 − 1 × 5) = −24 + 40 − 15 = 1
性質
性質效果
任兩列（或兩行）對調值變號
某一列乘以 k值乘以 k
某列加上另一列的倍數值不變
有兩列相同或成比例值為 0
行列互換（轉置）值不變

這些性質和 3A 的二階行列式完全一樣，常用來先把某一行湊出很多 0，再展開，計算會快很多。

體積與共平面

歪斜的展示櫃能裝多少？

觀察 → 規律

三個向量 a、b、c 張出一個平行六面體（每個面都是平行四邊形的「歪斜箱子」）。它的體積 = 底面積 × 高：

底面積 = |a × b| 高 = c 在 a × b 方向上的正射影長 = |c・(a × b)|／|a × b| 體積 = |c・(a × b)|

把 c・(a × b) 展開，剛好就是以 a、b、c 為三列的三階行列式：

體積公式
平行六面體體積 = |a₁a₂a₃b₁b₂b₃c₁c₂c₃|
四面體體積 = (1／6) × 平行六面體體積
情境

道具組的展示櫃是一個平行六面體，三條邊向量為 (2, 0, 0)、(1, 3, 0)、(1, 1, 4)（單位：公寸）。容量是多少？

200130114 = 2(3 × 4 − 0 × 1) − 0 + 0 = 24 體積 = 24 立方公寸 = 24 公升
用一用：四點共平面

三個向量張不出體積，代表它們躺在同一個平面上：

a、b、c 共平面 ⟺ 三階行列式 = 0

(1, 2, 3)、(2, 1, 0)、(3, 3, k) 共平面，求 k。

12321033k = 1(k − 0) − 2(2k − 0) + 3(6 − 3) = k − 4k + 9 = 9 − 3k = 0 ⟹ k = 3（檢查：(3, 3, 3) = (1, 2, 3) + (2, 1, 0) ✓）

收進工具箱：1-4 外積、體積與行列式

外積造出法向量並給出面積；三階行列式給出體積並判斷共平面——兩者都在下一章找平面方程式時派上用場。

名稱內容
外積a × b = (y₁z₂ − z₁y₂, z₁x₂ − x₁z₂, x₁y₂ − y₁x₂)
外積性質垂直 a、b；|a × b| = |a||b|sinθ；b × a = −a × b
面積平行四邊形 |a × b|；三角形 (1／2)|a × b|
三階行列式沿第一列展開：+ − + 交錯
體積平行六面體 = |det|；四面體 = |det|／6
共平面三向量的行列式 = 0

練習題

1外積

求 (1, −1, 2) × (3, 0, 1)，並驗證它和兩個向量都垂直。

參考答案
((−1)(1) − 2 × 0, 2 × 3 − 1 × 1, 1 × 0 − (−1) × 3) = (−1, 5, 3) (−1, 5, 3)・(1, −1, 2) = −1 − 5 + 6 = 0 ✓ (−1, 5, 3)・(3, 0, 1) = −3 + 0 + 3 = 0 ✓
2三角形面積

A(1, 1, 1)、B(2, 3, 1)、C(1, 2, 4)，求三角形 ABC 的面積。

參考答案
AB = (1, 2, 0)，AC = (0, 1, 3) AB × AC = (6, −3, 1)，長度 √46 面積 = √46／2
3三階行列式

計算 210131012。

參考答案
= 2(3 × 2 − 1 × 1) − 1(1 × 2 − 1 × 0) + 0 = 10 − 2 = 8
4四面體體積

求以 O(0, 0, 0)、A(2, 1, 0)、B(0, 3, 1)、C(1, 0, 2) 為頂點的四面體體積。

參考答案
210031102 = 2(6 − 0) − 1(0 − 1) + 0 = 13 四面體體積 = 13／6
5共平面

(1, 1, 0)、(0, 1, 1)、(1, k, 1) 共平面，求 k。

參考答案
1100111k1 = 1(1 − k) − 1(0 − 1) + 0 = 2 − k = 0 ⟹ k = 2 （檢查：(1, 2, 1) = (1, 1, 0) + (0, 1, 1) ✓）

第一章完成：從空間概念到體積

從 1-1 的點線面關係，到 1-2 的空間坐標、1-3 的內積、這一節的外積與行列式，空間向量的工具已經齊全。下一章要用它們寫出空間中的「平面」和「直線」的方程式。外積在這裡學到的「造出法向量」，正是 2-1「平面方程式」的第一步。
