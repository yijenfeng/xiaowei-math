級數

把數列的每一項加起來

情境

筱葳想存錢買一台相機，訂了15週的存錢計畫：第1週存300元，之後每週都比前一週多存50元。她想知道：存到第5週為止，總共存了多少錢？

第1~5週各週存款：300, 350, 400, 450, 500
觀察 → 規律 → 公式

要回答「總共存了多少」，就是把數列的前幾項通通加起來：

300+350+400+450+500 = 2000（元）

像這樣把數列 a₁, a₂, a₃, …, aₙ 的前 n 項依序加總，叫做級數，n 稱為項數，總和記作 Sₙ：

級數（前 n 項和）
Sₙ = a₁ + a₂ + a₃ + ⋯ + aₙ

所以筱葳存到第5週為止的總金額就是 S₅=2000元。但如果要問「存完整個15週計畫，總共會存到多少錢」，難道要把15個數字一個一個加起來嗎？下一個主題就是要找出更快的算法。

等差級數與等比級數

不用一項一項加，也能算出總和

情境：等差級數

筱葳的存錢計畫是等差數列：a₁=300，公差d=50，共15週。第15週會存多少？整個計畫存滿15週，總共能存到多少錢，夠不夠買心儀的相機？

a₁₅ = a₁+(15−1)×50 = 300+700 = 1000（元）

如果照定義把15個數字全部加起來會很累。這裡有一個經典的技巧：把總和倒過來加一次，再跟原本的加起來。先用計畫裡前5週的存款（300, 350, 400, 450, 500）示範這個想法：

觀察 → 規律

圖中每一欄的藍＋橘都固定等於800（=300+500），這正是「首項＋末項」的概念。現在把同樣的想法套用到完整的15週計畫：用S代表S₁₅，把它倒過來寫一次，兩式對齊相加：

S = 300 + 350 + 400 + ⋯ + 950 + 1000 +) S = 1000 + 950 + 900 + ⋯ + 350 + 300 ------------------------------------------ 2S = 1300 + 1300 + 1300 + ⋯ + 1300 + 1300　（共15個1300） 2S = 15 × 1300 = 19500 S = 9750

神奇的地方在於：每一組上下對齊的兩個數，加起來都固定是「首項+末項」=300+1000=1300，跟原本的公差 d 完全無關！這個技巧對任何等差數列都成立：

等差級數求和公式
Sₙ = n(a₁+aₙ) ／ 2 　　（也可寫成 Sₙ = n[2a₁+(n−1)d] ／ 2）

結論：筱葳存滿15週後總共會有 9750元，足夠買下她心儀的相機了！

情境：等比級數

回到1-1的社團迎新影片：第1天分享3人，之後每天變成前一天的3倍，連續5天。5天內，總共觸及了多少人次的分享？

S = 3+9+27+81+243

等差級數的「倒過來加」在這裡沒有用（因為規律是相乘，不是相加）。但有一個類似的技巧：把整個總和乘上公比，再跟原本的相減。

觀察 → 規律 → 公式
S = 3 + 9 + 27 + 81 + 243 -) 3S = 9 + 27 + 81 + 243 + 729 ------------------------------------ S − 3S = 3 − 729 −2S = −726 S = 363

關鍵在於：S 和 3S 中間有4項完全重複（9,27,81,243），相減後幾乎都消掉了，只剩頭尾兩項。這個技巧對任何等比數列（r≠1）都成立：

等比級數求和公式（r≠1）
Sₙ = a₁(1−rⁿ) ／ (1−r)　　（r=1時，Sₙ=n·a₁）
驗算：S₅ = 3×(1−3⁵)／(1−3) = 3×(1−243)／(−2) = 3×(−242)／(−2) = 363　✓

結論：這支迎新影片5天內總共被分享了 363人次——這就是「病毒式擴散」的威力：即使每天只是乘上固定倍數，累積起來的總量成長得非常快。

常用的求和公式

三個貫穿學測的求和公式

回顧：Σk

1-1的「疊杯挑戰」已經證明過：1+2+3+⋯+n = n(n+1)／2。這其實就是「首項1、公差1」的等差級數，代入等差級數公式 Sₙ=n(a₁+aₙ)／2，把 a₁=1、aₙ=n 代進去，一樣可以得到同樣的結果——兩種方法殊途同歸。

求和公式①
1+2+3+⋯+n = Σk = n(n+1) ／ 2
情境：Σk²

筱葳幫社刊設計封面，用邊長分別是1, 2, 3, …公分的正方形色紙貼成階梯圖案。如果貼了邊長1到6公分的色紙各一張，總共用掉多少面積的色紙？

面積依序：1²=1, 2²=4, 3²=9, 4²=16, 5²=25, 6²=36 總面積 = 1+4+9+16+25+36 = 91（平方公分）
規律 → 公式（數學歸納法證明）

這類「平方和」有一個現成公式，可以用數學歸納法證明對所有正整數 n 都成立：

求和公式②
1²+2²+3²+⋯+n² = Σk² = n(n+1)(2n+1) ／ 6
(1) n=1：左式=1²=1，右式=1×2×3／6=1，相等，成立。 (2) 假設 n=k 成立：1²+2²+⋯+k² = k(k+1)(2k+1)／6 ……① n=k+1時，左式 = 1²+2²+⋯+k²+(k+1)² = k(k+1)(2k+1)／6 + (k+1)²　　（代入①） = (k+1)[k(2k+1)+6(k+1)]／6 = (k+1)(2k²+7k+6)／6 = (k+1)(k+2)(2k+3)／6 = (k+1)[(k+1)+1][2(k+1)+1]／6 正是 n=k+1 該有的形式，P(k+1) 成立。 由(1)(2)，根據數學歸納法，此公式對所有正整數n成立。

驗算色紙例子：n=6時，Σk²=6×7×13／6=91，跟直接加總的結果一致。

情境：Σk³

筱葳後來把色紙立體化，改用邊長1, 2, 3, 4公分的正方體積木堆成裝置藝術。這4個正方體的總體積是多少？

體積依序：1³=1, 2³=8, 3³=27, 4³=64 總體積 = 1+8+27+64 = 100（立方公分）

立方和也有現成公式，且它的形式跟公式①有巧妙的關聯：

求和公式③
1³+2³+3³+⋯+n³ = Σk³ = [n(n+1)／2]²

觀察公式③的右邊：n(n+1)／2 正是公式①（Σk）！也就是說「立方和＝（一次方和）的平方」，是一個很漂亮的巧合。驗算積木例子：n=4時，Σk³=[4×5／2]²=10²=100，跟直接加總一致。公式③同樣可以用數學歸納法證明，作法跟公式②完全一樣，留給你當作練習。

用一用：混合應用

社課要用彩帶裝飾會場，依序需要 1×2, 2×3, 3×4, …, n×(n+1) 公分長的彩帶。若 n=10，總共需要多少公分的彩帶？

觀察：k×(k+1) = k²+k Σ[k×(k+1)]（k=1到10）= Σk² + Σk = [10×11×21／6] + [10×11／2] = 385 + 55 = 440（公分）

這種「把複雜的求和式拆成已知公式的組合」，是求和公式最常見的應用方式——遇到 k²+k、2k+1 這類含 k 的多項式求和，先拆開成 Σk²、Σk、Σ常數項分別處理，再代公式加起來即可。

複利的應用

把存到的錢放進銀行，複利會怎麼幫你增值？

情境

買了相機以後，筱葳把存錢計畫賺到的9750元先放進一個年利率2.4%（月利率0.2%）、每月複利一次的帳戶，準備存來買鏡頭。存滿12個月後，帳戶裡會有多少錢？

觀察 → 規律

複利的意思是：每個月的利息，會併入本金一起繼續生息（利滾利），而不是每個月都只用原始本金去算利息（那樣叫單利）。設本金 a、每期利率 r，經過1期後變成 a(1+r)；這筆錢再滾一期，變成 a(1+r)²……依此類推：

複利公式
本金a、每期利率r，經過n期後本利和 = a(1+r)ⁿ
9750 × (1+0.2%)¹² = 9750 × (1.002)¹² ≈ 9750 × 1.0243 ≈ 9986.6（元），取整數約 9987元

12個月只多了大約237元的利息，看起來不多。但如果每個月都「額外」再存一筆錢進去，會怎麼樣呢？

情境：定期定額（延伸）

筱葳的朋友怡君也想存錢，她跟筱葳約定：從第1個月起，每個月都存入500元到同一個帳戶（月利率一樣是0.2%，每次存入立刻開始計息）。存滿12個月後（即第12次存入的錢也已經計息一次），這個帳戶裡總共會有多少錢？

觀察 → 規律 → 公式

第1個月存的500元，會複利12次；第2個月存的500元，會複利11次；……第12個月存的500元，只複利1次。把每一筆都算出來再加總，其實就是一個等比級數：

總額 = 500(1+0.2%)¹ + 500(1+0.2%)² + ⋯ + 500(1+0.2%)¹² 這是首項 a₁=500(1.002)、公比 r=1.002、項數n=12 的等比級數： S₁₂ = a₁(1−r¹²)／(1−r) ≈ 6078.6，取整數約 6079元

結論：怡君存滿12個月後，帳戶裡大約有 6079元——每月只存500元、共存入6000元本金，複利就多幫她賺了大約79元的利息。這說明「定期定額投入＋複利」用的正是等比級數求和的技巧，只是每一筆本金投入的時間點不同，複利的期數也各不相同。

學測考複利、年金相關題目時，最常見的錯誤是搞混「單筆存入、放n期」跟「每期都存入一筆、各自複利不同期數」這兩種情境——前者直接用 a(1+r)ⁿ，後者則要用等比級數公式加總。動筆前先想清楚：錢是一次進場，還是分批進場？

收進工具箱：1-2 級數

這一節把數列「加總」的規律整理成公式，是往後排列組合、機率、甚至微積分都會用到的基本功。

名稱內容
級數Sₙ=a₁+a₂+⋯+aₙ（數列前n項的和）
等差級數Sₙ=n(a₁+aₙ)／2＝n[2a₁+(n−1)d]／2
等比級數Sₙ=a₁(1−rⁿ)／(1−r)（r≠1）；r=1時Sₙ=na₁
求和公式①Σk＝n(n+1)／2
求和公式②Σk²＝n(n+1)(2n+1)／6
求和公式③Σk³＝[n(n+1)／2]²
複利本金a、每期利率r，n期後本利和＝a(1+r)ⁿ；定期定額則用等比級數加總

練習題

1等差級數

等差數列 a₁=5，公差d=3，求前20項的和 S₂₀。

參考答案
a₂₀ = 5+(20−1)×3 = 5+57 = 62 S₂₀ = 20×(5+62)／2 = 20×67／2 = 670
2等比級數

等比數列 a₁=2，公比r=3，求前6項的和 S₆。

參考答案
S₆ = 2×(1−3⁶)／(1−3) = 2×(1−729)／(−2) = 2×(−728)／(−2) = 728
3求和公式①

求 1+2+3+⋯+50 的值。

參考答案
Σk（n=50）= 50×51／2 = 1275
4求和公式②③

求 1²+2²+⋯+8² 以及 1³+2³+⋯+5³ 的值。

參考答案
Σk²（n=8）= 8×9×17／6 = 204 Σk³（n=5）= [5×6／2]² = 15² = 225
5複利

筱葳把5000元存入年利率3.6%（月利率0.3%）、每月複利一次的帳戶，求6個月後的本利和（取到整數元，已知 1.003⁶≈1.01814）。

參考答案
本利和 = 5000×(1+0.3%)⁶ = 5000×1.003⁶ ≈ 5000×1.01814 ≈ 5090.7，取整數約 5091元

第一章小結：從一項到一整串的加總
