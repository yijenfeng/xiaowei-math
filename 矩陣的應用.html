矩陣的應用

學期末，筱葳替學生會做了兩個小專題：一個是追蹤同學中午在「學餐」和「便當」之間怎麼換來換去，預測長期下來學餐會有多少人；另一個是幫測量社設計新社徽，要在繪圖軟體裡把圖形旋轉、放大、鏡射。兩件看似無關的事，背後都是同一個工具：用矩陣乘法描述「變化」。情境例子為原創設計。

4-2 學會了矩陣乘法，這一節看它的兩個經典應用。第一個是轉移矩陣：描述一群人在幾種狀態之間的移動，每乘一次代表過了一天。第二個是線性變換：一個 2 × 2 矩陣乘上點的坐標，就把整個平面旋轉、伸縮或翻轉；而它的行列式，剛好告訴我們面積變成幾倍。

轉移矩陣

今天吃學餐，明天還吃學餐嗎？

情境

筱葳調查發現：今天吃學餐的人，明天有 70% 繼續吃學餐、30% 改吃便當；今天吃便當的人，明天有 40% 改吃學餐、60% 繼續吃便當。今天學餐、便當各佔一半。明天、後天的比例是多少？

把比例寫成矩陣：第 1 行是「今天學餐」的人明天的去向，第 2 行是「今天便當」的人明天的去向：

轉移矩陣 A = 0.70.40.30.6　（列：明天學餐、明天便當；行：今天學餐、今天便當） 今天 X₀ = 0.50.5 明天 X₁ = AX₀ = 0.7 × 0.5 + 0.4 × 0.50.3 × 0.5 + 0.6 × 0.5 = 0.550.45 後天 X₂ = AX₁ = 0.385 + 0.180.165 + 0.27 = 0.5650.435
轉移矩陣
每個元都是機率（0 到 1 之間），且每一行的和為 1
Xₙ₊₁ = AXₙ，所以 Xₙ = AⁿX₀

每一行加起來是 1，因為「今天吃學餐的人」明天一定會選其中一個。n 天後的狀態，就是轉移矩陣自乘 n 次再乘以今天的狀態——這要用到 4-2 的結合律。

用一用：兩步轉移
A² = 0.70.40.30.60.70.40.30.6 = 0.610.520.390.48 A² 的 (1, 2) 元 0.52 = 今天吃便當的人，後天吃學餐的機率 X₂ = A²X₀ = 0.61 × 0.5 + 0.52 × 0.50.39 × 0.5 + 0.48 × 0.5 = 0.5650.435 ✓
穩定狀態

長期下來，比例會停在哪裡？

觀察 → 規律

0.5 → 0.55 → 0.565 → …，學餐比例越變越慢。如果某一天的狀態 X 再乘一次 A 仍然不變，就到達了穩定狀態：

設穩定狀態 X = p1 − p，AX = X： 0.7p + 0.4(1 − p) = p 0.7p + 0.4 − 0.4p = p ⟹ 0.3p + 0.4 = p ⟹ 0.7p = 0.4 ⟹ p = 4／7 ≈ 0.571 穩定狀態：學餐 4／7、便當 3／7
穩定狀態
AX = X，且 X 的各元總和為 1

有趣的是，不管今天的比例是多少（全部吃學餐也好、全部吃便當也好），長期都會趨近 4／7 和 3／7。這正是轉移矩陣用來做「長期預測」的原因：天氣、市佔率、人口遷移都能這樣分析。

線性變換

一個 2 × 2 矩陣，搬動整個平面

情境

社徽草圖上有一點 (2, 1)。繪圖軟體要把整個圖案繞原點逆時針旋轉 90°，這個點會跑到哪裡？

把點寫成 2 × 1 矩陣，左乘一個 2 × 2 矩陣，就得到新的點。逆時針旋轉 θ 的矩陣是：

旋轉矩陣（繞原點逆時針旋轉 θ）
R(θ) = cosθ−sinθsinθcosθ
R(90°) = 0−110 0−11021 = −12 ⟹ (2, 1) 轉到 (−1, 2)

為什麼是這個矩陣？矩陣的第 1 行是 (1, 0) 變換後的位置，第 2 行是 (0, 1) 變換後的位置。(1, 0) 旋轉 θ 後是 (cosθ, sinθ)，(0, 1) 旋轉 θ 後是 (−sinθ, cosθ)——這就是 3A 單位圓上的坐標。

常見的變換矩陣
變換矩陣(x, y) 變成
伸縮（x 方向 a 倍、y 方向 b 倍）a00b(ax, by)
對 x 軸鏡射100−1(x, −y)
對 y 軸鏡射−1001(−x, y)
對直線 y = x 鏡射0110(y, x)
推移（水平方向）1k01(x + ky, y)

找變換矩陣的通用方法：問「(1, 0) 會變到哪？」寫成第 1 行；「(0, 1) 會變到哪？」寫成第 2 行。

合成變換

社徽先逆時針旋轉 90°，再對 x 軸鏡射。合起來是哪一種變換？

先做的變換寫在右邊（離點最近），後做的寫在左邊：

先旋轉 R = 0−110，再鏡射 F = 100−1 合成 = FR = 100−10−110 = 0−1−10 (x, y) ↦ (−y, −x)：這是對直線 y = −x 的鏡射 若順序反過來：RF = 0110，變成對 y = x 的鏡射——順序不同，結果不同

這就是 4-2「AB ≠ BA」的幾何意義：先轉再翻，和先翻再轉，通常不一樣。

行列式 = 面積倍率

社徽的底座原本是邊長 1 的正方形，用推移矩陣 2101 變換後面積變成多少？

(1, 0) ↦ (2, 0)，(0, 1) ↦ (1, 1) 正方形變成由 (2, 0)、(1, 1) 張成的平行四邊形 面積 = |2101| = |2 − 0| = 2（3A 的二階行列式）
線性變換與面積
矩陣 A 把任何圖形的面積變成 |det A| 倍
旋轉、鏡射：|det| = 1，面積不變；det < 0 代表圖形被翻面
