三種平均數

「平均」其實不只一種算法

情境：算術平均數

老闆想知道招牌「珍珠奶茶」最近賣得如何，筱葳翻出過去10天的銷售紀錄（單位：杯）：

42, 38, 50, 46, 55, 40, 48, 52, 44, 45

要用一個數字代表這10天的銷售狀況，最直覺的做法就是把所有數字加起來，再除以天數。

觀察 → 規律 → 公式
總和 = 42+38+50+46+55+40+48+52+44+45 = 460 平均 = 460 ÷ 10 = 46（杯）

這就是算術平均數：把所有數值加總、除以個數。若資料為 x₁, x₂, …, xₙ，算術平均數記作 μ（讀作 mu）：

算術平均數
μ = (x₁ + x₂ + ⋯ + xₙ) ／ n

結論：這10天平均每天賣出 46杯珍珠奶茶。

情境：加權平均數

老闆接著問：「那我們一杯飲料平均賣多少錢？」這天總共賣出三種杯型：

杯型單價（元）賣出杯數
大杯5030
中杯4550
小杯4020

如果直接把 50、45、40 三個價格加起來除以3，得到45元——但這樣算對嗎？中杯明明賣得最多，應該要「比較有份量」才對。

觀察 → 規律 → 公式

正確的做法，是把每個價格乘上它的「銷售杯數」（權重），加總後再除以總杯數：

(50×30 + 45×50 + 40×20) ÷ (30+50+20) = (1500 + 2250 + 800) ÷ 100 = 4550 ÷ 100 = 45.5（元）

這種「依重要性（權重）調整」的平均，叫做加權平均數。若資料 x₁,…,xₙ 對應的權重為 w₁,…,wₙ：

加權平均數
W = (x₁w₁ + x₂w₂ + ⋯ + xₙwₙ) ／ (w₁ + w₂ + ⋯ + wₙ)

結論：這天每杯的平均客單價是 45.5元，比單純平均的45元更能反映真實營收——因為它把「賣得多的中杯」考慮進去了。

情境：幾何平均數

老闆很興奮地說：「我們開幕第一年營業額成長了21%，第二年又成長了44%！平均下來，我們每年到底成長了幾%？」

你可能會想直接算 (21%+44%)÷2=32.5%——但這其實是錯的！因為「成長率」是一年接著一年連乘上去的，不是直接相加的。

觀察 → 規律 → 公式

設營業額原本是 100（萬元），兩年後變成：

100 × (1+21%) × (1+44%) = 100 × 1.21 × 1.44 = 174.24（萬元）

如果兩年都用「同一個成長率 r」來算，兩年後應該是 100×(1+r)²。要讓兩種算法結果一樣：

(1+r)² = 1.21 × 1.44 = 1.7424 1+r = √1.7424 = 1.32 r = 0.32 = 32%

驗算：100×1.32×1.32 = 174.24（萬元），跟原本的算法完全吻合！這種「連乘後開n次方根」的平均，叫做幾何平均數，最適合用在成長率、利率這種「一段接一段相乘」的情境：

幾何平均數（n個正數 x₁,…,xₙ）
G = ⁿ√(x₁·x₂·⋯·xₙ)

用在成長率時，要先把每年的成長率換成「(1+成長率)」的形式，取幾何平均後再減1，才是正確的「平均成長率」。這一點很容易跟算術平均數搞混，考試中常出這種陷阱。

用一用

飲料店第三年營業額又成長了69%。那麼開幕以來這三年，平均每年的成長率大約是多少？（已知第一、二年分別成長21%與44%）

三年平均成長率 g 滿足：(1+g)³ = 1.21 × 1.44 × 1.69 = 1.7424 × 1.69 = 2.945...

取三次方根：g = ³√2.945... − 1 ≈ 0.434，也就是平均每年大約成長 43%（實際上 1.21×1.44×1.69 恰好等於 1.3³=2.197 的情況才會是整數解，這裡刻意讓數字不是整數，提醒你：現實中的資料不會每次都剛好湊整，遇到開根號算不出整數時，用計算機取到適當的小數位即可）。

百分位數

模擬考的「百分等級」是怎麼算出來的？

情境

學測成績單上除了級分，還會有一個「百分等級（PR值）」，代表你打敗了全國考生的百分之幾。筱葳很好奇這是怎麼算出來的，於是先用班上一次模擬考的數學成績（20人，已由小到大排序）練習：

52, 55, 58, 60, 62, 64, 65, 66, 68, 70, 71, 72, 74, 75, 76, 78, 80, 82, 85, 90

如果筱葳考了75分，能不能只看「排在第几名」就知道自己贏過幾成的人？資料只有20筆，但百分等級要換算成「贏過幾%」，需要更精確的算法。

觀察 → 規律 → 公式

把資料由小到大排序後分成100等分，第 m 個百分位數 Pm 大致代表「有 m% 的資料在它（或與它相等）之下」。設共有 n 筆資料，計算：

第 m 百分位數 Pm 的求法
I = n × (m ／ 100)
若 I 不是整數：取大於 I 的下一個整數 k，P_m = 由小到大排序的第 k 筆資料 若 I 是整數：P_m = 由小到大排序的第 I 筆與第 (I+1) 筆資料的平均
用一用

求這20筆模擬考成績的 P₇₀（第70百分位數）。

I = 20 × (70/100) = 14　　（整數） 取第14筆與第15筆資料的平均： 第14筆 = 75，第15筆 = 76 P₇₀ = (75+76) ÷ 2 = 75.5

也就是說，考75.5分左右的同學，大約贏過班上70%的人。用同樣的方法可以算出 P₉₀：I=20×0.9=18（整數），取第18、19筆的平均 (82+85)÷2=83.5。

觀察：I 不是整數的情況

如果要找 P₃₃ 呢？

I = 20 × (33/100) = 6.6　　（不是整數） 取大於6.6的下一個整數：7 P₃₃ = 由小到大排序的第7筆資料 = 65

大考中心實際計算全國考生百分等級的公式跟這裡略有不同（會再做一些微調），但核心精神一致：都是先把資料排序，再算出「這個分數贏過百分之幾的人」。

標準差

平均數一樣，代表兩家店表現一樣穩定嗎？

情境

飲料店打算加盟展店，想從「車站店」和「公園店」中選一家當示範店。兩家店最近5天的銷售杯數如下，平均都是每天48杯——但老闆問：「平均一樣，是不是代表兩家店表現一樣穩定？」

分店最近5天銷售杯數
車站店4448505246
公園店4647495048
觀察

兩家店的平均數確實都是48杯，但仔細看數字：車站店有44、52這種離48比較遠的天數；公園店的數字則都緊緊貼著48附近。光看平均數，完全看不出這個差異。

規律 → 公式

要用一個數字量化「資料離平均數有多分散」，作法是：先算出每筆資料與平均數的差（離均差），再取平方（避免正負互相抵消）、加總、除以個數，最後開根號拉回原本的單位。

變異數與標準差（資料 x₁,…,xₙ，平均數 μ）
變異數 σ² = [(x₁−μ)² + (x₂−μ)² + ⋯ + (xₙ−μ)²] ／ n
標準差 σ = √σ²

標準差越大，代表資料越分散；標準差越小，代表資料越集中、越穩定。

用一用
車站店：μ=48 離均差：−4, 0, 2, 4, −2 平方和：16+0+4+16+4 = 40 σ² = 40÷5 = 8　　σ = √8 = 2√2 ≈ 2.83（杯） 公園店：μ=48 離均差：−2, −1, 1, 2, 0 平方和：4+1+1+4+0 = 10 σ² = 10÷5 = 2　　σ = √2 ≈ 1.41（杯）

結論：雖然兩家店平均銷量相同，但公園店的標準差（≈1.41）比車站店（≈2.83）小很多，代表公園店的銷售更穩定——如果老闆想選一家「表現最可預期」的店當示範店，公園店會是更好的選擇。

數據的轉換與標準化

換算單位後，平均數和標準差會怎麼變？

情境：伸縮與平移

飲料店推出會員點數活動：「每消費1元累積2點，開幕禮再送50點」。也就是說，如果某位顧客消費金額是 x 元，他得到的點數是 y = 2x + 50。已知某天5位顧客的消費金額（元）分別是：

30, 50, 70, 90, 60

這5筆消費金額的平均數是60元、標準差是20元。換算成點數後，點數的平均數與標準差會變成多少？

觀察

直接算算看：5位顧客的點數分別是 y=2x+50 代入後得到 110, 150, 190, 230, 170。

點數平均 = (110+150+190+230+170)÷5 = 850÷5 = 170 點數的離均差：−60, −20, 20, 60, 0 平方和：3600+400+400+3600+0 = 8000 點數變異數 = 8000÷5 = 1600　　點數標準差 = √1600 = 40

比較一下：消費金額 μ=60 變成點數 μ=170；消費金額 σ=20 變成點數 σ=40。發現規律了嗎？170 = 2×60+50，跟 y=2x+50 的公式一模一樣；而 40 = 2×20，剛好是原本標準差乘上2（也就是乘上 x 前面的係數，且不受「+50」影響）。

規律 → 公式

這不是巧合。只要是「乘上一個數再加上一個數」這種線性轉換，資料的平均數和標準差都會照著規律變化：

伸縮與平移對 μ 與 σ 的影響
資料 x₁,…,xₙ，令 y_i = a·x_i + b（a≠0）
μ_y = a·μ_x + b　　　σ_y = |a|·σ_x

「平移」（加減一個常數 b）不會改變資料的分散程度，只會整批往同一個方向移動，所以標準差不受 b 影響；「伸縮」（乘上係數 a）則會把分散程度也跟著放大或縮小 |a| 倍，取絕對值是因為標準差不能是負的。

情境：標準化數據（Z分數）

筱葳這學期數學考了兩次段考：第一次段考全班平均70分、標準差10分，她考了82分；第二次段考全班平均75分、標準差15分，她考了90分。單看原始分數，第二次（90分）比第一次（82分）高，但這樣就能說她「這次考得比較好」嗎？

問題在於：兩次考試的難度、全班分布都不一樣，原始分數沒辦法直接比較——需要換算成「相對於全班的位置」才公平。

觀察 → 規律 → 公式

把每個分數換算成「贏過平均數幾個標準差」，這個換算後的數值叫做 Z分數（標準化數據）：

標準化（資料 x₁,…,xₙ，平均數 μ，標準差 σ）
Z = (x − μ) ／ σ
第一次段考：Z₁ = (82−70)÷10 = 1.2 第二次段考：Z₂ = (90−75)÷15 = 1.0

結論：雖然第二次段考的原始分數（90）比第一次（82）高，但用Z分數比較，第一次段考的 Z₁=1.2 大於第二次的 Z₂=1.0，代表她在第一次段考「相對於全班的表現」其實更突出——因為那次考試整體分數比較集中（標準差只有10），她的82分顯得更加拉開差距。

標準化之後的所有數據，平均數必為0、標準差必為1（可以驗證：把 x=μ 代入得 Z=0；把 μ_Z=(μ_x−μ)/σ=0、σ_Z=|1/σ|·σ_x=1 代入伸縮平移公式即可得證）。也因為如此，Z分數常用來比較「單位不同」或「難度不同」的兩組資料，例如不同科目、不同次考試的成績。

收進工具箱：3-1 一維數據分析

這一節的每個工具都是「用一個數字，描述一整組資料」的方法，接下來會反覆用到。

名稱內容
算術平均數μ=(x₁+x₂+⋯+xₙ)／n
加權平均數W=(x₁w₁+⋯+xₙwₙ)／(w₁+⋯+wₙ)
幾何平均數G=ⁿ√(x₁·x₂·⋯·xₙ)，用於成長率等連乘情境
百分位數I=n×(m/100)；I為整數取第I、I+1筆平均，否則取大於I的下一整數位置
變異數、標準差σ²=Σ(xᵢ−μ)²／n，σ=√σ²，衡量資料的離散程度
伸縮與平移y=ax+b ⟹ μ_y=aμ_x+b，σ_y=|a|σ_x

練習題

1加權平均數

飲料店某天賣出大杯（50元）20杯、中杯（45元）40杯、小杯（40元）40杯，求這天的加權平均客單價。

參考答案
(50×20+45×40+40×40)÷(20+40+40) =(1000+1800+1600)÷100=4400÷100=44（元）
2幾何平均數

某分店營業額連續兩年分別成長44%與69%，求這兩年的平均年成長率。

參考答案
(1+r)²=1.44×1.69=2.4336 1+r=√2.4336=1.56　　r=0.56=56%
3百分位數

某次模擬考共有25位同學，由小到大排序。求 P₈₀。

參考答案
I=25×0.8=20（整數），P₈₀取第20筆與第21筆資料的平均數（需視實際資料代入計算）。
4標準差

某分店連續4天銷售杯數為 50, 54, 46, 50，求這組資料的平均數與標準差。

參考答案
μ=(50+54+46+50)÷4=200÷4=50 離均差：0,4,−4,0　　平方和：0+16+16+0=32 σ²=32÷4=8　　σ=√8=2√2≈2.83
5標準化數據

已知某班數學平均分數60分、標準差12分，小明的Z分數是1.5，求小明的原始分數。

參考答案
Z=(x−μ)／σ 1.5=(x−60)／12 x−60=18　　x=78（分）
