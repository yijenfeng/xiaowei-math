數A 第三冊・第一章 三角函數・1-4

三角函數的疊合

校慶園遊會前，筱葳和同學要用推車把一塊長方形攤位底座推進校門，底座在推車上會轉來轉去。校門至少要多寬，底座才怎麼轉都過得去？這個問題的答案，藏在「兩個波相加還是一個波」的疊合技巧裡。這一節學會疊合，用它求最大最小值，最後替港口潮汐建立一個週期模型。情境例子為原創設計。

上一節的和角公式說：r・sin(x + φ) 可以展開成 sinx 與 cosx 的組合。這一節把它倒過來：遇到 a・sinx + b・cosx，就把它合成單一的 r・sin(x + φ)。一旦合成，振幅 r 就是最大值，問題立刻變簡單。這是學測三角函數最常考的技巧之一。

正餘弦的疊合

兩個波加起來，還是一個波

情境

攤位底座是長 4 公尺、寬 3 公尺的長方形，平放在推車上。從上往下看，底座的長邊和校門方向的夾角是 θ（0 ≤ θ ≤ π／2）。底座此時佔掉的寬度是多少？θ 怎麼轉，寬度最大？

把長邊、短邊分別投影到水平方向：長邊貢獻 4cosθ，短邊（和長邊垂直）貢獻 3sinθ，所以：

佔用寬度 W(θ) = 3sinθ + 4cosθ
觀察 → 規律：湊出和角公式

想把 3sinθ + 4cosθ 寫成 r・sin(θ + φ) = r・cosφ・sinθ + r・sinφ・cosθ，比較係數需要 r・cosφ = 3、r・sinφ = 4。兩式平方相加：

r² cos²φ + r² sin²φ = 3² + 4² ⟹ r² = 25 ⟹ r = 5 cosφ = 3／5，sinφ = 4／5 ∴ 3sinθ + 4cosθ = 5sin(θ + φ)，其中 φ 滿足 cosφ = 3／5、sinφ = 4／5
規律 → 公式
疊合公式（a、b 不同時為 0）
a・sinx + b・cosx = r・sin(x + φ)
其中 r = √(a² + b²)，cosφ = a／r，sinφ = b／r

一個很好用的推論：−√(a² + b²) ≤ a・sinx + b・cosx ≤ √(a² + b²)。所以底座最寬是 5 公尺——恰好是長方形的對角線長，轉到對角線和校門平行時發生。校門至少要 5 公尺寬。

用一用：漂亮的角度
√3 sinx + cosx：r = √(3 + 1) = 2，cosφ = √3／2，sinφ = 1／2 ⟹ φ = π／6 ∴ √3 sinx + cosx = 2sin(x + π／6) sinx − cosx：r = √2，cosφ = 1／√2，sinφ = −1／√2 ⟹ φ = −π／4 ∴ sinx − cosx = √2 sin(x − π／4)
最大值與最小值

先疊合，再看 x 的範圍

用一用：x 有範圍

若 0 ≤ x ≤ π／2，求 f(x) = √3 sinx + cosx 的最大值與最小值。

x 有範圍時，不能直接說最大值是 r。要先算出「括號裡的角」的範圍：

f(x) = 2sin(x + π／6) 0 ≤ x ≤ π／2 ⟹ π／6 ≤ x + π／6 ≤ 2π／3 在這段範圍內：sin 最大是 1（角 = π／2），最小是 1／2（角 = π／6） ∴ 最大值 2（x = π／3 時），最小值 1（x = 0 時）

畫出單位圓上 π／6 到 2π／3 那段弧，看 y 坐標的最高、最低點，就不會判斷錯。

另一型：化成二次函數

求 f(x) = cos2x + 2sinx 的最大值與最小值。

這題不能疊合（cos2x 和 sinx 的「頻率」不同）。改用二倍角把 cos2x 換成 sinx，再令 t = sinx：

f(x) = 1 − 2sin²x + 2sinx 令 t = sinx，−1 ≤ t ≤ 1 f = −2t² + 2t + 1 = −2(t − 1／2)² + 3／2 t = 1／2 時最大值 3／2 t = −1 時最小值 −2 − 2 + 1 = −3

判斷用哪一招：只有一次的 sinx、cosx（同一個 x）→ 疊合；出現平方或 2x → 用二倍角換成同一個函數，變成二次函數，記得 t 的範圍是 [−1, 1]。

週期性現象的模型

替潮汐寫一個公式

情境

園遊會結束後，筱葳跟家人到海邊的漁港。港口告示牌寫著：今天港內水深在凌晨 3 點最深、達 7 公尺，9 點最淺、只有 3 公尺，漲退大約每 12 小時重複一次。一艘漁船進港需要至少 6 公尺水深。一天之中，哪些時段可以安全進港？

把水深寫成 d(t) = a・cos(b(t − h)) + k（t 為午夜起算的小時數），一個一個讀出參數：

中心線 k = (7 + 3)／2 = 5 振幅 a = (7 − 3)／2 = 2 週期 12 ⟹ b = 2π／12 = π／6 最高點在 t = 3 ⟹ 用 cos 並讓 h = 3（cos 在角度 0 時最大） d(t) = 5 + 2cos(π(t − 3)／6)
用一用：解三角不等式
d(t) ≥ 6 ⟺ 2cos(π(t − 3)／6) ≥ 1 ⟺ cos(π(t − 3)／6) ≥ 1／2 cosθ ≥ 1／2 ⟺ −π／3 + 2kπ ≤ θ ≤ π／3 + 2kπ −π／3 ≤ π(t − 3)／6 ≤ π／3 ⟹ −2 ≤ t − 3 ≤ 2 ⟹ 1 ≤ t ≤ 5 再加一個週期 12：13 ≤ t ≤ 17 ∴ 凌晨 1:00～5:00、下午 13:00～17:00 可以安全進港
建模步驟整理
從資料寫出 y = a・cos(b(t − h)) + k
1. 中心線 k = (最大 + 最小)／2
2. 振幅 a = (最大 − 最小)／2
3. b = 2π／週期
4. 用 cos 時，h = 最大值發生的時刻；用 sin 時，h = 「從中心線往上爬」的時刻

真實潮汐週期大約是 12 小時 25 分，這裡為了好算取 12 小時。氣溫的年變化、白天長度、心跳血壓，都能用同樣的步驟建模。

收進工具箱：1-4 三角函數的疊合

疊合把兩項變一項；一項之後，最大最小值、週期、解不等式都回到 1-2 學過的單一正弦波。

名稱內容
疊合公式a・sinx + b・cosx = r・sin(x + φ)，r = √(a²+b²)，cosφ = a／r，sinφ = b／r
值域−√(a²+b²) ≤ a・sinx + b・cosx ≤ √(a²+b²)
有範圍的極值先求 x + φ 的範圍，再看 sin 在那段的最大、最小
二次型含 sin²、cos2x → 換成同一函數 t，t ∈ [−1, 1]，配方
週期模型k = (最大+最小)／2，a = (最大−最小)／2，b = 2π／週期

練習題

1疊合

把 sinx + √3 cosx 化成 r・sin(x + φ) 的形式（0 ≤ φ < 2π），並求最大值與最小值。

參考答案
r = √(1 + 3) = 2，cosφ = 1／2，sinφ = √3／2 ⟹ φ = π／3 sinx + √3 cosx = 2sin(x + π／3)，最大值 2，最小值 −2
2疊合

求 3sinx − 4cosx 的最大值與最小值。

參考答案
√(3² + (−4)²) = 5 ⟹ 最大值 5，最小值 −5
3有範圍的極值

0 ≤ x ≤ π，求 sinx + cosx 的最大值與最小值。

參考答案
sinx + cosx = √2 sin(x + π／4) 0 ≤ x ≤ π ⟹ π／4 ≤ x + π／4 ≤ 5π／4 sin 在此範圍：最大 1（角 = π／2），最小 −√2／2（角 = 5π／4） 最大值 √2（x = π／4），最小值 √2 × (−√2／2) = −1（x = π）
4二次型

求 f(x) = cos2x + 4sinx 的最大值與最小值。

參考答案
f = 1 − 2sin²x + 4sinx，令 t = sinx ∈ [−1, 1] f = −2t² + 4t + 1 = −2(t − 1)² + 3 頂點 t = 1 在範圍內 → 最大值 3 t = −1 離頂點最遠 → 最小值 −2 − 4 + 1 = −5
5週期模型

某港口水深（公尺）為 d(t) = 4 + 3sin(πt／6)，t 為午夜起算的小時數。求凌晨 1 點的水深，以及 0 ≤ t ≤ 12 之間水深至少 5.5 公尺的時段。

參考答案
d(1) = 4 + 3sin(π／6) = 4 + 1.5 = 5.5（公尺） d(t) ≥ 5.5 ⟺ sin(πt／6) ≥ 1／2 0 ≤ πt／6 ≤ 2π 中：π／6 ≤ πt／6 ≤ 5π／6 ⟹ 1 ≤ t ≤ 5 ∴ 凌晨 1:00 到 5:00
