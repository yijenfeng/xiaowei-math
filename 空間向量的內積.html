數A 第四冊・第一章 空間向量・1-3

空間向量的內積

燈光秀彩排時，導演要求兩道雷射光束在空中「剛好垂直交叉」，還要知道無人機爬升的仰角，才能決定觀眾席放哪裡。這些都是空間中的角度問題。這一節把 3A 的內積推廣到三維，學會求空間向量的夾角、方向餘弦、正射影，並用三維的柯西不等式求最大最小值。情境例子為原創設計。

3A 的內積有兩張臉：幾何上是 |a||b|cosθ，代數上是「對應分量相乘再相加」。兩者之所以相等，靠的是餘弦定理——而餘弦定理在空間中照樣成立。所以內積的所有性質，到了三維只要多加一項 z₁z₂ 就好。這一節的新內容只有一個：方向餘弦，用來描述一個向量和三條坐標軸各夾多少角度。

  • 1內積與夾角
  • 2方向餘弦
  • 3正射影
  • 4柯西不等式
內積與夾角

對應分量相乘再相加，多加一項而已

規律 → 公式
空間向量的內積（a = (x₁, y₁, z₁)，b = (x₂, y₂, z₂)）
a・b = |a||b|cosθ = x₁x₂ + y₁y₂ + z₁z₂
夾角：cosθ = (a・b)／(|a||b|)
垂直：a ⊥ b ⟺ x₁x₂ + y₁y₂ + z₁z₂ = 0

推導方式和 3A 一樣：把 |a − b|² 用餘弦定理和坐標各算一次，展開比較就得到。內積的交換律、分配律、|a ± b|² = |a|² ± 2a・b + |b|² 也全部照用。

情境：兩道雷射

舞台上的兩支雷射從同一點射出，方向分別是 u = (2, −1, 3) 與 v = (1, 5, 1)。它們垂直嗎？若把第二支改成 (1, k, 2)，k 要多少才會垂直？

u・v = 2 − 5 + 3 = 0 ⟹ 垂直 ✓ (2, −1, 3)・(1, k, 2) = 2 − k + 6 = 0 ⟹ k = 8
用一用：正方體裡的角度

邊長 1 的正方體，以一個頂點為原點、三條邊為坐標軸。從原點出發的「面對角線」(1, 1, 0) 與「體對角線」(1, 1, 1) 夾角的餘弦是多少？兩條相鄰面的面對角線 (1, 1, 0) 與 (1, 0, 1) 呢？

(1, 1, 0)・(1, 1, 1) = 2，長度 √2、√3 ⟹ cosθ = 2／√6 = √6／3 (1, 1, 0)・(1, 0, 1) = 1，長度都是 √2 ⟹ cosθ = 1／2 ⟹ θ = 60°

第二個結果用幾何也看得出來：三條面對角線的端點 (1,1,0)、(1,0,1)、(0,1,1) 兩兩距離都是 √2，連成正三角形，夾角當然是 60°。

方向餘弦

一個向量和三條坐標軸各夾幾度

情境

無人機從起降點沿 v = (2, 1, 2) 的方向爬升。它和正東（x 軸）、正北（y 軸）、正上方（z 軸）各夾多少角？爬升的仰角（和地面的夾角）是多少？

和 x 軸的夾角 α，就是 v 和 (1, 0, 0) 的夾角：cosα = (v・(1,0,0))／|v| = 2／3。另外兩個同理：

|v| = √(4 + 1 + 4) = 3 cosα = 2／3，cosβ = 1／3，cosγ = 2／3 仰角 = 90° − γ，sin(仰角) = cosγ = 2／3 ⟹ 仰角 ≈ 41.8°
方向角與方向餘弦
v = (a, b, c)：cosα = a／|v|，cosβ = b／|v|，cosγ = c／|v|
(cosα, cosβ, cosγ) 就是 v 方向的單位向量
cos²α + cos²β + cos²γ = 1

檢查：(2／3)² + (1／3)² + (2／3)² = 1 ✓。這條恆等式常用來「已知兩個方向角，求第三個」。

正射影

斜的向量，在某個方向上「實際走了多少」

規律 → 公式
a 在 b 上的正射影（與 3A 相同）
正射影向量 = ((a・b)／|b|²)b，正射影長 = |a・b|／|b|
情境

一陣風對無人機施加的力為 F = (1, 2, 3)（牛頓）。無人機正沿水平方向 d = (1, 1, 0) 前進。風力在前進方向上的分量是多少？

F・d = 1 + 2 + 0 = 3，|d|² = 2 正射影向量 = (3／2)(1, 1, 0) = (3／2, 3／2, 0) 正射影長 = 3／√2 = 3√2／2 ≈ 2.12（牛頓）——這部分順風在推它前進
柯西不等式

三個分量的版本

規律 → 公式

|cosθ| ≤ 1 ⟹ |a・b| ≤ |a||b|，平方後寫成坐標：

柯西不等式（三維）
(a₁b₁ + a₂b₂ + a₃b₃)² ≤ (a₁² + a₂² + a₃²)(b₁² + b₂² + b₃²)
等號成立 ⟺ (a₁, a₂, a₃) ∥ (b₁, b₂, b₃)
情境：最高能飛到哪

無人機被限制在以起降點為中心、半徑 9 公尺的球形範圍內（x² + y² + z² ≤ 81，這裡取邊界 = 81）。燈光評分公式是 x + 2y + 2z，分數最高是多少？此時無人機在哪裡？

(x + 2y + 2z)² ≤ (1² + 2² + 2²)(x² + y² + z²) = 9 × 81 = 729 ⟹ x + 2y + 2z ≤ 27 等號：(x, y, z) = t(1, 2, 2)，代入 9t² = 81 ⟹ t = 3（取正） 最高分 27，位置 (3, 6, 6)

幾何意義：在球面上找一點，使它在 (1, 2, 2) 方向上的正射影最長——答案當然是沿著這個方向直直走到球面。

收進工具箱：1-3 空間向量的內積

內積的公式和性質全部沿用 3A，只多一項 z₁z₂；新增方向餘弦，描述向量和三軸的夾角。

名稱內容
內積a・b = x₁x₂ + y₁y₂ + z₁z₂ = |a||b|cosθ
垂直a・b = 0
方向餘弦(a, b, c)／|v|；cos²α + cos²β + cos²γ = 1
仰角和 xy 平面的夾角 φ：sinφ = |c|／|v|
正射影((a・b)／|b|²)b
柯西不等式(Σaᵢbᵢ)² ≤ (Σaᵢ²)(Σbᵢ²)，平行時等號成立

練習題

1夾角

a = (1, −2, 2)，b = (3, 0, −4)，求兩向量夾角的餘弦值。

參考答案
a・b = 3 + 0 − 8 = −5，|a| = 3，|b| = 5 cosθ = −5 ／ 15 = −1／3
2垂直

(1, k, 2) 與 (3, −1, k) 垂直，求 k。

參考答案
3 − k + 2k = 0 ⟹ k = −3
3方向餘弦

求 v = (2, −3, 6) 的方向餘弦。

參考答案
|v| = 7 ⟹ (cosα, cosβ, cosγ) = (2／7, −3／7, 6／7)
4正射影

求 (2, 1, −1) 在 (1, 1, 1) 上的正射影向量。

參考答案
內積 = 2，|(1,1,1)|² = 3 ⟹ 正射影 = (2／3)(1, 1, 1) = (2／3, 2／3, 2／3)
5柯西不等式

實數 x、y、z 滿足 2x − y + 2z = 6，求 x² + y² + z² 的最小值與此時的 (x, y, z)。

參考答案
36 = (2x − y + 2z)² ≤ (4 + 1 + 4)(x² + y² + z²) ⟹ x² + y² + z² ≥ 4 等號：(x, y, z) = t(2, −1, 2)，9t = 6 ⟹ t = 2／3 最小值 4，(x, y, z) = (4／3, −2／3, 4／3)

下一步：找一個同時垂直兩個向量的方向

舞台上的布幕是一個平面，燈光師想從正面（垂直布幕）打光。已知布幕上兩個方向，怎麼找出垂直它們的方向？內積只能「檢查」垂直，不能直接「造出」垂直。在 1-4「外積、體積與行列式」，我們會學到一種新的向量乘法——外積，它直接造出垂直向量，還順便算出面積與體積。
