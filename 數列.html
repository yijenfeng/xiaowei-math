數列

用筱葳自己的「半馬訓練計畫」與社團「迎新影片」的分享數，認識數列的定義、等差數列、等比數列、遞迴數列，以及數學歸納法。情境例子為原創設計。

暑假快結束了，筱葳決定挑戰人生第一場半程馬拉松，教練幫她排了訓練計畫；同時，她也在社團裡負責拍攝迎新影片，正緊張地盯著分享數字往上跳。這兩件事看似無關，其實都藏著同一種數學結構——把數字按照順序排成一列，就是這一節要介紹的「數列」。

數列的定義

把數字按順序排成一列

情境

社團學期末要選出「最佳幹部」，依過去6次社課的簽到人數決定：18, 20, 20, 23, 25, 25（依序是第1次到第6次社課）。筱葳想跟教練報告的時候說得精確一點，於是把「第幾次社課」跟「簽到人數」對應起來記錄。

像這樣把一群數依照固定的順序排成一列，就是數列。每個位置上的數叫做這個數列的項，若共有6項，就依序記作 a₁, a₂, a₃, a₄, a₅, a₆——這裡 a₁=18（稱為首項），a₆=25。

觀察 → 規律 → 公式

因為簽到人數只記錄了6次，這是一個有限數列，項數為6。如果換成「訓練計畫第n週的目標里程」，理論上可以一直排下去（第1週、第2週、……沒有終點），這種數列就叫做無窮數列，記作：

數列的一般表示法
a₁, a₂, a₃, …, aₙ, …

其中 a₁ 是首項，第 n 項 aₙ 叫做這個數列的一般項——只要知道一般項的公式（用 n 表示的式子），就能算出數列中任何一項。

用一用

如果一個數列的一般項是 aₙ = 4n − 3，寫出前5項；如果一般項是 aₙ = (−1)ⁿ⁺¹ · 1／(2n)，也寫出前5項。

aₙ = 4n−3：n=1,2,3,4,5 代入 → 1, 5, 9, 13, 17 aₙ = (−1)ⁿ⁺¹ · 1／(2n)：n=1,2,3,4,5 代入 → 1/2, −1/4, 1/6, −1/8, 1/10

第二個例子中 (−1)ⁿ⁺¹ 會讓正負號交替出現——這種數列稱為「交錯數列」，n為奇數時整體為正、n為偶數時整體為負。

等差數列

每次都多跑固定的距離

情境

教練幫筱葳排了10週的訓練計畫：第1週先跑5公里當作暖身，之後每一週的「長距離訓練」都比前一週多跑2公里，直到第10週練到接近正式比賽的距離。

第1週：5　第2週：7　第3週：9　第4週：11　……

每一項跟前一項的差，都固定是同一個數（這裡是+2公里），這樣的數列就叫做等差數列，這個固定的差叫做公差，通常用 d 表示。

規律 → 公式

設首項為 a₁、公差為 d，數列就是 a₁, a₁+d, a₁+2d, a₁+3d, …——第 n 項比首項多加了 (n−1) 次公差：

等差數列的一般項
aₙ = a₁ + (n−1)d

套進訓練計畫：a₁=5，d=2，所以第 n 週的長跑距離是 aₙ = 5+(n−1)·2 = 2n+3。驗算第10週：a₁₀=2×10+3=23，跟原本規劃的一致。

用一用：反推公差與首項

筱葳的隊友只記得自己訓練計畫的第3週跑9公里、第8週跑19公里，且知道整個計畫是等差數列，請幫她找出首項與公差，並寫出一般項。

設首項 a₁、公差 d： a₃ = a₁+2d = 9 … ① a₈ = a₁+7d = 19 … ② ② − ①：5d = 10　→　d = 2 代入①：a₁ = 9−2×2 = 5 一般項：aₙ = 5+(n−1)×2 = 2n+3

結果跟筱葳自己的計畫完全一樣——兩人其實用的是同一套訓練表！只要知道等差數列中任兩項，就能用聯立方程式解出首項與公差，進而寫出整個數列的一般項。

等比數列

每次都變成前一次的固定倍數

情境

筱葳幫社團剪了一支迎新影片，上傳後緊張地每天回來看分享數：第1天有3人分享，之後每天的分享數都變成前一天的3倍（同學越傳越開，呈現病毒式擴散）。

第1天：3　第2天：9　第3天：27　第4天：81　第5天：243

這裡每一項跟前一項的「比值」固定是同一個數（這裡是×3），這樣的數列叫做等比數列，這個固定的比值叫做公比，通常用 r 表示。

規律 → 公式

設首項為 a₁、公比為 r（r≠0），數列就是 a₁, a₁r, a₁r², a₁r³, …——第 n 項是首項連乘了 (n−1) 次公比：

等比數列的一般項
aₙ = a₁ · rⁿ⁻¹

套進分享數：a₁=3，r=3，所以第 n 天的分享數是 aₙ = 3·3ⁿ⁻¹ = 3ⁿ。驗算第5天：a₅=3⁵=243，跟原本記錄的一致。

用一用：反推公比與首項

另一個社團的貼文，只知道第2天分享數是18、第5天分享數是486，且確定是等比數列，請找出首項、公比與一般項。

設首項 a₁、公比 r： a₂ = a₁r = 18 … ① a₅ = a₁r⁴ = 486 … ② ② ÷ ①：r³ = 27　→　r = 3 代入①：a₁ = 18÷3 = 6 一般項：aₙ = 6·3ⁿ⁻¹

如果題目給的是 aₙ 的偶數次方比（例如 a₂ 與 a₄ 的比），開根號時要記得正負兩種可能的公比都要考慮——這是等比數列最容易被扣分的地方。

遞迴數列

用「前一項」定義「這一項」

情境

仔細想想，「每週比前一週多跑2公里」「每天變成前一天的3倍」這兩句話，其實都是在說：下一項可以用「前一項」加減乘除算出來，不需要另外硬記一個跟 n 有關的公式。這種「用初始值＋前後項關係」定義的數列，叫做遞迴數列。

觀察 → 規律 → 公式

一般的遞迴數列，是先給出首項 a₁=a，再給出一條規則，說明 aₙ 要怎麼從 aₙ₋₁ 算出來（n≥2）。前面兩個情境剛好對應兩種最基本的類型：

兩種基本遞迴型式
等差型：a₁=a，aₙ=aₙ₋₁+d（n≥2） ——半馬計畫：a₁=5，aₙ=aₙ₋₁+2
等比型：a₁=a，aₙ=r·aₙ₋₁（n≥2） ——分享數：a₁=3，aₙ=3aₙ₋₁

但遞迴關係其實可以更複雜——不一定是「固定加」或「固定乘」，這時就沒辦法直接套等差、等比的公式，必須換一種方法找出一般項。

情境：疊杯挑戰

社課園遊會，筱葳的攤位在玩「疊杯挑戰」：把杯子疊成三角形的金字塔，最上面一層放1個杯子，第2層要比上一層「多疊2個」（也就是放2個），第3層要比上一層「多疊3個」（放3個），依此類推——第 n 層要比第 (n−1) 層多放 n 個杯子。設 aₙ 為疊到第 n 層為止，總共用掉的杯子數，請問 a₅ 是多少？有沒有辦法不用一層一層數，就直接算出 a₁₀？

觀察 → 規律

把「總杯數」的遞迴關係寫下來：a₁=1，且第 n 層比第 (n−1) 層多用 n 個杯子，所以 aₙ = aₙ₋₁ + n（n≥2）。逐項算出來：

a₁ = 1 a₂ = a₁+2 = 3 a₃ = a₂+3 = 6 a₄ = a₃+4 = 10 a₅ = a₄+5 = 15

把 1, 3, 6, 10, 15 這幾個數字跟 n 對照看看，會發現一個規律：a₁=1×2/2，a₂=2×3/2，a₃=3×4/2，a₄=4×5/2，a₅=5×6/2——每一項都等於「n×(n+1)÷2」！猜測一般項是：

猜測的一般項
aₙ = n(n+1) ／ 2

照這個公式，a₁₀ = 10×11÷2 = 55，不用真的疊到第10層去數。但這只是從5個例子「觀察」出來的規律，還沒有證明對所有的 n 都成立——這正是下一個主題「數學歸納法」要解決的事。

數學歸納法

怎麼證明一個對「所有」n 都成立的規律？

情境

觀察5層、甚至觀察100層，都沒辦法保證第100萬層也一定符合 aₙ=n(n+1)/2——畢竟「觀察到目前為止都對」不等於「證明了以後永遠都對」。需要一種方法，一次證明「對所有正整數 n 都成立」。

想像一整排骨牌：只要確定「第1張骨牌會倒」，並且確定「只要前一張倒了、下一張就一定會跟著倒」，那麼不管骨牌排多長，最後全部都會倒下去。數學歸納法就是把這個想法應用在證明數學規律上。

規律 → 原理
數學歸納法原理
若一個與正整數 n 有關的命題 P(n) 滿足：
(1) 基礎步驟：P(1) 成立；
(2) 歸納步驟：假設 P(k) 成立（k為任意正整數），可以推得 P(k+1) 也成立；
則 P(n) 對所有正整數 n 都成立。

套用到骨牌：(1) 就是「第1張會倒」，(2) 就是「前一張倒、下一張就跟著倒」——兩者都成立，骨牌才會一路倒到底。

用一用：證明疊杯公式

用數學歸納法證明：疊杯挑戰中 a₁=1、aₙ=aₙ₋₁+n（n≥2）所定義的數列，一般項是 aₙ = n(n+1)／2，對所有正整數 n 都成立。

(1) 基礎步驟（n=1）： a₁=1，且 1×2÷2=1，兩者相等，P(1) 成立。 (2) 歸納步驟：假設 n=k 時成立，即 a_k = k(k+1)／2 ……① 要證明 n=k+1 時也成立，即 a_(k+1) = (k+1)(k+2)／2 由遞迴關係：a_(k+1) = a_k + (k+1) = k(k+1)／2 + (k+1)　　（代入①） = (k+1)・(k／2 + 1) = (k+1)(k+2)／2　　　（化簡） 這正是 n=k+1 時應該有的形式，所以 P(k+1) 成立。

由 (1)(2) 可知，根據數學歸納法，aₙ = n(n+1)／2 對所有正整數 n 都成立——這下就能放心地說，疊到第100層總共會用 100×101÷2=5050 個杯子，完全不用真的排排看。

數學歸納法的關鍵在歸納步驟：一定要「假設 n=k 成立」當作已知條件，再想辦法從遞迴關係「推出」n=k+1 也成立，而不是直接把 n=k+1 代進猜測的公式驗算一次——那樣只是再驗證一個例子，並不是證明。

收進工具箱：1-1 數列

這一節建立了描述「一列數字」的四種語言，之後在 1-2 級數會反覆用到它們的一般項公式。

名稱內容
數列a₁,a₂,…,aₙ,…（有限／無窮），aₙ稱為一般項
等差數列公差d固定；aₙ=a₁+(n−1)d
等比數列公比r≠0固定；aₙ=a₁・rⁿ⁻¹
遞迴數列a₁=a，用aₙ₋₁定義aₙ（n≥2）
數學歸納法(1) 驗證n=1成立　(2) 假設n=k成立，推出n=k+1成立

練習題

1等差數列

某數列為等差數列，a₁=8，公差d=3，求 a₁₂。

參考答案
a₁₂ = a₁+(12−1)d = 8+11×3 = 8+33 = 41
2等比數列

某等比數列 a₂=6，a₄=54，求公比 r 與首項 a₁（提示：注意 r 可能有兩種答案）。

參考答案
a₄／a₂ = r² = 54／6 = 9　→　r = 3 或 r = −3 若 r=3：a₁ = 6÷3 = 2 若 r=−3：a₁ = 6÷(−3) = −2 兩組答案：(a₁,r)=(2,3) 或 (−2,−3)
3遞迴數列與觀察規律

數列滿足 a₁=1，aₙ=aₙ₋₁+2n（n≥2）。先求出 a₂,a₃,a₄,a₅，觀察規律猜出一般項公式，再求 a₆。

參考答案
a₂=1+4=5　a₃=5+6=11　a₄=11+8=19　a₅=19+10=29 觀察：1,5,11,19,29 對照 n²+n−1： n=1:1　n=2:5　n=3:11　n=4:19　n=5:29　　完全吻合！ 猜測一般項：aₙ = n²+n−1 驗算 a₆ = 6²+6−1 = 41（也可直接用遞迴：a₆=a₅+12=29+12=41，一致）
4數學歸納法

用數學歸納法證明：a₁=2，aₙ=3aₙ₋₁+2（n≥2）所定義的數列，一般項為 aₙ=3ⁿ−1，對所有正整數 n 都成立。

參考答案
(1) n=1：a₁=2，且 3¹−1=2，兩者相等，成立。 (2) 假設 n=k 成立：a_k = 3^k−1 ……① n=k+1：a_(k+1) = 3a_k+2 = 3(3^k−1)+2　　（代入①） = 3^(k+1)−3+2 = 3^(k+1)−1 正是 n=k+1 該有的形式，故 P(k+1) 成立。 由(1)(2)，根據數學歸納法，aₙ=3ⁿ−1 對所有正整數n成立。
5數列的定義／觀察規律

一數列前5項為 4, 7, 12, 19, 28，觀察規律寫出一般項公式，並求第6項。

參考答案
觀察：每項減去3後，依序是 1,4,9,16,25，恰為 n² ！ 即 aₙ−3 = n²　→　aₙ = n²+3 驗算：n=1:4　n=2:7　n=3:12　n=4:19　n=5:28　　吻合 第6項：a₆ = 6²+3 = 39
