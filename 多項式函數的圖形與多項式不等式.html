三次函數的圖形

蓄水池水位，原來先升、微降，再升

情境

回到 3-1 的蓄水池模型 f(t)=2t³−9t²+12t−4（t：從早上8點起算的小時數）。物業想把整段時間的水位變化畫成一條曲線，看看到底是怎麼升降的。

觀察

先列出幾個時間點的水位：

t（小時）00.511.5234
f(t)（公分）−4010.50528

對照數字會發現：從 t=0 到 t=1，水位一路上升（−4 → 1）；但 t=1 到 t=2，水位竟然「回降」了一點（1 → 0.5 → 0）；t=2 之後才又重新爬升。三次函數的圖形，就可能出現這種「升、降、再升」的波浪狀。

規律 → 公式：圖形的平移寫法

就像二次函數可以配方成 a(x−h)²+k，三次函數 f(x)=ax³+bx²+cx+d 也可以整理成「平移後」的形式：

f(x) = a(x−h)³ + p(x−h) + k　，其中 h = −b／3a

把 f(t)=2t³−9t²+12t−4 的 a=2, b=−9 代入：h = −(−9)／(3×2) = 1.5。整理後（過程略）可以得到：

f(t) = 2(t−1.5)³ − 1.5(t−1.5) + 0.5

這代表 f(t) 的圖形，是把 y=2t³ 的圖形平移調整後的結果；圖形以「反曲點」 (1.5, 0.5) 為中心，呈點對稱——這也是為什麼表格中 t=1 和 t=2 的水位（1 和 0）會對稱地分布在 t=1.5 兩側。

因為 a=2>0 且 p=−1.5<0，這組合對應「有局部極值」的波浪形（先升、中間有小段下降、再升）；如果 a、p 同號（或 p=0），圖形則會是「一路上升（或一路下降）沒有波浪」的單調曲線。

用一用

曲線 y=x³−3x 的圖形，屬於「一路單調」還是「有波浪起伏」？

已經是 y=ax³+px 的形式：a=1>0, p=−3<0

a、p 異號，屬於有波浪起伏（有局部極大、極小）的類型。

多項式函數圖形的大域特徵

如果時間一直過下去，水位模型會怎麼走？

情境

維修工程師知道模型 f(t)=2t³−9t²+12t−4 只在 0≤t≤5 這段時間內有意義。但單純從數學式來看：如果放任 t 一直增加，這個式子的「走勢」會是什麼樣子？

觀察 → 規律

當 |t| 非常大時，多項式裡「次數最高的那一項」會遠遠蓋過其他項的影響——就像 2t³ 在 t=100 時是 2,000,000，而 −9t²、12t、−4 加起來也不過幾萬，完全不成比例。所以判斷多項式函數「兩端」的走勢，只要看最高次項的次數與係數正負：

函數類型x→+∞x→−∞
常數函數 f(x)=c保持水平 c保持水平 c
一次函數，a>0持續上升持續下降
二次函數，a>0上升（開口向上）上升（開口向上）
二次函數，a<0下降（開口向下）下降（開口向下）
三次函數，a>0持續上升持續下降
三次函數，a<0持續下降持續上升

蓄水池模型 f(t)=2t³−9t²+12t−4 是三次多項式，首項係數 2>0：數學上，t 越來越大時 f(t) 會一路衝高——當然，這已經超出「0到5小時」這個模型原本設計的有效範圍，只是數學式本身的走勢。

用一用

y=−3x³+2x²−x+5 的圖形，當 x→+∞ 與 x→−∞ 時各朝什麼方向走？

三次函數，首項係數 −3<0：x→+∞ 時圖形下降（→−∞），x→−∞ 時圖形上升（→+∞）。

一次不等式與二次不等式

煙火要飛多高，才算「安全高度」？

情境：一次不等式

在正式建立三次模型之前，工程師先用一個簡化的一次函數估計水位趨勢：g(t)=3t−6。水位偏差「轉為正值」（回到標準線以上）大概是哪個時間之後？

3t−6 > 0 3t > 6 t > 2

跟移項解一次方程式的手法一樣——只差在不等式兩邊「同乘或同除一個負數」時，不等號方向要反過來。

情境：二次不等式

社區跨年晚會施放煙火，煙火升空的高度（公尺）模型為 H(t)=−5t²+30t（t：秒）。地面安全人員規定，煙火高度必須達到40公尺以上才算飛到安全高度，請問是在第幾秒到第幾秒之間？

觀察 → 規律 → 公式

要解的不等式是 −5t²+30t≥40，先移項成右邊為0：

−5t²+30t−40 ≥ 0 　　（兩邊同除以 −5，不等號反向） t²−6t+8 ≤ 0 (t−2)(t−4) ≤ 0

畫出 y=(t−2)(t−4) 這條開口向上的拋物線：跟 t 軸交於 t=2 與 t=4，在兩根之間函數值為負（含等於0），兩根之外為正。

所以 2≤t≤4：煙火在第2秒到第4秒之間，高度都在40公尺以上。驗算：H(2)=−20+60=40，H(4)=−80+120=40，H(3)=−45+90=45（確實超過40）。

用一用

解不等式 x²−5x+6<0。

x²−5x+6=(x−2)(x−3)<0 兩根之間為負：2 < x < 3
高次不等式

蓄水池水位，什麼時候不低於標準線？

情境

回到蓄水池模型，3-1 已經把它完全分解：f(t)=(t−2)²(2t−1)。物業想知道：從早上8點開始，水位「不低於」標準線（f(t)≥0）的時段是什麼時候？

觀察 → 規律：穿根法

高次多項式不等式的解法，是把每個一次因式的正負號分開來看，列成一張「符號表」：

區間t<0.50.5<t<2t>2
2t−1−++
(t−2)²+++
f(t)=(t−2)²(2t−1)−++

要特別注意：(t−2)² 是「平方」，不管 t 取什麼值都不會是負的——這種「偶數次」的重根，經過該點時不會變號；只有像 (2t−1) 這種「奇數次」（這裡是1次）的因式，經過根的地方才會變號。這也解釋了為什麼 t=2 只是圖形「碰到」t軸，而 t=0.5 才是真正「穿越」t軸。

公式

由符號表，f(t)≥0 的解是 t≥0.5（含 t=0.5 和 t=2 兩個等號成立的點）。對照這一節有效範圍 0≤t≤5，答案是：

上午8:30（t=0.5）之後，水位就不再低於標準線
用一用

解不等式 (x+1)(x−2)(x−5)<0。

三個根：x=−1, 2, 5（都是一次，奇數次，每個根都變號） 符號表： x<−1：(−)(−)(−) = − −1<x<2：(+)(−)(−) = + 2<x<5：(+)(+)(−) = − x>5：(+)(+)(+) = + 小於0的區間：x<−1 或 2<x<5

練習題

1三次函數圖形

曲線 y=x³+4x 的圖形，屬於單調還是有波浪起伏？

參考答案
a=1，p=4，同號（都為正）→ 單調遞增，沒有局部極值。
2大域特徵

y=4x²−x+1 的圖形，當 x→+∞ 和 x→−∞ 時走勢各是如何？

參考答案
二次函數，首項係數 4>0（開口向上），x→+∞ 和 x→−∞ 時，圖形都上升（y→+∞）。
3一次不等式

解不等式 5x−15≤0。

參考答案
5x ≤ 15 x ≤ 3
4二次不等式

解不等式 x²+x−12≥0。

參考答案
(x+4)(x−3) ≥ 0
解：x≤−4 或 x≥3
5高次不等式

解不等式 (x−1)(x+3)²≤0。

參考答案
(x+3)² 是偶數次重根，恆為正或0，不影響變號；只有 (x−1) 這個一次因式決定正負。整個式子在 x≤1 時恆為負或0（在 x=−3 處也恰好等於0）。
解：x ≤ 1
