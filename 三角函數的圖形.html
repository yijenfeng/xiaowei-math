三角函數的圖形

高二校外教學去遊樂園，筱葳搭上一座大摩天輪，一邊轉一邊用手機記錄座艙離地多高。回家把數據畫出來，她看到一條一模一樣的波浪不斷重複。這一節從單位圓出發，把 sin、cos、tan 變成以實數為輸入的函數，畫出它們的圖形，並學會讀出振幅、週期與平移。情境例子為原創設計。

數學2學的三角比，是「給一個角，算一個比值」。有了弧度，角就是一個實數，於是 sinx 可以像 x² 一樣，看成一個「輸入 x、輸出 sinx」的函數。三角函數最大的特色是週期性：轉一圈回到原位，函數值就重來一次。生活中所有「一圈一圈重複」的現象——摩天輪、潮汐、晝夜長短、聲波——背後都是這幾條曲線。

單位圓與三角函數

在單位圓上走，x 坐標是 cos，y 坐標是 sin

情境

把摩天輪縮小成半徑 1 的圓，圓心放在原點。座艙從 (1, 0) 出發，逆時針轉了 x 弧度後到達點 P。P 的坐標是什麼？

這正是數學2「廣義角三角比」的定義：在單位圓上，轉了角度 x 之後的點 P 坐標就是 (cosx, sinx)。現在 x 可以是任何實數——轉 10 弧度、轉 −3 弧度都可以，所以：

三角函數（x 為弧度，可以是任意實數）
P(x) = (cosx, sinx)
tanx = sinx／cosx（cosx ≠ 0）
觀察 → 規律：週期性

多轉一整圈（2π），座艙回到同一個位置，坐標完全一樣：

sin(x + 2π) = sinx　　cos(x + 2π) = cosx 更一般：sin(x + 2kπ) = sinx，k 為任意整數

如果一個函數滿足 f(x + p) = f(x) 對所有 x 都成立，就說 f 是週期函數，最小的正數 p 叫做週期。sin 與 cos 的週期都是 2π。

因為 P 在單位圓上，坐標一定在 −1 到 1 之間：−1 ≤ sinx ≤ 1，−1 ≤ cosx ≤ 1。這兩個不等式是之後求最大值、最小值的出發點。

振幅、週期與平移

把波浪拉高、壓扁、搬家

觀察 → 規律：伸縮

比較三條曲線：y = sinx、y = 2sinx、y = sin2x。

y = 2sinx：每個函數值都乘 2 → 上下拉高，最高 2、最低 −2，週期不變 y = sin2x：x 只要走到 π，2x 就走完 2π → 左右壓扁，週期變成 π，高度不變
規律 → 公式
y = a・sin(bx + c) + d（a、b ≠ 0）
振幅 = |a|　　週期 = 2π／|b|
中心線 y = d；最大值 d + |a|，最小值 d − |a|
c 讓圖形左右平移（cos 的情形完全相同）

記法：乘在外面的 a 管高低（振幅），乘在 x 上的 b 管快慢（週期），加在外面的 d 管整條波的上下位置。

情境：摩天輪的高度

遊樂園的摩天輪半徑 40 公尺，轉軸離地 45 公尺，轉一圈要 20 分鐘。筱葳從最低點上車，t 分鐘後座艙離地多高？

每分鐘轉 2π／20 = π／10 弧度，所以 t 分鐘轉了 πt／10。從最低點出發，座艙相對轉軸的高度是 −40cos(πt／10)（t = 0 時為 −40，剛好在最下面）：

摩天輪高度模型
h(t) = 45 − 40cos(πt／10)
振幅 = 40（半徑）　中心線 h = 45（轉軸高度） 週期 = 2π ÷ (π／10) = 20 分鐘　✓ 最高 45 + 40 = 85 公尺（t = 10） 最低 45 − 40 = 5 公尺（t = 0、20、40……） t = 5 時：h = 45 − 40cos(π／2) = 45（剛好與轉軸一樣高）
正切函數的圖形

tan 沒有上限，而且每隔 π 就斷一次

情境

回程經過海邊的燈塔。燈塔離筆直的海岸線 1 公里，探照燈從「正對海岸」的方向開始轉，轉了 x 弧度時，光點打在海岸上的位置，距離正對點多遠？

燈塔、正對點、光點構成直角三角形，鄰邊 1 公里，所以光點距離 = tanx 公里。x 越接近 π／2，光束越接近和海岸平行，光點就跑得越遠：

x = π／4　→　tanx = 1（1 公里） x = π／3　→　tanx = √3 ≈ 1.73 x = 1.5　 →　tanx ≈ 14.1 x = π／2　→　光束和海岸平行，永遠打不到：tan(π／2) 沒有定義
整理性質
y = tanx 的性質
定義域：x ≠ π／2 + kπ（k 為整數）
值域：全體實數（沒有最大、最小值）
週期 = π（不是 2π！）；y = tan(bx) 的週期為 π／|b|
對稱於原點：tan(−x) = −tanx

為什麼週期是 π？點 P 轉半圈到對面，sin 和 cos 同時變號，比值 sin／cos 不變：tan(x + π) = (−sinx)／(−cosx) = tanx。

收進工具箱：1-2 三角函數的圖形

看到 y = a・sin(bx + c) + d，先讀出振幅 |a|、週期 2π／|b|、中心線 y = d，圖形就畫得出來。

名稱內容
單位圓定義轉 x 弧度後的點 P = (cosx, sinx)
sin、cos 的週期2π；值域 [−1, 1]

練習題

1讀圖形參數

求 y = 3sin2x − 1 的振幅、週期、最大值與最小值。

參考答案
振幅 3，週期 2π／2 = π 最大值 −1 + 3 = 2，最小值 −1 − 3 = −4
2讀圖形參數

求 y = −2cos(x／2) + 1 的週期與值域。

參考答案
週期 = 2π ÷ (1／2) = 4π 振幅 |−2| = 2，中心線 y = 1 → 值域 −1 ≤ y ≤ 3

a 是負的只代表圖形上下翻轉，振幅仍取絕對值。

3摩天輪模型

另一座摩天輪半徑 30 公尺，轉軸離地 35 公尺，轉一圈 15 分鐘，從最低點上車。寫出 t 分鐘後的高度 h(t)，並求 t = 5 時的高度。

參考答案
每分鐘轉 2π／15 弧度 h(t) = 35 − 30cos(2πt／15) t = 5：h = 35 − 30cos(2π／3) = 35 − 30 × (−1／2) = 50（公尺）
4正切

求 y = tan3x 的週期，並寫出它的鉛直漸近線。

參考答案
週期 = π／3 3x = π／2 + kπ 時沒有定義 → 漸近線 x = π／6 + kπ／3（k 為整數）
5比較大小

不用計算機，比較 sin1、sin2、sin3 的大小。

參考答案
利用 sinx = sin(π − x)（圖形對稱於 x = π／2）： sin2 = sin(π − 2) ≈ sin1.14 sin3 = sin(π − 3) ≈ sin0.14 0.14 < 1 < 1.14 都在 0 到 π／2 之間，sin 在此遞增 ∴ sin3 < sin1 < sin2
