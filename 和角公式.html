數A 第三冊・第一章 三角函數・1-3

和角公式

在摩天輪上，筱葳發現一件有趣的事：不管轉到哪裡，她和隔壁座艙之間的直線距離永遠不變。這個「只跟兩者夾角有關」的觀察，正好能推出三角函數最重要的一組公式——和角公式。這一節從它出發，一路推到正切的和差角、二倍角與半角公式。情境例子為原創設計。

sin30°、sin45° 背得出來，那 sin75° 呢？75° = 45° + 30°，但 sin75° 絕對不是 sin45° + sin30°（那會超過 1）。三角函數不能「分配」進括號裡，我們需要真正的拆法。和角公式就是這把鑰匙：只要知道兩個角各自的 sin、cos，就能算出它們相加或相減之後的值。二倍角、半角公式都是它的直接推論。

正弦與餘弦的和差角

兩個座艙的距離，只看它們差了多少角度

情境

把摩天輪當成單位圓。筱葳的座艙 P 在角度 α 的位置，隔壁座艙 Q 在角度 β 的位置。摩天輪轉動時，P、Q 一起轉，兩者的直線距離不變。把整個輪子倒轉 β，讓 Q 轉回 (1, 0)，P 就轉到角度 α − β 的位置。

同一段距離，用兩種坐標各算一次：

轉之前：P(cosα, sinα)，Q(cosβ, sinβ) PQ² = (cosα − cosβ)² + (sinα − sinβ)² = (cos²α + sin²α) + (cos²β + sin²β) − 2(cosα cosβ + sinα sinβ) = 2 − 2(cosα cosβ + sinα sinβ) 轉之後：P'(cos(α−β), sin(α−β))，Q'(1, 0) P'Q'² = (cos(α−β) − 1)² + sin²(α−β) = 2 − 2cos(α−β) 兩者相等 ⟹ cos(α−β) = cosα cosβ + sinα sinβ
規律 → 公式：一口氣推出四條

有了 cos(α−β)，把 β 換成 −β（cos(−β) = cosβ，sin(−β) = −sinβ）就得到 cos(α+β)；再利用 sinθ = cos(π／2 − θ)，就能推出 sin 的兩條：

和差角公式
sin(α ± β) = sinα cosβ ± cosα sinβ
cos(α ± β) = cosα cosβ ∓ sinα sinβ

口訣：sin 是「sin cos、cos sin，符號照抄」；cos 是「cos cos、sin sin，符號相反」。

用一用
sin75° = sin(45° + 30°) = sin45° cos30° + cos45° sin30° = (√2／2)(√3／2) + (√2／2)(1／2) = (√6 + √2)／4 ≈ 0.966 cos15° = cos(45° − 30°) = cos45° cos30° + sin45° sin30° = (√6 + √2)／4　← 和 sin75° 一樣，因為 15° + 75° = 90°
正切的和差角

用斜率算兩條路的夾角

規律 → 公式

tan = sin／cos，把上面兩條相除，分子分母同除以 cosα cosβ：

正切的和差角公式
tan(α ± β) = (tanα ± tanβ)／(1 ∓ tanα tanβ)
情境

單車社的路線圖畫在坐標方格上：A 路的斜率是 3，B 路的斜率是 1／2，兩條路在一個路口交叉。轉彎時車頭要轉多少度？

直線斜率 = tan（斜角）。設 tanα = 3、tanβ = 1／2，兩路夾角就是 α − β：

tan(α − β) = (3 − 1／2)／(1 + 3 × 1／2) = (5／2)／(5／2) = 1 ∴ α − β = 45°，兩條路的夾角是 45°

這個做法可以推廣成「兩直線夾角」的公式：斜率 m₁、m₂ 的兩直線，夾角 θ 滿足 tanθ = |(m₁ − m₂)／(1 + m₁m₂)|。若 1 + m₁m₂ = 0，代表兩直線垂直。

二倍角公式

α = β 時，和角公式變成二倍角

規律 → 公式

在和角公式裡令 β = α：

二倍角公式
sin2θ = 2sinθ cosθ
cos2θ = cos²θ − sin²θ = 2cos²θ − 1 = 1 − 2sin²θ
tan2θ = 2tanθ／(1 − tan²θ)

cos2θ 的三種寫法都要熟：題目給 cosθ 就用 2cos²θ − 1，給 sinθ 就用 1 − 2sin²θ，不必再去求另一個。

情境：投多遠？

體育課測壘球擲遠。物理老師說：若不計空氣阻力、出手點與落地點同高，以初速 v、仰角 θ 拋出，水平射程 R = (2v² sinθ cosθ)／g。筱葳出手速度約 20 公尺／秒（g 取 10），仰角幾度投得最遠？

R = (2v² sinθ cosθ)／g = v² sin2θ／g sin2θ 最大是 1，發生在 2θ = 90°，即 θ = 45° 最遠射程 = 20² × 1 ÷ 10 = 40（公尺） 若仰角 30°：R = 40 × sin60° = 20√3 ≈ 34.6（公尺） 若仰角 60°：R = 40 × sin120° = 20√3 ≈ 34.6（公尺）——一樣遠！

二倍角公式把「兩個三角函數相乘」合成「一個三角函數」，最大值就一眼看出來。30° 與 60° 射程相同，因為 sin60° = sin120°（互補的兩個 2θ）。

半角公式

把二倍角倒過來用

規律 → 公式

把 cos2θ = 2cos²θ − 1 = 1 − 2sin²θ 裡的 θ 換成 θ／2，移項：

半角公式
cos²(θ／2) = (1 + cosθ)／2
sin²(θ／2) = (1 − cosθ)／2
tan(θ／2) = sinθ／(1 + cosθ) = (1 − cosθ)／sinθ

開根號時要看 θ／2 落在哪個象限，自己決定正負號。

用一用
sin22.5° = sin(45°／2)，22.5° 在第一象限取正 sin²22.5° = (1 − cos45°)／2 = (1 − √2／2)／2 = (2 − √2)／4 sin22.5° = √(2 − √2)／2 ≈ 0.383 tan22.5° = sin45°／(1 + cos45°) = (√2／2)／(1 + √2／2) = √2／(2 + √2) = √2 − 1

收進工具箱：1-3 和角公式

整節只有一條真正要推的公式：cos(α−β) = cosα cosβ + sinα sinβ。其他全部是它的換角、相除、令兩角相等。

名稱內容
正弦和差角sin(α ± β) = sinα cosβ ± cosα sinβ
餘弦和差角cos(α ± β) = cosα cosβ ∓ sinα sinβ
正切和差角tan(α ± β) = (tanα ± tanβ)／(1 ∓ tanα tanβ)
二倍角sin2θ = 2sinθ cosθ；cos2θ = 2cos²θ − 1 = 1 − 2sin²θ；tan2θ = 2tanθ／(1 − tan²θ)
半角cos²(θ／2) = (1 + cosθ)／2；sin²(θ／2) = (1 − cosθ)／2
常用值sin75° = cos15° = (√6+√2)／4；sin15° = cos75° = (√6−√2)／4

練習題

1和差角

求 cos75° 的值。

參考答案
cos75° = cos(45° + 30°) = cos45° cos30° − sin45° sin30° = (√2／2)(√3／2) − (√2／2)(1／2) = (√6 − √2)／4
2和差角

α、β 都是銳角，sinα = 3／5，cosβ = 5／13。求 sin(α + β) 與 cos(α + β)，並判斷 α + β 是銳角還是鈍角。

參考答案
cosα = 4／5，sinβ = 12／13（銳角取正） sin(α+β) = (3／5)(5／13) + (4／5)(12／13) = 15／65 + 48／65 = 63／65 cos(α+β) = (4／5)(5／13) − (3／5)(12／13) = 20／65 − 36／65 = −16／65 cos(α+β) < 0 ⟹ α + β 是鈍角
3正切

α、β 都是銳角，tanα = 2，tanβ = 3，求 α + β。

參考答案
tan(α+β) = (2 + 3)／(1 − 2 × 3) = 5／(−5) = −1 α、β 都是銳角 ⟹ 0° < α + β < 180°，tan 值為 −1 ∴ α + β = 135°（即 3π／4）
4二倍角

已知 cosθ = 1／3，求 cos2θ。

參考答案
cos2θ = 2cos²θ − 1 = 2 × (1／9) − 1 = −7／9
5二倍角應用

θ 為銳角且 sinθ = 4／5，求 sin2θ 與 cos2θ。

參考答案
cosθ = 3／5 sin2θ = 2 × (4／5)(3／5) = 24／25 cos2θ = 1 − 2sin²θ = 1 − 2 × (16／25) = −7／25

下一步：把 sin 和 cos 合成一個波

和角公式把 sin(x + φ) 展開成 sinx 與 cosx 的組合。反過來讀，就是一個超實用的技巧：像 3sinx + 4cosx 這種「兩個波相加」的式子，其實可以合成一個單一的正弦波 5sin(x + φ)，最大值、最小值立刻看得出來。在 1-4「三角函數的疊合」，我們會用這招處理看板旋轉與潮汐模型。
