圓與直線的關係

從灑水器與基地台的涵蓋範圍，推出圓的方程式；再討論一個點、一條直線分別跟圓的位置關係，最後學會求圓的切線方程式。情境例子是重新設計的原創內容。

圓跟直線一樣，只要抓住幾個關鍵數字（圓心、半徑）就能寫成方程式；接著只要比較距離跟半徑，就能判斷一個點、一條直線分別跟圓是什麼關係，最後再學會求切線。

圓的定義與方程式

灑水器能澆到多遠的花？

情境

公園中央的灑水器裝在坐標原點 (0,0)，出水射程是 8 公尺，只要花圃裡的花距離灑水器不超過 8 公尺，就澆得到水。花圃裡有一朵花種在 (5,6)，澆得到嗎？

觀察

灑水器能澆到的所有位置，就是「跟圓心距離恰好等於（或小於）半徑」的所有點——這正是圓的定義。設圓上任一點 (x,y)，圓心 (0,0)，半徑 8，用兩點間距離公式：

√(x²+y²) = 8　　⟹　　x²+y² = 64

那朵花在 (5,6)，距離灑水器：

√(5²+6²) = √(25+36) = √61 ≈ 7.81（公尺）

7.81 < 8，澆得到。

規律 → 公式

一般化：圓心在 (h,k)、半徑為 r 的圓：

標準式
(x−h)² + (y−k)² = r²

把標準式展開，可以化成另一種常見形式：

(x−h)²+(y−k)² = r² x²−2hx+h² + y²−2ky+k² = r² x²+y² + (−2h)x + (−2k)y + (h²+k²−r²) = 0
一般式（D=−2h，E=−2k，F=h²+k²−r²）
x² + y² + Dx + Ey + F = 0

一般式看起來跟標準式差很多，但只要用配方法「補回」被展開藏起來的 (x−h)²、(y−k)²，就能還原出圓心和半徑。若配方後右邊等於 0，圖形只是「一個點」；若右邊是負數，就沒有實際的圓存在——並不是每個 x²+y²+Dx+Ey+F=0 的形式都真的代表一個圓。

用一用

某電信基地台訊號涵蓋範圍是圓心 (3,4)、半徑 10 公里的圓。寫出標準式與一般式。

標準式：(x−3)²+(y−4)² = 100 展開：x²−6x+9 + y²−8y+16 = 100 一般式：x²+y²−6x−8y−75 = 0

反過來，已知一般式 x²+y²−6x−8y−75=0，求圓心與半徑。

配方：(x²−6x+9) + (y²−8y+16) = 75+9+16 (x−3)² + (y−4)² = 100 圓心 (3,4)，半徑 √100 = 10
圓與點的位置關係

工人站在爆破警戒圈的哪裡？

情境

工地進行爆破作業，安全規定要求半徑 50 公尺內（含邊界）都算危險區，警戒圈圓心設在爆破點 (0,0)。三名工人分別站在 (30,20)、(48,14)、(60,10)，誰的位置是安全的？

觀察 → 規律 → 公式

判斷一個點跟圓的位置關係，只要比較「這個點到圓心的距離」跟「半徑」的大小：

比較位置關係
距離 < r在圓內
距離 = r在圓上
距離 > r在圓外
警戒圓：x²+y²=2500（半徑 50） 工人甲 (30,20)：30²+20²=900+400=1300<2500 ⟹ 在圓內（危險） 工人乙 (48,14)：48²+14²=2304+196=2500=2500 ⟹ 在圓上（仍算危險，因為含邊界） 工人丙 (60,10)：60²+10²=3600+100=3700>2500 ⟹ 在圓外（安全）

如果圓是用一般式 x²+y²+Dx+Ey+F=0 給的，不需要先化成標準式：把點的坐標代入「x²+y²+Dx+Ey+F」這個式子，結果小於 0 表示在圓內、等於 0 表示在圓上、大於 0 表示在圓外——這跟直接比較距離和半徑的結論是一致的，只是省去先求圓心、半徑的步驟。

圓與直線的關係

步道會不會切過水池？

情境

公園裡有一座圓形水池，圓心在 (0,0)，半徑 5 公尺。園方想蓋一條筆直的步道，方程式是 x+y=8。這條步道會不會穿過水池？

觀察

關鍵在於比較「圓心到這條直線的距離」跟「半徑」的大小——這正好可以用 2-2 學過的點到直線距離公式：

直線：x+y−8=0（即 a=1, b=1, c=−8） d = |1(0)+1(0)−8| ／ √(1²+1²) = 8／√2 = 4√2 ≈ 5.66（公尺）

5.66 > 5（半徑），圓心到步道的距離比半徑還遠，步道不會穿過水池。

規律 → 公式

設圓心到直線的距離為 d，圓半徑為 r：

比較位置關係交點數
d > r相離0
d = r相切1
d < r相交2

除了「幾何判別法」（比較 d 與 r），也可以把直線代入圓的方程式，消去一個變數後得到一個一元二次方程式，再看判別式 D=B²−4AC 的正負：D>0 對應相交、D=0 對應相切、D<0 對應相離——這種「代數判別法」跟幾何判別法會得到完全一致的結論，遇到直線是鉛直線（不能用斜率）時特別好用。

用一用

如果園方改把步道規劃成 x+y=6，還有 x+y=5√2，這兩條步道分別跟水池是什麼關係？

x+y=6：d = |0+0−6|／√2 = 6/√2 = 3√2 ≈ 4.24 < 5　⟹　相交，會穿過水池 x+y=5√2：d = |0+0−5√2|／√2 = 5√2/√2 = 5 = r　⟹　相切，恰好碰到水池邊緣

相交代表步道會直接穿過水池中央區域，通常設計上會避開；相切則是「剛好貼著池邊」，實務上也常常會再留一點安全距離，不會真的設計成恰好相切。

圓的切線

沿著廣場邊緣走的路要怎麼設計？

情境

社區有一座圓形廣場，圓心 (2,3)、半徑 5 公尺。廣場邊緣的入口在 (5,7)（可驗證：(5−2)²+(7−3)²=9+16=25，確實在圓上），設計單位想從入口拉一條「恰好貼著廣場邊緣、不切進廣場內部」的步道，這條步道（也就是圓在入口這一點的切線）方程式該怎麼求？

觀察 → 規律：切線垂直半徑

圓上一點的切線，有一個很重要的幾何性質：切線必定垂直於「圓心到這一點」的半徑（因為切線是最貼近圓、但完全不切入圓內部的直線，唯一的接觸方式就是與半徑垂直）。先求圓心到入口的斜率，再用「垂直斜率乘積 −1」求切線斜率：

半徑方向斜率：(7−3)／(5−2) = 4／3 切線斜率：−1 ÷ (4／3) = −3／4

再用點斜式，代入切點 (5,7)：

y − 7 = −(3/4)(x − 5) 4(y−7) = −3(x−5) 4y − 28 = −3x + 15 切線方程式：3x + 4y − 43 = 0
延伸：從圓外一點拉切線

另一座圓形噴水池，圓心在原點、半徑 4 公尺。岸上有一座燈柱在 (0,5)（距圓心 5 公尺，因為 5>4 所以燈柱在池外），想從燈柱架兩條筆直的護欄，恰好貼著水池邊緣（也就是兩條切線），這兩條護欄的方程式是什麼？

這次不知道切點在哪裡，但可以設護欄的方程式為「通過 (0,5)、斜率 m」，再用「圓心到這條線的距離＝半徑」來解出 m：

護欄：y = mx + 5　⟹　mx − y + 5 = 0 圓心 (0,0) 到護欄的距離 = 半徑 4： |m(0) − 0 + 5| ／ √(m²+1) = 4 5 ／ √(m²+1) = 4 √(m²+1) = 5／4 m² + 1 = 25／16 m² = 9／16　⟹　m = ±3／4

所以兩條護欄分別是 y = (3/4)x + 5 與 y = −(3/4)x + 5（一個點在圓外，恰好可以拉出兩條不同的切線）。

1代數

寫出圓心 (−2,5)、半徑 6 的圓的標準式與一般式。

查看解答
標準式：(x+2)²+(y−5)² = 36 展開：x²+4x+4+y²−10y+25 = 36 一般式：x²+y²+4x−10y−7 = 0
2代數

已知圓 x²+y²+2x−4y−4=0，求圓心與半徑；並判斷點 (3,3) 在圓內、圓上還是圓外。

查看解答
(x²+2x+1)+(y²−4y+4) = 4+1+4 (x+1)²+(y−2)² = 9 圓心 (−1,2)，半徑 3 代入 (3,3)：9+9+2(3)−4(3)−4 = 18+6−12−4 = 8 > 0 ⟹ 在圓外
3情境

灑水器覆蓋範圍是圓心 (0,0)、半徑 6 的圓。一條步道方程式是 x=8，步道會被灑到水嗎？

查看解答
直線 x−8=0（a=1,b=0,c=−8） d = |1(0)+0(0)−8|／√(1²+0²) = 8 8 > 6（半徑），相離，步道不會被灑到水
4代數

圓 x²+y²=25 上有一點 (3,4)，求圓在這一點的切線方程式。

查看解答
半徑方向斜率：(4−0)/(3−0) = 4/3 切線斜率：−1÷(4/3) = −3/4 y−4 = −(3/4)(x−3) 4y−16 = −3x+9 切線：3x+4y−25 = 0
5代數

圓 x²+y²=9 外有一點 (0,6)，求從這一點所拉出兩條切線的方程式。

查看解答
設切線 y=mx+6，即 mx−y+6=0 距離 = 半徑：|6|／√(m²+1) = 3 √(m²+1) = 2　⟹　m²=3　⟹　m=±√3 切線：y=√3x+6 與 y=−√3x+6

給筱葳的話

這一節的核心心法是：先把圓抽象成「圓心＋半徑」兩個關鍵數字，再把幾何問題（在不在圓內、切不切過、貼不貼著邊緣）翻譯成代數計算（比較距離大小、解方程式）。整個第二章（2-1～2-3）走的都是同一條路：先看懂圖形，再抓關鍵數字，最後翻譯成代數——這套方法之後在圓錐曲線、空間向量等單元還會反覆用到。
