數學2・第二章 排列組合與古典機率・2-4

機率

延續畢業旅行闖關遊戲的情境——轉盤遊戲、抽兌換券、摸彩箱——認識樣本空間、事件、古典機率，以及數學期望值。情境例子為原創設計。

前面三節建立了「數數量」的工具箱：加法原理、乘法原理、排列數、組合數，都在回答「總共有幾種可能」。這一節要把這些工具用在一個更貼近生活的問題上：「某件事發生的可能性有多大？」畢業旅行的闖關遊戲攤位，正好是練習機率最自然的場景。

樣本空間

先把「所有可能發生的結果」列清楚

情境

畢業旅行的闖關攤位有一個轉盤遊戲：轉盤平均分成紅、黃、綠三等份，玩家要轉兩次（兩次轉的結果互不影響）。想知道各種結果的可能性之前，得先把「所有可能出現的結果」一個不漏地列出來。

像轉轉盤這種「在相同條件下進行、結果無法事先確定」的過程，叫做試驗；一次試驗所有可能結果所成的集合，叫做樣本空間，通常記作 S；樣本空間裡的每一個結果，叫做一個樣本點。

觀察 → 規律

轉兩次轉盤，每次都有3種可能顏色，用乘法原理，樣本空間應該有 3×3=9 個樣本點。用表格把所有的「(第一次顏色, 第二次顏色)」列出來最清楚：

第一次 ＼ 第二次紅黃綠
紅(紅,紅)(紅,黃)(紅,綠)
黃(黃,紅)(黃,黃)(黃,綠)
綠(綠,紅)(綠,黃)(綠,綠)
公式
樣本空間
S = {(紅,紅),(紅,黃),(紅,綠),(黃,紅),(黃,黃),(黃,綠),(綠,紅),(綠,黃),(綠,綠)}　　n(S) = 9

列樣本空間最容易犯的錯，是漏掉「順序不同但顏色相同」的組合——例如(紅,黃)跟(黃,紅)是兩次轉盤先後不同、結果不同，必須當成兩個不同的樣本點，不能只列一次。

事件

樣本空間中，我們真正關心的那一部分

情境

玩家其實只關心兩件事：「兩次轉出同一個顏色（可以兌換神秘獎品）」，還有「至少有一次轉到紅色（可以再抽一次）」。這兩種「我們關心的結果集合」，就是樣本空間 S 的子集合，稱為事件。

設 A = 兩次顏色相同 = {(紅,紅),(黃,黃),(綠,綠)}　　n(A) = 3 設 B = 至少一次紅色 = {(紅,紅),(紅,黃),(紅,綠),(黃,紅),(綠,紅)}　　n(B) = 5

如果事件只包含樣本空間中的一個樣本點（例如「剛好轉出(紅,黃)」），叫做基本事件；包含兩個以上樣本點的事件（像A、B），叫做複合事件。而樣本空間 S 本身也是一個事件（代表「一定會發生」，稱必然事件），空集合 ∅ 也是一個事件（代表「不可能發生」，稱不可能事件）。

觀察 → 規律：事件的運算

事件之間也可以做集合運算，意義非常直覺——「A 或 B 發生」對應聯集，「A 且 B 都發生」對應交集，「A 不發生」對應餘集：

A∪B（和事件）＝「顏色相同」或「至少一次紅色」至少一項發生 = {(紅,紅),(黃,黃),(綠,綠),(紅,黃),(紅,綠),(黃,紅),(綠,紅)}　　n(A∪B)=7 A∩B（積事件）＝「顏色相同」且「至少一次紅色」同時發生 = {(紅,紅)}　　　n(A∩B)=1 A′（餘事件）＝「兩次顏色不同」＝ S 中扣掉 A 的部分 n(A′) = n(S)−n(A) = 9−3 = 6
事件的運算
和事件 A∪B：A 或 B 至少一個發生　　積事件 A∩B：A、B 同時發生
互斥事件：A∩B=∅（A、B不可能同時發生）　　餘事件 A′=S−A：A 不發生

如果換一個事件 C = 兩次都轉到綠色以外的顏色 = 兩次都轉到紅或黃，可以驗證 A∩C 不是空集合（例如(紅,紅)同時屬於A和C），所以 A 與 C 不是互斥事件；但如果 D = 只有一次紅色一次綠色，D∩A=∅，A 與 D 才是互斥事件。

古典機率

「感興趣的結果數」佔「全部結果數」的比例

情境

回到轉盤遊戲，如果樣本空間 S 裡的9個樣本點，因為轉盤三等份切割均勻，出現的機會是完全相同的，那麼「兩次顏色相同」這個事件 A 發生的機率，很自然地就是 A 佔 S 的比例。

古典機率的定義
P(A) = n(A) ／ n(S)
條件：樣本空間 S 中每個樣本點發生的機會均等（等機率）
P(A) = n(A)／n(S) = 3／9 = 1／3
用一用：不放回的抽取

另一個攤位用5張兌換券（編號1到5）讓玩家抽獎，玩家一次抽出2張（抽出後不放回）。請問「抽到的2張都是奇數編號」的機率是多少？

1~5中奇數編號有{1,3,5}共3張，偶數編號有{2,4}共2張 n(S) = C²₅ = 10（從5張中抽2張，不管順序） n(都是奇數) = C²₃ = 3（從3張奇數中抽2張） P(都是奇數) = C²₃／C²₅ = 3／10
規律 → 機率的性質

古典機率有幾條從定義就能直接看出來的性質，計算時常常用來檢查答案是否合理，或簡化計算：

機率的性質
(1) 0 ≤ P(A) ≤ 1　　(2) P(S)=1，P(∅)=0　　(3) P(A′) = 1−P(A)
(4) P(A∪B) = P(A)+P(B)−P(A∩B)

60位同學參加畢業旅行問卷，玩迷宮遊戲攤位的有35人，玩套圈圈攤位的有20人，兩個攤位都玩的有10人。隨機抽問一位同學，求「至少玩過一個攤位」的機率，以及「兩個攤位都沒玩」的機率。

P(A) = 35／60，P(B) = 20／60，P(A∩B) = 10／60 P(A∪B) = 35／60 + 20／60 − 10／60 = 45／60 = 3／4 P(兩個都沒玩) = P((A∪B)′) = 1 − P(A∪B) = 1 − 3／4 = 1／4
用一用：反過來想——用餘事件簡化計算

闖關遊戲的休息區裡剛好聚集了10位同學，假設每個人的出生月份在1~12月中是等機率、且互相獨立的，求「這10人中至少有兩人在同一個月出生」的機率（取到小數點後兩位）。

「至少兩人同月」直接算很麻煩（要考慮兩人同月、三人同月……很多種情況），反過來想它的餘事件「10人生日月份全部不同」，只需要算一種情況就好：

n(S) = 12¹⁰（每人的出生月份各自獨立，有12種可能） n(10人月份全不同) = P¹⁰₁₂ = 12×11×10×⋯×3（12選10人排出順序，對應到10個不同月份） P(全不同) = P¹⁰₁₂ ／ 12¹⁰ ≈ 0.0039 P(至少兩人同月) = 1 − P(全不同) ≈ 1 − 0.0039 ≈ 0.996

「至少……」的機率問題，第一個該想到的策略永遠是「算它的餘事件」——只要餘事件（例如「全部不同」「一次都沒有」）比原事件單純，用 1 減掉餘事件的機率往往快得多。

數學期望值

把「可能得到的獎金」依機率加權平均

情境

闖關遊戲的最後一關是個獎金轉盤：轉盤平均分成5等份，其中2等份可以得到150元的禮券，另外3等份可以得到450元的禮券。如果每個人都可以免費轉一次，平均每人「應該」拿到多少元的禮券？這個「長期玩下來的平均值」，就是數學期望值。

規律 → 公式

把樣本空間依「獎金金額」分成幾類，各類發生的機率分別是 p₁,p₂,…,pₙ，對應的獎金是 m₁,m₂,…,mₙ，數學期望值就是把每種獎金乘上它發生的機率，再全部加起來（也就是「加權平均」）：

數學期望值
E = m₁p₁ + m₂p₂ + ⋯ + mₙpₙ
P(150元) = 2／5，P(450元) = 3／5 E = 150×(2／5) + 450×(3／5) = 60 + 270 = 330 元

這代表：如果有很多人輪流來轉，平均每人拿到的禮券金額會趨近330元——不是說真的有人剛好拿到330元（轉盤上根本沒有330元這個選項），而是「長期平均下來」的參考值。

用一用：反推未知的獎金（公平遊戲）

另一個攤位設計了一款「積分挑戰」：參加者要先付出3點積分當作入場費，接著抽一張卡，1／4的機率贏得9點、1／2的機率贏得3點、1／4的機率贏得x點。老師希望這個遊戲設計成「公平遊戲」——長期玩下來，玩家平均不賺不賠，請問x應該設計成多少？

「公平遊戲」的意思是：贏得點數的期望值，要剛好等於入場費，玩家才不會長期虧損或佔便宜：

設贏得點數的期望值為 E，公平遊戲要求 E = 3（入場費） E = 9×(1／4) + 3×(1／2) + x×(1／4) = 3 9／4 + 3／2 + x／4 = 3 9／4 + 6／4 + x／4 = 12／4 (15 + x)／4 = 12／4 15 + x = 12 x = −3

期望值算出「x=−3」代表這張卡其實是「倒扣3點」——不是真的贏了負的獎品，而是代表玩家這次要多付出3點積分，這樣整體加權平均才會剛好打平，是公平遊戲設計常見的手法。

練習題

1樣本空間與古典機率

擲兩顆四面體骰子（每顆各有1~4點）各一次，求樣本空間的樣本點數，以及「兩顆點數相同」的機率。

參考答案
n(S) = 4×4 = 16 兩顆相同的結果有(1,1),(2,2),(3,3),(4,4)共4種 P(相同) = 4／16 = 1／4
2古典機率（不放回）

從標號1到9的9張卡片中，一次抽出2張（不放回），求「兩張都是3的倍數」的機率。

參考答案
1~9中3的倍數有{3,6,9}共3張 n(S) = C²₉ = 36　　n(都是3的倍數) = C²₃ = 3 P = 3／36 = 1／12
3事件運算與機率

60位同學問卷調查，玩迷宮遊戲的有35人，玩套圈圈遊戲的有20人，兩者都玩的有10人。隨機抽問一位同學，求P(至少玩過一項)與P(兩項都沒玩)。

參考答案
P(A∪B) = 35／60 + 20／60 − 10／60 = 45／60 = 3／4 P(都沒玩) = 1 − 3／4 = 1／4
4數學期望值

轉盤平均分成5等份，其中2等份可得80分，3等份可得20分。求轉一次的期望得分。

參考答案
E = 80×(2／5) + 20×(3／5) = 32 + 12 = 44 分
5期望值的應用

某摸彩箱有10張籤，其中2張中30元、3張中10元、5張槓龜（0元），參加一次要先付5元。求玩一次的期望「淨」收益（獎金期望值減去參加費用），並判斷這個遊戲對玩家是否划算。

參考答案
E(獎金) = 30×(2／10) + 10×(3／10) + 0×(5／10) = 6 + 3 = 9 元 淨收益 = E(獎金) − 參加費 = 9 − 5 = 4 元 淨收益為正，長期而言對玩家是划算的遊戲。
