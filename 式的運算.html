PART 1 ・ 乘法公式

老闆的心算絕活

情境

傳統市場的水果攤，老闆常常要瞬間算出總價。假設一斤水果 47 元，這次買了 53 斤，老闆要怎麼在心裡快速算出 47 × 53，而不用拿計算機慢慢按？

老闆的訣竅：把 47 和 53 都看成「50 上下加減一點」——47 = 50 − 3，53 = 50 + 3。

觀察

先老實把它展開看看：

(50 − 3)(50 + 3) = 50×50 + 50×3 − 3×50 − 3×3 = 2500 + 150 − 150 − 9 = 2500 − 9 = 2491

有趣的事發生了：中間的 +150 和 −150 完全抵銷，只剩下 50² − 3²。拿計算機驗算 47×53，答案確實是 2491，分毫不差。

規律 → 公式

這不是巧合。把 50 換成任何數 a，把 3 換成任何數 b，同樣的抵銷永遠會發生：

(a + b)(a − b) = a² − b²

這就是「平方差公式」——它把一個看起來很麻煩的乘法，變成兩個平方相減。再試一次：

998 × 1002 = (1000 − 2)(1000 + 2) = 1000² − 2² = 1000000 − 4 = 999996

三秒心算完成，比按計算機還快。

擴建花園，推出完全平方公式

情境

筱葳家有一塊邊長 a 公尺的正方形花園。今年想擴建，把長和寬各加寬 b 公尺，變成一個邊長 (a+b) 的正方形花園。擴建後，總共增加了多少面積？

觀察（用圖形拆解）

把新花園拆成四塊：原本的花園、右邊多出來的長條、下面多出來的長條，還有右下角新增的小正方形。

規律 → 公式

四塊面積相加：a² + ab + ab + b² = a² + 2ab + b²。而整塊新花園的面積，也可以直接用邊長算：(a+b)²。同一塊地，兩種算法，答案必須相等：

(a + b)² = a² + 2ab + b²

這就是「完全平方公式」——不是要你死背，你隨時都能自己畫一個正方形，重新推導一次。

延伸

把邊長 a 的正方形，看成是先切掉一條寬度 b 的長條，剩下 (a−b)（就是上面第二張圖），用同樣的拆法可以得到：

a² = (a−b)² + 2b(a−b) + b² 移項整理 → (a−b)² = a² − 2ab + b²
(a − b)² = a² − 2ab + b²
回到情境：工具的威力

如果我們知道 a+b=5 且 ab=6，可以不用先解出 a、b 各是多少，就直接求出 a²+b² 嗎？

a² + b² = (a+b)² − 2ab = 5² − 2×6 = 25 − 12 = 13

這就是代數工具的威力：有時候我們根本不需要知道每個變數的真實身分，只要善用公式，就能直接算出想要的組合值。

把花園蓋成蓄水池：多一個維度會發生什麼事

情境

筱葳家後來決定不種花了，把那塊邊長 a 公尺的正方形地，改建成一座正立方體的蓄水池。同樣地，過幾年想擴建，把長、寬、高都各加大 b 公尺。這次多出來的「體積」該怎麼算？

觀察（用立體圖拆解）

把邊長 (a+b) 的大正立方體，想像成沿著長、寬、高三個方向都切一刀（切在 a 和 b 的交界），會切出 2×2×2 = 8 個小長方體：

規律 → 公式

八塊體積加起來：a³ + 3a²b + 3ab² + b³。這就是把 (a+b) 連乘三次的結果：

(a + b)³ = a³ + 3a²b + 3ab² + b³

「為什麼中間兩項的係數是 3？」——因為 a²b 這種尺寸的小方塊，在長寬高三個方向裡「哪一邊是 b」可以有 3 種選法，ab² 也是同樣的道理。

延伸

用同一招反過來切：把邊長 a 的蓄水池看成「先蓋 (a−b)，再加高 b」蓋成的，一樣可以拆成 8 塊，整理後可以得到：

(a − b)³ = a³ − 3a²b + 3ab² − b³
回到情境：工具的威力（再一次）

如果兩座蓄水池的邊長和是 a+b=4，邊長乘積是 ab=3，可以不用先解出 a、b，就直接算出兩座水池的體積和 a³+b³ 嗎？

把 (a+b)³ 展開式重新排列：

(a+b)³ = a³ + 3ab(a+b) + b³ 移項 → a³+b³ = (a+b)³ − 3ab(a+b)
a³+b³ = 4³ − 3×3×4 = 64 − 36 = 28

用同樣的方法整理 (a−b)³，還能推出立方差的因式分解：

(a−b)³ = a³ − 3ab(a−b) − b³ 移項 → a³−b³ = (a−b)³ + 3ab(a−b) = (a−b)[(a−b)² + 3ab] = (a−b)(a²+ab+b²)
a³+b³ = (a+b)(a²−ab+b²)　　　a³−b³ = (a−b)(a²+ab+b²)

這兩個因式分解公式，不是又要背一組新東西——它們就是從 (a+b)³ 和 (a−b)³ 這兩個已經蓋好的「工具」，重新排列零件生產出來的。

延伸挑戰：三塊地合併

情境 → 規律

如果不是兩塊地合併，而是三戶人家把邊長 a、b、c 的正方形土地合併成一塊邊長 (a+b+c) 的正方形，邏輯完全一樣，只是切割方式從 2×2 變成 3×3：

公式
(a+b+c)² = a²+b²+c²+2ab+2bc+2ca
PART 2 ・ 分式的運算

兩條水管一起注水，要多久？

情境

筱葳家的水池，只開 A 水管，a 小時可以裝滿；只開 B 水管，b 小時可以裝滿。如果兩條水管一起開，要多久才能裝滿？

觀察

換個角度想「速度」而不是「時間」：A 水管每小時裝滿 1/a 個水池，B 水管每小時裝滿 1/b 個水池。一起開，速度直接相加：

兩管合併的注水速度 = 1/a + 1/b（水池／小時）

但 1/a 和 1/b 分母不一樣，不能直接把分子加起來。要先把兩個分式換成「同一種分母」，這個動作叫做通分——分母同乘對方缺少的因子：

1/a = b/(ab)　　　1/b = a/(ab)　　（分母都通成 ab） 1/a + 1/b = b/(ab) + a/(ab) = (a+b)/(ab)
規律 → 公式
c/a + d/b = (cb+ad) / (ab)　　（先通分，分子才能相加）

算出合併速度後，裝滿一整個水池（1 個單位）所需的時間，就是速度的倒數：

合併時間 = 1 ÷ [(a+b)/(ab)] = ab/(a+b)（小時）

代入具體數字驗算：A 管 3 小時裝滿、B 管 6 小時裝滿：

合併時間 = 3×6/(3+6) = 18/9 = 2（小時）

兩管一起開，果然比單開任何一管都快（比 3 小時、比 6 小時都短），符合直覺。

延伸：分式的乘除與約分

分式的乘除，規則跟一般分數一樣：乘法就是分子乘分子、分母乘分母；除法則是「除以一個分式」等於「乘上它的倒數」：

(c/a) × (d/b) = cd/(ab)　　　　(c/a) ÷ (d/b) = (c/a) × (b/d) = cb/(ad)

而分式的約分，常常要搬出上一節推導過的乘法公式，把分子、分母拆解成相同的因式再消去。例如：

(x²−4) / (x−2) = [(x+2)(x−2)] / (x−2) = x+2　（x≠2，用平方差公式拆解分子） (x²+4x+4) / (x+2) = [(x+2)²] / (x+2) = x+2　（x≠−2，用完全平方公式拆解分子）

分式運算最容易出錯的地方，是漏看「分母不能是 0」這個限制——上面兩個例子分別要排除 x=2 和 x=−2。乘法公式不是只有 1-2 前半段有用，往後的分式、根式運算都會一直用到它。

PART 3 ・ 根式的運算

花圃要訂多長的圍籬？

情境

筱葳家另一塊正方形花圃，面積是 72 平方公尺。五金行問她：「圍籬要訂多長？」她需要知道邊長。

邊長 = √72，但這個數字不好想像有多長，能不能寫得更清楚一點？

觀察

把 72 拆成一個完全平方數乘上剩下的部分：

72 = 36 × 2 = 6² × 2

而 √(6²×2) 其實就是 √(6²) 乘上 √2，也就是：

√72 = √(36×2) = √36 × √2 = 6√2 ≈ 6×1.414 ≈ 8.49（公尺）

比起 √72 這種寫法，「6√2」讓人一眼就能估出大概是 8.5 公尺左右，五金行也比較好報價。

規律 → 公式
√a · √b = √(ab)　　（a, b ≥ 0）

反過來用，就是根式化簡的方法：把根號內的數拆成「完全平方數 × 剩下的數」，完全平方數就能開根號跳出來。

(√a)² = a　　　√(a²) = |a|　　　√a/√b = √(a/b)（b>0）
回到情境：兩塊地合併

筱葳家隔壁也想合種花，兩塊地各自算出需要的圍籬長度是 √8 公尺和 √18 公尺。總共要訂多長？

不能直接把根號內的數字相加（√8+√18 ≠ √26！），要先各自化簡成同一種根式：

√8 = √(4×2) = 2√2 √18 = √(9×2) = 3√2 √8 + √18 = 2√2 + 3√2 = 5√2 （公尺）

關鍵觀念：只有「根號內的數字一樣」的根式，才能直接相加減（就像 2 個蘋果加 3 個蘋果，不能跟橘子加在一起）。

分母有理化：師傅的捲尺，量不出根號

情境

木工師傅算出一塊木板該裁 1/√2 公尺寬。但捲尺上只有普通刻度，師傅該裁在哪裡？

1/√2 這個寫法，沒辦法直接看出大概是多少公尺——分母帶根號，很難心算估計。

觀察

把分子分母同時乘上 √2（相當於乘 1，數值不變）：

1/√2 = (1×√2)/(√2×√2) = √2/2

現在只要知道 √2 ≈ 1.414，馬上能算出：

√2/2 ≈ 1.414/2 ≈ 0.707（公尺）
規律 → 公式
1/√a = √a/a　　（分子分母同乘 √a）
延伸：分母有兩項時，搬出乘法公式

如果分母是 √a+√b 這種兩項的根式呢？例如 3/(√5−√2)。這時候乘 √5 沒辦法一次消掉兩個根號，但還記得 PART 1 推導過的平方差公式嗎？

(A+B)(A−B) = A² − B²

把分母乘上「相反符號」的另一半，根號就會被平方消掉：

3/(√5−√2) = 3(√5+√2) / [(√5−√2)(√5+√2)] = 3(√5+√2) / (5−2) = 3(√5+√2) / 3 = √5+√2

分母有理化的本質，其實就是「製造一個平方差公式的機會」，把根號變成整數消掉。這就是為什麼乘法公式、分式、根式三個主題要一起熟練——它們常常互相合作。

PART 4 ・ 算幾不等式

籬笆長度固定，怎麼圍面積最大？

情境

筱葳有 20 公尺長的籬笆，想圍出一塊長方形花圃（四邊都要圍）。長、寬各設計成多少，圍出來的面積會最大？

觀察

設長方形的長、寬分別是 x、y 公尺，周長固定：2x+2y=20，也就是 x+y=10。把幾種可能的組合都算一次面積 xy：

xyx+y面積 xy
19109
371021
551025 ← 最大
731021
91109

很明顯，當長寬相等（都是 5）時，面積最大，而且越往兩邊「拉不平均」，面積就掉得越快。這是巧合，還是規律？

規律 → 公式

對任意兩個非負實數 a、b，先看一個顯然成立的事實：平方一定不會是負的。

(√a − √b)² ≥ 0 展開： a − 2√(ab) + b ≥ 0 移項： a + b ≥ 2√(ab) 兩邊除以 2： (a+b)/2 ≥ √(ab)

左邊 (a+b)/2 是 a、b 的算術平均數，右邊 √(ab) 是 a、b 的幾何平均數。這個不等式就叫做算幾不等式：

(a+b)/2 ≥ √(ab)　　（a,b≥0，等號成立 ⟺ a=b）

從推導過程可以直接看出：等號成立的條件，剛好就是 √a=√b，也就是 a=b——這正好解釋了花圃問題裡「長寬相等時面積最大」的現象。

回到情境：用公式直接算出最大面積

把算幾不等式倒過來看：如果 a+b（和）固定，那麼 √(ab) 最大只能等於 (a+b)/2，也就是 ab 的最大值是 [(a+b)/2]²。代入花圃問題（x+y=10 固定）：

xy ≤ [(x+y)/2]² = (10/2)² = 25 等號成立條件：x=y，也就是 x=y=5

不用一格一格試表格，公式直接告訴我們：面積最大是 25 平方公尺，在長寬都是 5 公尺時發生——跟剛剛觀察表格得到的結論完全吻合。

延伸：反過來，積固定時「和」最小

如果換成「花圃面積固定要 36 平方公尺，籬笆該怎麼圍才能最省材料（周長最小）？」

這時候 ab=36 固定，算幾不等式反過來限制「和」的最小值：

(x+y)/2 ≥ √(xy) = √36 = 6 所以 x+y ≥ 12，等號成立於 x=y=6

面積固定時，長寬相等（正方形）用的周長最省——這也是為什麼日常生活中很多「固定容量、最省材料」的包裝設計，常常會盡量做成接近正方形或正立方體的形狀。

算幾不等式只有一個使用限制，但很容易忘記：a、b 都必須是非負數，而且套用之前最好先確認「和固定」還是「積固定」，才能判斷該找最大值還是最小值。

收進工具箱：1-2 式的運算

上面每一條都已經自己推導過一次，不是憑空要背的規則——收錄在這裡，需要時隨時查。

乘法公式

名稱公式
完全平方(a+b)² = a²+2ab+b²
完全平方(a−b)² = a²−2ab+b²
平方差(a+b)(a−b) = a²−b²
三項平方(a+b+c)² = a²+b²+c²+2ab+2bc+2ca
完全立方(a+b)³ = a³+3a²b+3ab²+b³
完全立方(a−b)³ = a³−3a²b+3ab²−b³
立方和a³+b³ = (a+b)(a²−ab+b²)
立方差a³−b³ = (a−b)(a²+ab+b²)

分式運算

用途公式
通分後相加c/a + d/b = (cb+ad)/(ab)
乘法(c/a)×(d/b) = cd/(ab)
除法(c/a)÷(d/b) = cb/(ad)
約分先用乘法公式拆解因式，再消去公因式（並排除使分母為 0 的值）

根式運算

用途公式
根式相乘√a · √b = √(ab)　(a,b≥0)
根式相除√a / √b = √(a/b)　(a≥0, b>0)
平方還原(√a)² = a　(a≥0)
開根還原√(a²) = |a|
一項分母有理化1/√a = √a／a
兩項分母有理化1/(√a+√b) = (√a−√b)／(a−b)

算幾不等式

用途公式
算幾不等式(a+b)/2 ≥ √(ab)　(a,b≥0，等號⟺a=b)
和固定 ⟹ 積的最大值ab ≤ [(a+b)/2]²
積固定 ⟹ 和的最小值a+b ≥ 2√(ab)

換你動手做

1情境

老闆想心算 99 × 101，用平方差公式怎麼算？

查看解答
把 99、101 看成 100∓1：
99×101 = (100−1)(100+1) = 100²−1² = 10000−1 = 9999
2代數

已知 a+b=7，ab=10，求 a²+b² 與 a³+b³。

查看解答
a²+b² = (a+b)²−2ab = 49−20 = 29 a³+b³ = (a+b)³−3ab(a+b) = 343−3×10×7 = 343−210 = 133
3情境

A 水管 4 小時裝滿水池，B 水管 12 小時裝滿。兩管一起開，多久裝滿？

查看解答
合併時間 = ab/(a+b) = 4×12/(4+12) = 48/16 = 3（小時）
4代數

化簡 (x²−9)/(x+3) + 1/(x+3)。

查看解答
(x²−9+1)/(x+3) = (x²−8)/(x+3)　（x≠−3）
提醒：分子 x²−9 雖然是平方差，但加了 1 之後不能再約分，要先合併同分母的分子。
5代數

化簡 √27 + √48 − √12。

查看解答
√27=3√3，√48=4√3，√12=2√3 √27+√48−√12 = 3√3+4√3−2√3 = 5√3
6代數

有理化 5/(√7−√3)。

查看解答
5/(√7−√3) = 5(√7+√3)/[(√7)²−(√3)²] = 5(√7+√3)/4
7情境

用 40 公尺的籬笆圍長方形花圃，長寬各為多少時面積最大？最大面積是多少？

查看解答
周長 40 ⟹ x+y=20：
xy ≤ [(x+y)/2]² = 10² = 100 等號成立於 x=y=10
長寬都是 10 公尺時，面積最大為 100 平方公尺。
8代數

設 x>0，用算幾不等式求 x + 4/x 的最小值。

查看解答
把 x 和 4/x 看成算幾不等式裡的 a、b（乘積固定 x×(4/x)=4）：
x + 4/x ≥ 2√(x×4/x) = 2√4 = 4 等號成立於 x = 4/x ⟹ x²=4 ⟹ x=2（因為 x>0）
最小值是 4，在 x=2 時發生。
9代數

因式分解 x³ − 64，並化簡 (x³−64)/(x²+4x+16)。

查看解答
x³−64 = (x−4)(x²+4x+16) (x³−64)/(x²+4x+16) = x−4　（x²+4x+16 恆不為 0，可直接約分）
10代數

已知三戶人家合併土地後 a+b+c=6，兩兩乘積和 ab+bc+ca=11，求 a²+b²+c²。

查看解答
利用 (a+b+c)²=a²+b²+c²+2(ab+bc+ca)：
a²+b²+c² = (a+b+c)² − 2(ab+bc+ca) = 36 − 22 = 14

乘法公式、分式、根式、算幾不等式看似四個獨立主題，其實常常互相合作——約分要用乘法公式拆因式，分母有理化要製造平方差公式，算幾不等式的推導本身就是一個完全平方式。下次遇到新公式，先別急著背，想想有沒有一個生活情境，或是一張圖，能幫你自己重新推導一次。
