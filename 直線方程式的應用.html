聯立方程式的幾何意義

兩條路的交叉口在哪裡？

情境

承上一節：主幹道 y=2x+3，垂直的新巷道 y=−x/2+3。這兩條路會在哪一點交會，好規劃紅綠燈？

觀察 → 規律

交叉口同時滿足兩條路的方程式，也就是聯立方程式的解。解聯立方程式，幾何上就是在找「兩條直線的共同點」：

2x+3 = −x/2+3 2x + x/2 = 0 (5/2)x = 0　⟹　x = 0，代回 y = 2(0)+3 = 3 交點：(0, 3)

一般化來看，兩條直線 a₁x+b₁y=c₁ 與 a₂x+b₂y=c₂ 聯立後，會有三種可能：

斜率關係解的情況幾何意義
斜率不同恰有一組解兩線相交於一點
斜率相同，截距不同無解兩線平行不相交
斜率相同，截距也相同無限多組解兩線其實是同一條線（重合）
用一用

如果規劃單位改提議另一條巷道 y=2x+7，它會跟主幹道 y=2x+3 交會嗎？

兩式斜率皆為 2，但常數項不同（3 ≠ 7） ⟹ 無解，兩條路互相平行，永遠不會相交
點到直線的距離

消防栓離馬路夠遠嗎？

情境

消防法規要求消防栓距離主幹道（中心線）至少 5 公尺。有一個消防栓設在 (10,2)，主幹道方程式是 2x−y+3=0，這個消防栓的位置合格嗎？

觀察 → 規律 → 公式
點 (x₀,y₀) 到直線 ax+by+c=0 的距離
d = |a·x₀ + b·y₀ + c| ／ √(a²+b²)
d = |2(10) − 2 + 3| ／ √(2²+(−1)²) = |20 − 2 + 3| ／ √5 = 21 ／ √5 ≈ 9.39（公尺）

9.39 > 5，合格。

延伸：兩條平行路之間的寬度

如果想知道主幹道 2x−y+3=0 跟另一條與它平行、方程式為 2x−y−7=0 的輔助道路之間相距多遠，可以直接用「兩平行線距離公式」，不必先找一個點：

兩平行線 ax+by+c₁=0 與 ax+by+c₂=0 的距離
d = |c₁−c₂| ／ √(a²+b²)
d = |3−(−7)| ／ √(2²+(−1)²) = 10／√5 = 2√5 ≈ 4.47（公尺）
二元一次不等式

候診區要畫在分隔線的哪一邊？

情境

診所大廳要用一條分隔線 x+y=10（單位：公尺）把地板分成兩區：靠近門口的一側放候診椅，另一側留給服務櫃檯。已知門口在原點 (0,0) 附近，候診椅該畫在哪一個不等式所代表的區域裡？

觀察

一條直線 ax+by+c=0 會把平面切成兩半；每一半都可以用一個不等式表示，只要挑一個「不在線上」的點代入，看代入後是大於 0 還是小於 0，就知道那一側對應哪個不等式：

分隔線：x+y−10=0 代入門口 (0,0)：0+0−10 = −10 < 0 ⟹ 門口這一側滿足 x+y−10<0，也就是 x+y<10

所以候診椅要畫在 x+y<10 這一側。

規律 → 公式

一般地，設 a,b 不同時為 0，直線 L：ax+by+c=0 把平面分成兩個半平面：

不等式邊界線圖示
ax+by+c>0 或 <0不含邊界畫虛線
ax+by+c≥0 或 ≤0含邊界畫實線

判斷哪一側對應哪個不等式，最簡單的方法就是「代一個不在線上的點」（不在線上的原點通常最方便），代入後的正負號就是那一整側的正負號——因為同一側的點，代入 ax+by+c 的正負號都相同。多個不等式同時成立（像「候診椅要在門口那一側，同時又要在櫃檯的另一條界線內」）時，答案就是每個不等式代表的區域「疊」起來的共同部分。

用一用

候診椅除了要滿足 x+y<10，還必須在櫃檯圍欄 x−y=−2 靠近門口（原點）的那一側，寫出這一側對應的不等式，並說明候診椅區域是哪兩個不等式的共同部分。

圍欄：x−y+2=0，代入 (0,0)：0−0+2=2>0 ⟹ 門口這一側滿足 x−y+2>0 候診椅區域：{ x+y<10 且 x−y+2>0（不含邊界，用虛線）}

用途公式
聯立方程式的解斜率不同→一解；斜率同截距異→無解；完全相同→無限多解

換你動手做

1代數

求兩直線 x+y=4 與 x−y=2 的交點；並判斷 x+y=4 與 x+y=9 是否相交。

查看解答
兩式相加：2x=6 ⟹ x=3 代回：3+y=4 ⟹ y=1 交點 (3,1) x+y=4 與 x+y=9：斜率相同、常數不同 ⟹ 無解，兩線平行不相交
2情境

路燈規定要距離道路中心線（3x−4y+1=0）至少 2 公尺，某路燈設於 (1,2)，是否合格？

查看解答
d = |3(1)−4(2)+1| ／ √(3²+4²) = |3−8+1|／5 = 4／5 = 0.8（公尺） 0.8 < 2，不合格，路燈離道路太近
3情境

圖書館用分隔線 x−y=4 隔開閱覽區與走道，服務台在 (0,0) 這一側算走道，寫出閱覽區對應的不等式。

查看解答
分隔線：x−y−4=0，代入 (0,0)：0−0−4=−4<0（走道側） ⟹ 閱覽區（另一側）：x−y−4>0，即 x−y>4
