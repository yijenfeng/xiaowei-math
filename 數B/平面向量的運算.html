平面向量的運算

定向越野結束，筱葳拖著器材行李箱走回社辦。拉桿越斜，手越累，箱子卻沒有走得比較快。物理老師說：只有順著前進方向的那部分力才真的在做功。這一節把這個想法變成向量的內積，用它算兩個向量的夾角、判斷垂直，並求一個向量在另一個方向上的正射影。情境例子為原創設計。

上一節的向量可以加減、可以乘一個數。這一節介紹兩個向量之間的一種「乘法」——內積。它的結果是一個數，同時反映兩個向量的長度和夾角。內積最常用的三件事：算夾角、判斷垂直、求正射影。

內積的意義

長度乘長度，再乘夾角的 cos

情境

筱葳用 50 牛頓的力拉箱子，拉桿和地面夾 60°，往前走了 20 公尺。她做了多少功？

沿地面方向的力 = 50 × cos60° = 25（牛頓） 功 = 25 × 20 = 500（焦耳） 一般地：功 = |F| × |d| × cosθ
定義
內積（θ 為兩向量夾角，0° ≤ θ ≤ 180°）
a・b = |a||b|cosθ
夾角內積意義
銳角正方向大致相同
直角0互相垂直
鈍角負方向大致相反
坐標算法與夾角

對應分量相乘再相加

公式

有坐標時，不用量角度就能算內積（推導用到數學2 的餘弦定理）：

內積的坐標算法
(x₁, y₁)・(x₂, y₂) = x₁x₂ + y₁y₂
夾角：cosθ = (a・b)／(|a||b|)
垂直：a ⊥ b ⟺ x₁x₂ + y₁y₂ = 0
用一用：夾角

兩條步道的方向分別是 (1, 1) 和 (0, 2)，夾角是多少？

內積 = 0 + 2 = 2，長度 √2 和 2 cosθ = 2 ／ (2√2) = √2／2 ⟹ θ = 45°
用一用：垂直

兩條步道方向 (k, 2) 和 (3, −6) 互相垂直，k 是多少？

3k − 12 = 0 ⟹ k = 4
內積與長度
a・a = |a|²
|a + b|² = |a|² + 2a・b + |b|²

兩人合力拉一台推車，一人 3 牛頓、一人 2 牛頓，兩力夾 60°。合力多大？

|合力|² = 9 + 2 × (3 × 2 × cos60°) + 4 = 9 + 6 + 4 = 19 |合力| = √19 ≈ 4.36（牛頓）
正射影

一個向量投在另一個方向上的影子

公式
a 在 b 方向上的正射影
正射影向量 = ((a・b)／|b|²)b
正射影長 = |a・b|／|b|
用一用
a = (2, 4)，b = (6, 2) a・b = 20，|b|² = 40 正射影 = (20／40)(6, 2) = (3, 1)，長度 √10
情境：順風逆風

單車社練習時，風對車的作用力是 (3, −1)（牛頓），車子往 (1, 0) 的方向（正東）騎。風在前進方向的分量是多少？是順風還是逆風？

正射影長 = (3, −1)・(1, 0) ／ 1 = 3 內積為正 ⟹ 順風，在前進方向上推了 3 牛頓

收進工具箱：3-2 平面向量的運算

內積同時有幾何定義（長度與夾角）和坐標算法，兩者互換就能解題。

名稱內容
內積a・b = |a||b|cosθ = x₁x₂ + y₁y₂
夾角cosθ = a・b／(|a||b|)
垂直a・b = 0
長度|a|² = a・a
正射影((a・b)／|b|²)b

練習題

1內積與夾角

a = (1, √3)、b = (√3, 1)，求內積與夾角。

參考答案
內積 = 2√3，長度都是 2 cosθ = 2√3／4 = √3／2 ⟹ θ = 30°
2垂直

(2, k) 與 (k − 3, 4) 垂直，求 k。

參考答案
2(k − 3) + 4k = 0 ⟹ 6k = 6 ⟹ k = 1
3長度

|a| = 2、|b| = 3，夾角 120°。求 a・b 與 |a + b|。

參考答案
a・b = 2 × 3 × (−1／2) = −3 |a + b|² = 4 − 6 + 9 = 7 ⟹ √7
4正射影

求 (4, 2) 在 (1, 1) 方向上的正射影向量。

參考答案
內積 6，|(1, 1)|² = 2 ⟹ 3(1, 1) = (3, 3)
5功

力 F = (5, 2)（牛頓）把物體從 (0, 0) 移到 (4, −1)（公尺），做了多少功？

參考答案
功 = F・d = 5 × 4 + 2 × (−1) = 18（焦耳）
