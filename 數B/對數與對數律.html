對數與對數律

筱葳的存款年利率 5%，每年計息一次。她想知道：幾年後存款會變成兩倍？要解的是 1.05ⁿ = 2，沒辦法化成同底數。這一節把數學1 的常用對數推廣到任何底數，學會三條對數律，並用「兩邊取 log」解出這類問題。情境例子為原創設計，利率為示意。

指數回答「乘幾次之後變多少」，對數回答「要乘幾次才會變這麼多」。數學1 學過以 10 為底的常用對數 log x；這一節讓底數可以是任何合法的正數，並整理出對數的運算規則：乘變加、除變減、次方變乘。這些規則讓查表和計算機都只需要 log 就能處理各種倍數問題。

對數的定義

「a 要幾次方才等於 b？」

定義
對數
aˣ = b ⟺ x = logₐb
底數 a > 0 且 a ≠ 1；真數 b > 0
底數 10 時省略不寫：log b = log₁₀b（常用對數）
log₂32 = 5　　　因為 2⁵ = 32 log₃(1／27) = −3　因為 3^(−3) = 1／27 log₉3 = 1／2　　　因為 9^(1／2) = 3 logₐ1 = 0，logₐa = 1

真數一定要是正數：不管 x 是多少，2ˣ 都大於 0，所以 log₂(−4)、log₂0 都沒有意義。

對數律

乘變加、除變減、次方變乘

由指數律得到

因為 aᵐ・aⁿ = a^(m+n)，「乘法」在指數上變成「加法」。翻譯成對數：

對數律（M、N > 0）
logₐ(MN) = logₐM + logₐN
logₐ(M／N) = logₐM − logₐN
logₐ(Mᵖ) = p・logₐM

常見錯誤：logₐ(M + N) 不能拆開。對數律只管乘、除、次方。

用一用
log₂24 − log₂3 = log₂8 = 3 log 4 + log 25 = log 100 = 2 log₅√125 = log₅5^(3／2) = 3／2
只背兩個值

已知 log 2 ≈ 0.3010、log 3 ≈ 0.4771、log 7 ≈ 0.8451，求 log 5、log 6、log 1.05 的近似值。

log 5 = log(10／2) = 1 − log 2 ≈ 0.6990 log 6 = log 2 + log 3 ≈ 0.7781 log 1.05 = log(105／100) = log 3 + log 5 + log 7 − 2 ≈ 0.4771 + 0.6990 + 0.8451 − 2 = 0.0212
兩邊取 log 解問題

存款幾年會翻倍？

情境

年利率 5%、每年計息，幾年後存款會變成兩倍？（log 2 ≈ 0.3010，log 1.05 ≈ 0.0212）

1.05ⁿ = 2 無法化成同底。兩邊取常用對數，用「次方變乘」把 n 拿下來：

log(1.05ⁿ) = log 2 n・log 1.05 = log 2 n = log 2 ／ log 1.05 ≈ 0.3010 ／ 0.0212 ≈ 14.2 ∴ 第 15 年底，存款會第一次超過兩倍

這個「兩邊取 log」的技巧，可以解出任何「已知倍數、求次數」的問題，例如人口成長、細菌繁殖、藥物代謝。

情境：估計位數

把 1 粒米放在棋盤第 1 格，第 2 格放 2 粒，第 3 格放 4 粒……第 64 格放 2⁶³ 粒。這個數有幾位數？

log(2⁶³) = 63 × log 2 ≈ 63 × 0.3010 = 18.963 ⟹ 2⁶³ ≈ 10^18.963，介於 10¹⁸ 和 10¹⁹ 之間 ⟹ 19 位數

這延續數學1 的位數估計：正整數 N 的位數 = log N 的整數部分 + 1。

用一用：地震規模

芮氏規模每增加 1，地震釋放的能量約變成 10^1.5 ≈ 31.6 倍。規模 7 的地震能量約是規模 5 的幾倍？

相差 2 級 ⟹ (10^1.5)² = 10³ = 1000 倍

收進工具箱：2-2 對數與對數律

對數是指數的反問題；對數律把乘除次方變成加減乘；「已知倍數、求次數」就兩邊取 log。

名稱內容
定義aˣ = b ⟺ x = logₐb（a > 0，a ≠ 1，b > 0）
特殊值logₐ1 = 0，logₐa = 1
對數律logₐMN = logₐM + logₐN；logₐ(M／N) = logₐM − logₐN；logₐMᵖ = p logₐM
解指數方程式aⁿ = b ⟹ n = log b ／ log a
常用值log 2 ≈ 0.3010，log 3 ≈ 0.4771，log 7 ≈ 0.8451

練習題

1定義

求 log₄64、log₂(1／8)、log 0.001。

參考答案
log₄64 = 3，log₂(1／8) = −3，log 0.001 = −3
2對數律

化簡 log₃54 − log₃2。

參考答案
log₃(54／2) = log₃27 = 3
3近似值

已知 log 2 ≈ 0.3010、log 3 ≈ 0.4771，求 log 72 與 log 0.18。

參考答案
log 72 = 3 log 2 + 2 log 3 ≈ 0.9030 + 0.9542 = 1.8572 log 0.18 = log(2 × 3² ／ 100) = 0.3010 + 0.9542 − 2 = −0.7448
4翻倍時間

某城市人口每年成長 2%，大約幾年會翻倍？（log 2 ≈ 0.3010，log 1.02 ≈ 0.0086）

參考答案
1.02ⁿ = 2 ⟹ n = 0.3010 ／ 0.0086 ≈ 35（年）
5位數

3⁴⁰ 是幾位數？（log 3 ≈ 0.4771）

參考答案
40 × 0.4771 = 19.084 ⟹ 20 位數
