數B 第四冊・第三章 機率・3-1

條件機率與獨立事件

學生會做了一份健康問卷，筱葳負責整理：200 位同學中，誰每天運動、誰睡眠充足。主任問：「有運動的人，睡眠比較充足嗎？」要回答這個問題，得先學會在「已知某件事」的前提下算機率。這一節用列聯表和文氏圖整理資料，學習條件機率、乘法原理，並判斷兩件事是否獨立。情境例子為原創設計。

數學2 的機率是在「全部的人」裡面算比例。但很多問題會先給一個條件：「已知他有運動」「已知今天下雨」。這時要算比例的範圍縮小了，這就是條件機率。如果加上條件之後機率完全沒變，就說兩件事獨立——彼此不影響。

主觀機率與客觀機率

機率從哪裡來？

比較
類型來源例子
客觀機率（古典）每種結果出現機會相等，用數的擲公正骰子出現 6 點：1／6
客觀機率（統計）大量重複觀察的相對次數問卷中每天運動的比例 80／200 = 0.4
主觀機率根據經驗與資訊的判斷「我覺得明天社團活動會順利辦成的機率是 90%」

主觀機率不是亂猜：氣象預報的降雨機率、醫師對病情的判斷，都是根據資料和經驗做的主觀機率，並且會隨著新資訊修正（3-2 的貝氏定理就是修正的方法）。

對照
P(A) = 80／200 = 0.4　　P(B) = 120／200 = 0.6 P(A ∩ B) = 60／200 = 0.3 P(A ∪ B) = P(A) + P(B) − P(A ∩ B) = 0.4 + 0.6 − 0.3 = 0.7

列聯表的每一格對應文氏圖的一塊：左上格是交集，「合計」列和行是兩個圓各自的大小。

條件機率與乘法原理

已知某件事發生，只看那一部分

情境

從 200 人中隨機抽一人。(1) 已知他每天運動，他睡眠充足的機率？(2) 已知他睡眠充足，他每天運動的機率？

(1) 只看「每天運動」那一列（80 人）：60／80 = 0.75 (2) 只看「睡眠充足」那一行（120 人）：60／120 = 0.5
條件機率（P(A) > 0）
P(B | A) = P(A ∩ B) ／ P(A)
讀作「在 A 發生的條件下，B 發生的機率」

P(B | A) = 0.75 和 P(A | B) = 0.5 不一樣：條件不同，分母就不同。

乘法原理
P(A ∩ B) = P(A)・P(B | A)

社團抽 2 位代表，8 位候選人中有 3 位是高二。不放回地依序抽，兩位都是高二的機率？

P(第 1 位高二) = 3／8 P(第 2 位高二 | 第 1 位高二) = 2／7 P(兩位都高二) = (3／8)(2／7) = 3／28
獨立事件

加上條件，機率沒變

定義
獨立事件
A、B 獨立 ⟺ P(A ∩ B) = P(A)・P(B)
（等價於 P(B | A) = P(B)）

回到問卷：「每天運動」和「睡眠充足」獨立嗎？

P(B) = 0.6，P(B | A) = 0.75 ≠ 0.6 ⟹ 不獨立 或檢查：P(A)・P(B) = 0.4 × 0.6 = 0.24 ≠ 0.3 = P(A ∩ B)

有運動的人睡眠充足的比例（75%）高於整體（60%），兩者有關聯。不過這只說明「有關」，不能直接說「運動造成睡眠充足」——也可能是其他原因（例如作息規律）同時影響兩者。

用一用：獨立的列聯表

另一份問卷：100 人中，喜歡貓的 40 人、戴眼鏡的 50 人，喜歡貓又戴眼鏡的 20 人。兩者獨立嗎？

P(貓)・P(眼鏡) = 0.4 × 0.5 = 0.2 = P(貓 ∩ 眼鏡) ⟹ 獨立 （喜歡貓的人中戴眼鏡比例 20／40 = 50%，和整體一樣）
獨立的應用

週六下雨機率 0.3，週日下雨機率 0.4，兩天互相獨立。週末兩天都不下雨的機率？至少一天下雨的機率？

都不下雨：0.7 × 0.6 = 0.42 至少一天下雨：1 − 0.42 = 0.58

獨立 ≠ 互斥。互斥是「不可能同時發生」；兩件事機率都大於 0 時，互斥就一定不獨立（知道 A 發生，B 就確定不會發生）。

收進工具箱：3-1 條件機率與獨立事件

列聯表的一列或一行就是「條件」；條件機率 = 那一格 ÷ 那一列（行）的合計。

名稱內容
主觀／客觀機率客觀：計數或相對次數；主觀：依經驗資訊判斷
聯集P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
條件機率P(B | A) = P(A ∩ B)／P(A)
乘法原理P(A ∩ B) = P(A)・P(B | A)
獨立P(A ∩ B) = P(A)・P(B) ⟺ P(B | A) = P(B)
有關 ≠ 因果不獨立只代表有關聯

練習題

1讀表

用本節的運動與睡眠列聯表，求「已知睡眠不足，他每天運動」的機率。

參考答案
睡眠不足 80 人，其中每天運動 20 人 ⟹ 20／80 = 1／4
2公式

P(A) = 0.5，P(B) = 0.4，P(A ∪ B) = 0.7。求 P(A | B)，並判斷是否獨立。

參考答案
P(A ∩ B) = 0.5 + 0.4 − 0.7 = 0.2 P(A | B) = 0.2／0.4 = 0.5 = P(A) ⟹ 獨立
3乘法原理

袋中 5 紅球、3 白球，不放回地取 2 球，求先紅後白的機率。

參考答案
(5／8)(3／7) = 15／56
4列聯表

某班 40 人，戴眼鏡 24 人；男生 20 人，其中戴眼鏡 12 人。「男生」和「戴眼鏡」獨立嗎？

參考答案
P(男) = 0.5，P(眼鏡) = 0.6，P(男 ∩ 眼鏡) = 12／40 = 0.3 0.5 × 0.6 = 0.3 ⟹ 獨立
5獨立

筱葳投籃命中率 0.6，各次獨立。投 3 次全部沒中的機率？至少中一次的機率？

參考答案
全沒中：0.4³ = 0.064 至少中一次：1 − 0.064 = 0.936

下一步：由結果回推原因

P(B | A) 和 P(A | B) 可以差很多。生活中常常知道其中一個、想求另一個：已知「有病的人篩檢會陽性」的機率，想知道「篩檢陽性的人真的有病」的機率。在 3-2「貝氏定理」，我們會學會這種反推。
