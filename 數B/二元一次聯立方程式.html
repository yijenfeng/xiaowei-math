二元一次聯立方程式

園遊會測量社賣飲料和點心，帳本只記了「一共賣 120 份、收入 5600 元」。各賣多少份？這是國中就會解的二元一次聯立方程式。這一節換一個角度看它：每個方程式是一條直線，而整組方程式也可以看成「用兩個向量組合出第三個向量」。從這兩個角度，我們能看出方程組什麼時候有唯一解、無解或無限多解。情境例子為原創設計。

國中學的加減消去法、代入消去法，告訴我們「怎麼解」。這一節要回答的是「為什麼有時候解不出來」。關鍵在於 3-1 的線性組合：兩個不平行的向量可以組合出任何向量；兩個平行的向量就不行。

解聯立方程式

加減消去法

情境

飲料每杯 40 元、點心每份 60 元，一共賣 120 份，收入 5600 元。各賣多少？

x + y = 120　　　　① 40x + 60y = 5600　②（除以 20：2x + 3y = 280） ② − 2 × ①：y = 280 − 240 = 40 x = 120 − 40 = 80 ∴ 飲料 80 杯、點心 40 份
直線的觀點

兩條直線的交點

觀察

每個二元一次方程式 ax + by = c 在坐標平面上是一條直線。聯立方程式的解，就是兩條直線的交點。以 x + y = 5、2x − y = 4 為例：

三種位置
兩直線解
相交於一點恰有一組解
平行不重合無解
重合無限多組解
向量的觀點

用兩個向量，組合出第三個向量

換個寫法

把 x + y = 5、2x − y = 4 的「x 的係數」和「y 的係數」分別直著讀：

x(1, 2) + y(1, −1) = (5, 4)

這正是 3-1 定向越野的第二關：用 x 張 (1, 2) 卡、y 張 (1, −1) 卡，走到 (5, 4)。解聯立方程式，就是在找線性組合的係數。

一般形式
二元一次聯立方程式的向量形式
a₁x + b₁y = c₁、a₂x + b₂y = c₂
⟺ x(a₁, a₂) + y(b₁, b₂) = (c₁, c₂)
解的三種情形

看兩個係數向量是否平行

規律

設 u = (a₁, a₂)、v = (b₁, b₂)、w = (c₁, c₂)：

判斷方法
u、v 不平行 ⟹ 恰有一組解（兩張不平行的卡能走到任何地方）
u ∥ v，且 w 也和它們平行 ⟹ 無限多組解
u ∥ v，但 w 不和它們平行 ⟹ 無解（走不到直線外的點）

u ∥ v 的條件是 a₁ : a₂ = b₁ : b₂，也就是 a₁b₂ − a₂b₁ = 0。

用一用

判斷下列方程組的解：(1) x + 2y = 3、2x + 4y = 6；(2) x + 2y = 3、2x + 4y = 7。

係數向量 (1, 2) 和 (2, 4) 平行（後者是前者的 2 倍） (1) 常數向量 (3, 6) 也和 (1, 2) 平行 ⟹ 無限多組解 （兩式其實是同一條直線 x + 2y = 3） (2) 常數向量 (3, 7) 不和 (1, 2) 平行 ⟹ 無解 （兩條平行的直線）
情境：帳目有沒有問題？

另一個攤位的飲料和點心都賣 50 元。學弟的帳寫著：「共賣 100 份，收入 5200 元。」能算出各賣幾份嗎？

x + y = 100，50x + 50y = 5200 向量形式：x(1, 50) + y(1, 50) = (100, 5200) 兩個係數向量相同（當然平行） (100, 5200) 和 (1, 50) 平行嗎？100 × 50 = 5000 ≠ 5200 ⟹ 不平行 ⟹ 無解

無解代表帳一定記錯了：每份都是 50 元，100 份只可能收 5000 元。如果收入真的是 5000 元，則變成無限多組解——帳是對的，但無法分辨飲料和點心各賣幾份。

收進工具箱：3-3 二元一次聯立方程式

解聯立方程式 = 找兩直線的交點 = 找線性組合的係數。係數向量不平行就有唯一解。

名稱內容
直線觀點相交 → 一組解；平行 → 無解；重合 → 無限多解
向量形式x(a₁, a₂) + y(b₁, b₂) = (c₁, c₂)
唯一解(a₁, a₂)、(b₁, b₂) 不平行，即 a₁b₂ − a₂b₁ ≠ 0
無限多解三個向量都平行
無解係數向量平行，常數向量不平行

練習題

1求解

解 3x + 2y = 12、x − y = −1。

參考答案
x = y − 1 代入：3y − 3 + 2y = 12 ⟹ y = 3，x = 2
2向量形式

把 2x − y = 5、x + 3y = 6 寫成向量形式，並求解。

參考答案
x(2, 1) + y(−1, 3) = (5, 6) 由第一式 y = 2x − 5 代入：x + 6x − 15 = 6 ⟹ x = 3，y = 1
3判斷

判斷 3x − 6y = 9、−x + 2y = −3 的解的情形。

參考答案
係數向量 (3, −1)、(−6, 2)：(−6, 2) = −2(3, −1)，平行 常數向量 (9, −3) = 3(3, −1)，也平行 ⟹ 無限多組解
4參數

方程組 x + ky = 2、2x + 6y = 5 無解，求 k。

參考答案
係數向量 (1, 2)、(k, 6) 平行 ⟹ 6 − 2k = 0 ⟹ k = 3 此時兩式為 x + 3y = 2 與 x + 3y = 2.5，平行不重合 ⟹ 無解 ✓
5應用

買 2 杯奶茶和 3 塊蛋糕共 330 元；買 3 杯奶茶和 1 塊蛋糕共 250 元。奶茶和蛋糕各多少錢？

參考答案
2x + 3y = 330，3x + y = 250 ⟹ y = 250 − 3x 2x + 750 − 9x = 330 ⟹ x = 60，y = 70 奶茶 60 元、蛋糕 70 元
