數B 第四冊・第二章 矩陣・2-1

矩陣的運算

學生會讓測量社在兩個校區各擺一個飲料攤，筱葳負責記帳。每天的銷售量是一張表：兩個攤位、三種飲料。要算兩天合計、比較兩天差多少、預估下學期銷量變成 1.2 倍——如果把表格當成一個整體來運算，就會簡單很多。這一節認識矩陣，學會矩陣的加減與係數積。情境例子為原創設計。

把一群數字排成長方形的表格，就是矩陣。表格在生活中到處都是：課表、成績單、銷售報表、營養成分表。矩陣的好處是能把整張表當作一個東西來加減乘，不用一格一格算。這一節先學最直觀的運算：加減和係數積。

矩陣的意義

把表格的數字框起來

情境

第一天兩個攤位的銷售量（杯）：

紅茶奶茶檸檬汁
A 攤302010
B 攤253515

只保留數字，記成矩陣：

P = 302010253515
矩陣的名詞
橫的叫列，直的叫行；m 列 n 行稱為 m × n 矩陣（P 是 2 × 3）
第 i 列第 j 行的數稱為 (i, j) 元，記作 aᵢⱼ
列數等於行數的矩陣稱為方陣

P 的 (2, 3) 元是 15：B 攤第一天賣出 15 杯檸檬汁。讀矩陣時一定要記得「列代表什麼、行代表什麼」。

相等
兩個矩陣相等 ⟺ 大小相同，而且每個對應位置的數都相等

若 x + 134y = 534−2，求 x、y。

x + 1 = 5 ⟹ x = 4；y = −2
加法與減法

對應位置相加減

情境

第二天的銷售量是 Q = 403010352525。兩天合計各賣多少？第二天比第一天多賣多少？

P + Q = 30+4020+3010+1025+3535+2515+25 = 705020606040 Q − P = 1010010−1010

Q − P 的 (2, 2) 元是 −10：B 攤的奶茶第二天少賣 10 杯。

矩陣的加減
大小相同的矩陣才能相加減：對應位置的數相加減

2 × 3 的矩陣不能和 3 × 2 的矩陣相加——就像兩張欄位不同的報表不能直接相加。

性質
交換律 A + B = B + A；結合律 (A + B) + C = A + (B + C)
所有元都是 0 的矩陣稱為零矩陣 O：A + O = A
係數積

整張表乘上同一個倍數

情境

學生會預估下學期每天的銷量都會是第一天的 1.2 倍。預估表是什麼？

1.2P = 362412304218
係數積
kA：每個元都乘以 k
k(A + B) = kA + kB；(k + h)A = kA + hA
用一用：平均

兩天平均每天各賣多少？

(1／2)(P + Q) = (1／2)705020606040 = 352510303020
用一用：解矩陣方程式

若 2X + A = B，A = 1234、B = 56710，求 X。

2X = B − A = 4446 ⟹ X = 2223

矩陣的加減和係數積遵守和數字一樣的規則，所以可以像解一元一次方程式那樣移項。

收進工具箱：2-1 矩陣的運算

矩陣就是資料表；加減要同大小、對應位置算；係數積是每個元都乘。

名稱內容
大小m 列 n 行 ⟹ m × n 矩陣
(i, j) 元第 i 列第 j 行
相等大小相同且對應元相等
加減同大小，對應元相加減
係數積每個元乘以 k
零矩陣A + O = A
