週期性數學模型

筱葳幫學生會規劃一年的戶外活動，想知道每個月大概多熱。她查了台北的月平均氣溫，畫成圖後發現：一年一個循環，像一條波浪。這一節從單位圓出發畫出正弦函數的圖形，認識週期與振幅，再用 y = a・sin(b(x − h)) + k 替氣溫、摩天輪高度建立數學模型。情境例子為原創設計，氣溫為近似值。

數學2 把正弦定義在任意角上：在單位圓上轉了角度 x，點的 y 坐標就是 sinx。有了弧度，x 可以是任何實數，sinx 就成了一個函數。它最重要的特性是週期性：轉一圈回到原處，函數值就重來一次。生活中所有「固定時間重複一次」的現象，都可以用調整過高低、快慢、位置的正弦曲線來描述。

性質
y = sinx 的性質
定義域：全體實數；值域：−1 ≤ y ≤ 1
週期 2π：sin(x + 2π) = sinx
最大值 1 在 x = π／2 + 2kπ；最小值 −1 在 x = 3π／2 + 2kπ

若 f(x + p) = f(x) 對所有 x 都成立，f 就稱為週期函數，最小的正數 p 叫做週期。

振幅與週期

拉高、壓扁、搬家

觀察
y = 3sinx：每個值乘 3 → 高低變成 −3 到 3，週期不變（振幅 3） y = sin(x／2)：x 要走到 4π，x／2 才走完 2π → 週期變成 4π，高低不變
規律 → 公式
y = a・sin(b(x − h)) + k（a > 0，b > 0）
振幅 a，週期 2π／b，中心線 y = k
最大值 k + a，最小值 k − a
h：圖形往右平移 h（在 x = h 時從中心線往上爬）

記法：外面乘的 a 管高低，x 前面乘的 b 管快慢，外面加的 k 管整條波的高度，括號裡減的 h 管起跑點。

建立週期性模型

從資料讀出四個參數

情境：一年的氣溫

台北月平均氣溫大約在 1 月最低、約 16°C，7 月最高、約 30°C，一年一個循環。用 T(m) = a・sin(b(m − h)) + k 建模（m 為月份）。

中心線 k = (30 + 16)／2 = 23 振幅 a = (30 − 16)／2 = 7 週期 12 個月 ⟹ b = 2π／12 = π／6 最高點在 7 月，正弦在「起跑點後 1／4 週期」到達最高 ⟹ 起跑點 h = 7 − 3 = 4 T(m) = 7sin(π(m − 4)／6) + 23
檢查： m = 4（4 月）：T = 7sin0 + 23 = 23 m = 7（7 月）：T = 7sin(π／2) + 23 = 30 ✓ m = 1（1 月）：T = 7sin(−π／2) + 23 = 16 ✓ m = 10（10 月）：T = 7sinπ + 23 = 23
用模型做判斷

學生會想把戶外活動排在月平均氣溫 26.5°C 以下的月份。哪些月份不適合？

T(m) > 26.5 ⟺ 7sin(π(m − 4)／6) > 3.5 ⟺ sin(π(m − 4)／6) > 1／2 sinθ > 1／2 ⟺ π／6 < θ < 5π／6 π／6 < π(m − 4)／6 < 5π／6 ⟹ 1 < m − 4 < 5 ⟹ 5 < m < 9 ∴ 6、7、8 月不適合（5 月與 9 月剛好是 26.5°C）
情境：摩天輪

遊樂園摩天輪半徑 40 公尺、轉軸離地 45 公尺，轉一圈 20 分鐘。筱葳從最低點上車，寫出 t 分鐘後的高度。

k = 45，a = 40，週期 20 ⟹ b = 2π／20 = π／10 最低點在 t = 0，最高點在 t = 10；在 t = 5 時剛好經過中心線往上爬 ⟹ h = 5 h(t) = 40sin(π(t − 5)／10) + 45 t = 0：40sin(−π／2) + 45 = 5（最低）✓ t = 10：40sin(π／2) + 45 = 85（最高）✓
建模步驟
從資料寫出 y = a・sin(b(x − h)) + k
1. k = (最大 + 最小)／2
2. a = (最大 − 最小)／2
3. b = 2π／週期
4. h = 最大值發生的時刻 − 週期／4（也就是「從中心線往上爬」的時刻）

收進工具箱：1-2 週期性數學模型

正弦曲線的四個參數：振幅、週期、中心線、起跑點。從最大、最小值和週期就能讀出它們。

名稱內容
y = sinx週期 2π；值域 [−1, 1]
一般式y = a・sin(b(x − h)) + k
振幅／週期a；2π／b
最大／最小k + a；k − a
建模k = (大 + 小)／2，a = (大 − 小)／2，b = 2π／週期

練習題

1讀參數

求 y = 4sin(2x) − 1 的振幅、週期、最大值與最小值。

參考答案
振幅 4，週期 2π／2 = π 最大值 −1 + 4 = 3，最小值 −1 − 4 = −5
2週期

y = sin(πx／3) 的週期是多少？

參考答案
2π ÷ (π／3) = 6
3建模

某港口水深每 12 小時循環一次，最深 8 公尺、最淺 2 公尺，在凌晨 3 點最深。用 d(t) = a・sin(b(t − h)) + k 寫出模型（t 為午夜起算的小時數）。

參考答案
k = 5，a = 3，b = 2π／12 = π／6 h = 3 − 12／4 = 0 d(t) = 3sin(πt／6) + 5（檢查 t = 3：3sin(π／2) + 5 = 8 ✓）
4代值

用本節的氣溫模型 T(m) = 7sin(π(m − 4)／6) + 23，估計 5 月的平均氣溫。

參考答案
T(5) = 7sin(π／6) + 23 = 3.5 + 23 = 26.5（°C）
5不等式

用第 3 題的模型，求 0 ≤ t ≤ 12 之間，水深至少 6.5 公尺的時段。

參考答案
3sin(πt／6) + 5 ≥ 6.5 ⟺ sin(πt／6) ≥ 1／2 π／6 ≤ πt／6 ≤ 5π／6 ⟹ 1 ≤ t ≤ 5 ∴ 凌晨 1:00 到 5:00
