空間坐標

營隊最後一晚有無人機燈光秀，測量社負責寫定位指令。每台無人機的位置只能用三個數字：往東幾公尺、往北幾公尺、往上幾公尺。這一節建立空間坐標系，學會空間中兩點的距離公式、中點，以及點在坐標平面和坐標軸上的投影與對稱。情境例子為原創設計。

平面上一個點用 (x, y) 表示；空間中要多一個方向「上下」，所以用 (x, y, z)。距離公式也是平面版本多一項：本質上是連用兩次畢氏定理。

空間坐標系

三條互相垂直的數線

情境

以起降平台為原點 O，x 軸朝東、y 軸朝北、z 軸朝上。1 號無人機收到指令「(3, 4, 3)」，它要飛到哪裡？

先往東 3、往北 4，到達地面上的 Q(3, 4, 0)；再往上 3，就是 P(3, 4, 3)。

空間坐標系
三軸兩兩垂直，交於原點 O
三個坐標平面：xy 平面（z = 0，地面）、yz 平面（x = 0）、xz 平面（y = 0）
三個坐標平面把空間分成 8 個卦限
距離與中點

兩次畢氏定理

推導
OQ（地面上）= √(3² + 4²) = 5 OP = √(OQ² + 3²) = √(25 + 9) = √34
兩點距離與中點
AB = √((x₂−x₁)² + (y₂−y₁)² + (z₂−z₁)²)
中點 = ((x₁+x₂)／2, (y₁+y₂)／2, (z₁+z₂)／2)
情境

2 號無人機在 A(1, 2, 3)，3 號在 B(4, 6, 15)。兩台相距多遠？若 4 號要停在兩台正中間，位置是哪裡？

AB = √(3² + 4² + 12²) = √169 = 13（公尺） 中點 = (2.5, 4, 9)
用一用：安全距離

規定兩台無人機至少相距 5 公尺。C(2, 1, 4) 和 D(5, 3, 6) 符合規定嗎？

CD = √(9 + 4 + 4) = √17 ≈ 4.12 < 5 ⟹ 太近，不符合
投影與對稱

保留哪些坐標、改掉哪些坐標

情境

地面投射燈要打在 P(3, −2, 5) 的正下方。正下方是哪一點？P 離地多高？離起降平台的垂直桿（z 軸）多遠？

正下方（投影到 xy 平面）：(3, −2, 0) 離地高度 = |z| = 5 離 z 軸的距離 = √(3² + (−2)²) = √13 ≈ 3.61
整理
P(a, b, c) 的結果
投影到 xy 平面(a, b, 0)；P 到 xy 平面距離 |c|
投影到 x 軸(a, 0, 0)；P 到 x 軸距離 √(b² + c²)
對 xy 平面對稱(a, b, −c)
對 x 軸對稱(a, −b, −c)
對原點對稱(−a, −b, −c)

口訣：投影到哪裡，就保留那裡的坐標，其餘改 0；對哪裡對稱，就保留那裡的坐標，其餘變號。

收進工具箱：1-2 空間坐標

空間坐標 = 平面坐標多一個 z；距離公式多一項平方。

名稱內容

中點各坐標取平均
到原點√(a² + b² + c²)

練習題

1距離

求 A(1, −2, 3) 與 B(3, 1, −3) 的距離與中點。

參考答案
√(4 + 9 + 36) = 7；中點 (2, −1／2, 0)
2投影

P(2, −3, 6) 在 yz 平面上的投影點是什麼？P 到 y 軸的距離是多少？

參考答案
投影 (0, −3, 6) 到 y 軸：√(2² + 6²) = √40 = 2√10
3對稱

P(1, 2, −4) 對 xz 平面、對 z 軸的對稱點各是什麼？

參考答案
對 xz 平面：(1, −2, −4) 對 z 軸：(−1, −2, −4)
4等距點

x 軸上一點 P 到 A(1, 2, 2) 和 B(3, 0, 1) 的距離相等，求 P。

參考答案
P(t, 0, 0)：(t − 1)² + 4 + 4 = (t − 3)² + 0 + 1 t² − 2t + 9 = t² − 6t + 10 ⟹ 4t = 1 ⟹ t = 1／4 P(1／4, 0, 0)
5應用

房間長 4、寬 3、高 2.4（公尺）。以一個牆角為原點建坐標，天花板最遠的角落坐標是什麼？兩點距離多少？

參考答案
(4, 3, 2.4)；√(16 + 9 + 5.76) = √30.76 ≈ 5.55（公尺）

下一步：球面

「到某一點距離都相等的點」在平面上是圓，在空間中就是球面。地球近似一個球，經線和緯線就畫在球面上。在 1-3「球面與圓錐截痕」，我們會用空間坐標寫出球面，算出緯線的長度，並看看用平面切圓錐會切出哪些曲線。
