平面向量

測量社辦了一場校園定向越野：地圖畫在方格上，每張提示卡只寫「往右幾格、往上幾格」。筱葳發現，提示卡可以接著走、可以倒著走、也可以走兩倍遠。這一節認識向量——同時有大小和方向的量——學會用坐標表示它、做加減與係數積，並用兩張提示卡組合出任何路線。情境例子為原創設計。

「走 500 公尺」不夠清楚，還要說往哪走。位移、速度、力這種需要大小和方向的量，叫做向量；只要一個數字的量（溫度、價錢）叫做純量。在方格地圖上，向量就是一對數字 (x, y)，所有運算都是 x 和 x 算、y 和 y 算。

向量的表示法

終點減始點

情境

提示卡寫「右 3、上 4」。筱葳從 A(1, 2) 走到 B(4, 6)，學妹從 C(5, 0) 走到 D(8, 4)。兩人走的是同一個向量嗎？

AB = (4 − 1, 6 − 2) = (3, 4) CD = (8 − 5, 4 − 0) = (3, 4) 坐標相同 ⟹ 同一個向量（長度、方向都一樣，只是起點不同）
公式
向量的坐標與長度
A(x₁, y₁)，B(x₂, y₂) ⟹ AB = (x₂ − x₁, y₂ − y₁)
長度 |(a, b)| = √(a² + b²)
|(3, 4)| = √(9 + 16) = 5

長度為 1 的向量叫單位向量。與 (3, 4) 同方向的單位向量是 (3, 4) ÷ 5 = (3／5, 4／5)。

加減與係數積

接著走、倒著走、走幾倍

加法：接著走

先照 a = (4, 1) 走，再照 b = (2, 4) 走，總位移是多少？

a + b = (4 + 2, 1 + 4) = (6, 5)

先走 b 再走 a 也會到同一個終點，兩條路線圍成一個平行四邊形，a + b 是它的對角線。

減法與係數積
運算規則
(x₁, y₁) ± (x₂, y₂) = (x₁ ± x₂, y₁ ± y₂)
k(x, y) = (kx, ky)：長度變 |k| 倍，k < 0 時方向相反
a = (2, −1)，b = (−1, 3) 2a − 3b = (4, −2) − (−3, 9) = (7, −11)
情境：渡河

橡皮艇船頭朝正對岸，靜水速度 4 公里／時；河水往右流 3 公里／時。實際速度是多少？

(0, 4) + (3, 0) = (3, 4)，速率 = 5 公里／時
平行向量

一個是另一個的倍數

規律
平行與三點共線
a ∥ b ⟺ a = tb ⟺ 兩向量的分量成比例
A、B、C 共線 ⟺ AB ∥ AC

檢查點 A(1, 1)、B(3, 4)、C(7, k) 在一直線上，k 是多少？

AB = (2, 3)，AC = (6, k − 1) x 分量是 3 倍 ⟹ k − 1 = 3 × 3 = 9 ⟹ k = 10
線性組合

兩張不平行的卡，可以走到任何地方

情境

第二關只有兩種卡：a = (1, 2)、b = (1, −1)。檢查點在 (5, 4)，各要用幾張？

xa + yb = (5, 4) x + y = 5，2x − y = 4 ⟹ x = 3，y = 2 3 張 a 卡、2 張 b 卡
線性組合
xa + yb 稱為 a、b 的線性組合
a、b 不平行時，平面上任何向量都能唯一寫成 xa + yb

如果兩張卡平行，例如 (1, 2) 和 (2, 4)，只能在一條直線上來回，到不了直線外的點。

分點

補給站 P 要設在 A(1, 2) 到 B(7, 5) 的步道上，AP : PB = 2 : 1。P 在哪裡？

P = A + (2／3)AB = (1, 2) + (2／3)(6, 3) = (1, 2) + (4, 2) = (5, 4)

寫成線性組合：OP = (1／3)OA + (2／3)OB，兩個係數加起來是 1。

收進工具箱：3-1 平面向量

向量 = 一對數字；加減乘都對分量做。兩個不平行的向量可以組合出平面上任何向量。

名稱內容
坐標AB = B − A
長度|(a, b)| = √(a² + b²)
加減、係數積分量各自運算
平行分量成比例；共線 ⟺ AB ∥ AC
線性組合a、b 不平行 ⟹ xa + yb 可表示任何向量
分點AP : PB = m : n ⟹ P = (nA + mB)／(m + n)

練習題

1坐標與長度

A(−2, 5)、B(4, −3)，求 AB 與它的長度。

參考答案
(6, −8)，長度 10
2運算

a = (3, −2)、b = (−1, 4)，求 a + 2b。

參考答案
(3 − 2, −2 + 8) = (1, 6)
3平行

(2, k) 與 (6, 9) 平行，求 k。

參考答案
(6, 9) = 3(2, 3) ⟹ k = 3
4線性組合

把 (7, 0) 寫成 x(1, 2) + y(2, −1)。

參考答案
x + 2y = 7，2x − y = 0 ⟹ y = 2x，5x = 7 x = 7／5，y = 14／5
5分點

A(2, −1)、B(−4, 8)，P 在 AB 上且 AP : PB = 1 : 2，求 P。

參考答案
P = (2A + B)／3 = ((4 − 4)／3, (−2 + 8)／3) = (0, 2)
