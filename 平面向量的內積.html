平面向量的內積

定向越野結束後，筱葳拖著裝滿器材的行李箱走回社辦。她注意到：拉桿越斜，手越累，箱子卻沒有走得比較快。物理老師說，因為只有「順著前進方向」的那部分力真的在做功。這一節把這個想法變成向量的內積，用它算夾角、判斷垂直、求正射影，並推出柯西不等式與三角不等式。情境例子為原創設計。

兩個向量相乘，可以有不同的定義方式。高中數學最重要的一種叫內積：它把兩個向量變成一個數，這個數同時反映兩者的長度與夾角。內積是向量裡最好用的工具——夾角、垂直、投影、距離、最大最小值，全都能用它處理。

內積的定義

長度乘長度，再乘上夾角的 cos

情境

筱葳用 50 牛頓的力拉行李箱，拉桿和地面夾 60°，沿著地面走了 20 公尺。她做了多少功？

功 = 「沿位移方向的力」× 位移。拉力沿地面方向的分量是 50cos60°（數學2的正射影長）：

功 W = (50 × cos60°) × 20 = 25 × 20 = 500（焦耳） 一般地：W = |F|・|d|・cosθ
規律 → 定義
內積（θ 為兩向量夾角，0 ≤ θ ≤ π）
a・b = |a||b|cosθ
夾角 θ內積的正負拉行李箱的意義
銳角a・b > 0力在幫忙前進
直角a・b = 0力完全沒幫上忙（只是提著）
鈍角a・b < 0力在扯後腿

特別情況：a・a = |a|²（自己和自己夾 0°）。這條式子讓我們能用內積算長度。

坐標表示與夾角

對應分量相乘再相加

觀察 → 規律

有坐標時，怎麼不量角度就算出內積？把 a、b、a − b 看成三角形三邊，用數學2的餘弦定理：

|a − b|² = |a|² + |b|² − 2|a||b|cosθ 設 a = (x₁, y₁)，b = (x₂, y₂)： (x₁ − x₂)² + (y₁ − y₂)² = (x₁² + y₁²) + (x₂² + y₂²) − 2a・b 展開消去 ⟹ a・b = x₁x₂ + y₁y₂
內積的坐標表示
(x₁, y₁)・(x₂, y₂) = x₁x₂ + y₁y₂
夾角：cosθ = (a・b)／(|a||b|)
垂直：a ⊥ b ⟺ a・b = 0 ⟺ x₁x₂ + y₁y₂ = 0
用一用
(1, √3) 與 (√3, 1) 的夾角： 內積 = √3 + √3 = 2√3，兩者長度都是 2 cosθ = 2√3 ／ 4 = √3／2 ⟹ θ = 30° (k, 2) ⊥ (3, −6)：3k − 12 = 0 ⟹ k = 4
運算性質
內積的性質
a・b = b・a；a・(b + c) = a・b + a・c；(ka)・b = k(a・b)
|a ± b|² = |a|² ± 2a・b + |b|²

兩股拉力，一股 3 牛頓、一股 2 牛頓，夾角 60°，合力多大？

|a + b|² = 3² + 2 × (3 × 2 × cos60°) + 2² = 9 + 6 + 4 = 19 |a + b| = √19 ≈ 4.36（牛頓）

|a ± b|² 的展開和 (a ± b)² 長得一樣，只是中間項變成內積。沒有坐標、只知道長度和夾角時，求合向量長度就靠它。

正射影

一個向量投在另一個向量上的影子

規律 → 公式

行李箱的例子裡，「|F|cosθ」就是拉力在前進方向上的影子長度。一般地，a 在 b 方向上的影子：

a 在 b 上的正射影
正射影向量 = ((a・b)／|b|²)b
正射影長 = |a・b|／|b|

記法：|a|cosθ 是有正負的影子長，再乘上 b 方向的單位向量 b／|b|。把 |a|cosθ 換成 (a・b)／|b| 就得到上面的公式。

用一用
a = (2, 4)，b = (6, 2) a・b = 12 + 8 = 20，|b|² = 40 正射影向量 = (20／40)(6, 2) = (3, 1) 正射影長 = 20 ／ √40 = √10 檢查：a − (3, 1) = (−1, 3)，與 b 的內積 = −6 + 6 = 0 ✓（垂直）
柯西不等式與三角不等式

|cosθ| ≤ 1 帶來的兩個不等式

觀察 → 規律：柯西不等式

因為 −1 ≤ cosθ ≤ 1，所以 |a・b| = |a||b||cosθ| ≤ |a||b|。兩邊平方、寫成坐標：

柯西不等式
(x₁x₂ + y₁y₂)² ≤ (x₁² + y₁²)(x₂² + y₂²)
等號成立 ⟺ (x₁, y₁) 與 (x₂, y₂) 平行（cosθ = ±1）
用一用：求最大值

實數 x、y 滿足 x² + y² = 1，求 3x + 4y 的最大值。

把 3x + 4y 看成 (3, 4)・(x, y)： (3x + 4y)² ≤ (3² + 4²)(x² + y²) = 25 × 1 = 25 ⟹ −5 ≤ 3x + 4y ≤ 5 等號：(x, y) ∥ (3, 4) 且長度 1 ⟹ (x, y) = (3／5, 4／5) 時最大值 5

令 x = cosθ、y = sinθ，這題就是 1-4 的疊合：3cosθ + 4sinθ 的最大值是 5。兩種方法殊途同歸。

用一用：求最小值

實數 x、y 滿足 2x + y = 10，求 x² + y² 的最小值。

(2x + y)² ≤ (2² + 1²)(x² + y²) ⟹ 100 ≤ 5(x² + y²) ⟹ x² + y² ≥ 20 等號：(x, y) = t(2, 1)，代入 2x + y = 10 ⟹ 5t = 10 ⟹ t = 2，(x, y) = (4, 2) 最小值 20

幾何意義：x² + y² 是點 (x, y) 到原點距離的平方，最小值 20 代表原點到直線 2x + y = 10 的距離是 √20 = 2√5——和數學1的點到直線距離公式算出來一樣。

三角不等式

定向越野的兩段路線分別長 3 公里和 5 公里。不知道方向的情況下，終點離起點最遠、最近各多少？

三角不等式
|a| − |b| ≤ |a + b| ≤ |a| + |b|（左邊取絕對值）
右邊等號：a、b 同向；左邊等號：a、b 反向
5 − 3 ≤ |總位移| ≤ 5 + 3 ⟹ 最近 2 公里（往回走），最遠 8 公里（同方向）

證明：|a + b|² = |a|² + 2a・b + |b|² ≤ |a|² + 2|a||b| + |b|² = (|a| + |b|)²，用的正是柯西不等式。直觀意義就是「三角形兩邊和大於第三邊」。

收進工具箱：3-3 平面向量的內積

內積同時有幾何定義（長度與夾角）和代數定義（坐標），在兩者之間切換就是解題的核心。

名稱內容
定義a・b = |a||b|cosθ
坐標(x₁, y₁)・(x₂, y₂) = x₁x₂ + y₁y₂
夾角／垂直cosθ = a・b／(|a||b|)；a ⊥ b ⟺ a・b = 0
長度|a|² = a・a；|a ± b|² = |a|² ± 2a・b + |b|²
正射影向量 ((a・b)／|b|²)b；長度 |a・b|／|b|

練習題

1內積與夾角

a = (2, −1)，b = (3, 4)，求 a・b 與兩向量夾角的餘弦值。

參考答案
a・b = 6 − 4 = 2 cosθ = 2 ／ (√5 × 5) = 2√5／25
2長度與夾角

|a| = 2，|b| = 3，a・b = −3。求兩向量夾角與 |2a + b|。

參考答案
cosθ = −3 ／ 6 = −1／2 ⟹ θ = 120° |2a + b|² = 4|a|² + 4a・b + |b|² = 16 − 12 + 9 = 13 |2a + b| = √13
3垂直

a = (1, 2)，b = (3, −1)。若 a + tb 與 a 垂直，求 t。

參考答案
(a + tb)・a = |a|² + t(a・b) = 5 + t(3 − 2) = 5 + t = 0 t = −5
4正射影

求 a = (4, 2) 在 b = (1, 1) 上的正射影向量。

參考答案
a・b = 6，|b|² = 2 正射影 = (6／2)(1, 1) = (3, 3)
5柯西不等式

x² + y² = 10，求 x + 3y 的最大值，以及此時的 (x, y)。

參考答案
(x + 3y)² ≤ (1² + 3²)(x² + y²) = 100 ⟹ x + 3y ≤ 10 等號：(x, y) = t(1, 3)，10t² = 10，取 t = 1 ⟹ (x, y) = (1, 3) 最大值 10

下一步：兩個向量圍出的面積

內積用 cos 量「兩向量有多同方向」。如果改用 sin，就能量「兩向量張得有多開」——也就是它們圍出的三角形與平行四邊形面積。在 3-4「面積與二階行列式」，我們會用坐標直接算出面積，認識二階行列式，並用它一步解出二元一次聯立方程式。
