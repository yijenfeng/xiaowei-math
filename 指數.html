指數

依照筱葳課本章節重新編寫：從細菌繁殖、放射性物質衰減，一路推出整數指數、有理數指數、實數指數，最後學會用科學記號紀錄超大或超小的數字。

指數原本只是「連乘」的簡寫，但課本開頭就點出重點：人口成長、複利、地震規模、放射性衰減這些現象，數字動輒差到幾百萬倍，用指數描述才寫得下、算得動。這一節依課本順序，把指數的定義從整數一路擴展到所有實數。

PART 1 ・ 整數指數與指數律

細菌一分為二，指數登場

情境

生物實驗室裡有一種細菌，每經過 1 小時就會分裂一次，數量變成原來的 2 倍。老師在培養皿裡只放入 1 隻細菌，想知道：經過 10 個小時後，培養皿裡會有多少隻細菌？這個數字用一般記數法寫出來，會是一長串很難唸的數字。

觀察

細菌數量是「每過 1 小時，乘以 2」：經過 1 小時變成 2 倍，經過 2 小時變成 2×2=4 倍，經過 3 小時變成 2×2×2=8 倍……經過 10 小時，就是 10 個 2 連乘。把 2×2×2×……×2（10 個 2）寫成 2¹⁰，就是指數記號存在的理由——把「連乘 n 次同一個數」壓縮成一個簡潔的符號：

aⁿ = a×a×a×……×a（共 n 個 a）　　a 稱為底數，n 稱為指數
規律 → 公式：正整數指數律

沿用細菌一小時一小時往後長的邏輯：如果先培養 m 小時（數量變成 aᵐ 倍），再繼續培養 n 小時（在此基礎上再變成 aⁿ 倍），總共培養了 m+n 小時，數量會變成原本的 aᵐ⁺ⁿ 倍：

(1) aᵐ·aⁿ = aᵐ⁺ⁿ　　　(2) (aᵐ)ⁿ = aᵐⁿ　　　(3) aⁿ·bⁿ = (ab)ⁿ

(2) 的意思是「疊 m 階為一組，重複 n 組」；(3) 的意思是「兩個東西各自成長 n 次方，等於兩者相乘後再成長 n 次方」，例如兩個維度同時放大 n 倍，面積會放大 nⁿ… 不，是放大 (邊長比)ⁿ 倍，可以自己代小數字驗證。

延伸：反向倒推，逼出 0 與負指數

指數律 aᵐ·aⁿ=aᵐ⁺ⁿ 反過來想，除法自然對應指數相減：

2⁴/2⁷ = (2×2×2×2)/(2×2×2×2×2×2×2) = 1/2³　　也可以直接寫成　2⁴⁻⁷=2⁻³

兩式必須相等，所以 2⁻³ = 1/2³。同樣的道理，如果分子分母指數相同：

2⁵/2⁵ = 1　　　但用指數律硬套：2⁵⁻⁵=2⁰　　⟹　　2⁰ = 1

推廣成一般規則：

整數指數的定義（a≠0，n 為正整數）
aⁿ = a×a×……×a（n 個 a）　　　a⁰ = 1　　　a⁻ⁿ = 1/aⁿ

這裡特別限定 a≠0：0ⁿ=0（n 為正整數）沒問題，但 0⁰ 和 0⁻ⁿ 都沒有意義（0 不能當分母）。

回到應用：放射性物質的半衰期

鈷-60 是常見的放射性物質，每經過 5.2714 年，含量就會衰減成原本的一半（這段時間稱為半衰期）。如果一開始有 100 單位的鈷-60，經過 n 個半衰期後，會剩下多少？

經過 1 個半衰期：100 × (1/2)¹ 經過 2 個半衰期：100 × (1/2)² 經過 n 個半衰期：100 × (1/2)ⁿ

如果已知衰減到只剩 12.5 單位（也就是剩下 12.5/100=1/8），要經過幾個半衰期？

(1/2)ⁿ = 1/8 = 1/2³　　⟹　　n = 3（個半衰期） 時間 = 3 × 5.2714 = 15.8142（年）

這裡的 n=3 剛好是整數，算起來很順。但如果題目問的是「剩下 12%」這種不是 2 的次方分之一的比例，n 就不會是整數——這正是 PART 2、PART 3 要解決的問題，也是後面「常用對數」真正派上用場的地方。

PART 2 ・ 有理數指數與指數律

經過「半個」半衰期，會剩下多少？

情境

同樣是鈷-60，如果只經過「半個」半衰期（也就是 2.6357 年），含量會變成原本的幾倍？換句話說：2⁻¹ 是「衰減一次」，那「衰減半次」該怎麼寫、怎麼算？

觀察

設「衰減半次」的倍率是 r。「連續衰減兩個半次」等於「衰減一整次」，所以 r 自己連乘兩次必須等於整個半衰期的倍率 1/2：

r × r = 1/2　　⟹　　r² = 1/2　　⟹　　r = 1/√2　（取正值，倍率不會是負的）

如果把「半次」寫成指數 1/2，這個倍率應該記成 (1/2)^(1/2)。反過來，也可以用純數字問同樣的問題：2^(1/3) 應該等於多少？設 x=2^(1/3)，也就是要找一個數，自己連乘 3 次等於 2。用逐步逼近試試看：

1.2³ = 1.728 1.25³ = 1.953125 1.259³ = 1.995616979 1.2599³ ≈ 1.999899758 1.25992³≈ 1.999995000 ……

越試越接近 2，這個數大約是 1.25992……，寫成根式就是 ³√2。

規律 → 定義

一般化：對 a>0、正整數 n，滿足 xⁿ=a 的正數 x，稱為 a 的 n 次方根，記作 x=a^(1/n)=ⁿ√a（n=2 時就是熟悉的 √a）。再進一步，對任意整數 m：

有理數指數的定義（a>0）
a^(1/n) = ⁿ√a　　　　a^(m/n) = ⁿ√(aᵐ)

用這個定義重新算「衰減半次」：(1/2)^(1/2) = √(1/2) = 1/√2 ≈ 0.707，跟剛剛推導的答案一致。

規律 → 公式：有理數指數律

可以證明（課本用「通分成相同分母」的技巧完整證過一次），整數指數律原封不動地推廣到有理數指數：

a, b > 0，r, s 為有理數
(1) aʳ·aˢ = aʳ⁺ˢ　　　(2) (aʳ)ˢ = aʳˢ　　　(3) aʳ·bʳ = (ab)ʳ
用一用

化簡 2^(1/4)×4^(1/8)，以及 (27/8)^(-2/3)。

2^(1/4)×4^(1/8) = 2^(1/4)×(2²)^(1/8) = 2^(1/4)×2^(1/4) = 2^(1/2) = √2 (27/8)^(-2/3) = ((3/2)³)^(-2/3) = (3/2)^(-2) = 1/(3/2)² = 4/9

解題關鍵：先把不同底數統一成同一個底數（例如都寫成 2 或 3/2 的次方），指數律才能派上用場。

回到情境：精確算出鈷-60衰減時間

回到 PART 1 留下的問題：如果鈷-60 衰減到剩下 12% 這種不是整數個半衰期的比例，該怎麼精確算出經過的年數？現在有了分數指數，可以列出方程式：

(1/2)^(n/5.2714) = 0.12

這個方程式裡，未知數 n 卡在指數的位置——這就是「常用對數」要解決的核心問題：怎麼從指數的位置，把未知數解出來。

PART 3 ・ 實數指數與指數律

指數如果是無理數呢？

情境

前面定義了整數指數、有理數指數（分數指數）。那 2^√2 這種指數本身是無理數的式子，又該怎麼理解？

觀察

用一系列越來越接近 √2 的有理數（√2≈1.414213562……）當指數，分別算出 2 的次方，看看會發生什麼事：

指數 n2ⁿ
1.42¹·⁴ ≈ 2.639015822
1.412¹·⁴¹ ≈ 2.657371628
1.4142¹·⁴¹⁴ ≈ 2.664749650
1.41422¹·⁴¹⁴² ≈ 2.665119089
1.414212¹·⁴¹⁴²¹ ≈ 2.665137562
1.4142132¹·⁴¹⁴²¹³ ≈ 2.665143104

指數越接近 √2，算出來的值就越接近同一個數：2^√2 ≈ 2.665144143。這個「不斷用有理數逼近」得到的極限值，就定義為 2^√2。

規律 → 定義

一般化：對 a>0 和任意實數 u（不管有理數還是無理數），都可以用同樣「取有理數逼近」的方式定義 aᵘ，而且之前推導的所有指數律，在實數範圍內全部繼續成立：

a, b > 0，r, s 為任意實數
aʳ·aˢ = aʳ⁺ˢ　　　(aʳ)ˢ = aʳˢ　　　aʳ·bʳ = (ab)ʳ
用一用

化簡 4^√2 × 8^(-2√2/3)，以及 (2^√3×3^√3)^√3。

4^√2 × 8^(-2√2/3) = (2²)^√2 × (2³)^(-2√2/3) = 2^(2√2) × 2^(-2√2) = 2^0 = 1 (2^√3×3^√3)^√3 = ((2×3)^√3)^√3 = 6^(√3×√3) = 6³ = 216

即使指數是無理數，「先統一底數、再合併指數」的解題套路完全不變——這正是把指數律推廣到實數範圍的意義：不用重新學一套新規則。

PART 4 ・ 科學記號與有效數字

回到細菌：40 小時後到底有幾隻？

情境

回到 PART 1 的細菌。已知這種細菌每 1 小時分裂成 2 倍，如果從 1 隻細菌開始，連續培養 40 小時（現實中培養皿的養分早就不夠，這裡只是想像的極限情況），數量究竟會變成原本的幾倍？

觀察
培養 40 小時 = 連續培養 4 段「10 小時」：每一段結束，數量變成 2¹⁰ 倍 40 小時的倍率 = 2¹⁰·2¹⁰·2¹⁰·2¹⁰ = 2⁴⁰

那 2⁴⁰ 寫成一般數字到底有多大？已知 2²⁰≈1.05×10⁶：

2⁴⁰ = (2²⁰)² ≈ (1.05×10⁶)² = 1.1025×10¹² ≈ 1.10×10¹²（倍）

寫成「1100000000000」這種原始數字，不但難唸也難比較大小；但寫成 1.10×10¹²，一眼就能看出這是「一兆多一點」倍——40 小時就能讓一隻細菌變成一兆多隻，這正是指數成長驚人的地方。

規律 → 定義

任何正數 a 都可以寫成「一個介於 1 到 10 之間的小數，乘上 10 的整數次方」，這種寫法叫做科學記號：

a = b × 10ⁿ　　（1 ≤ b < 10，n 為整數；b 稱為係數，其中的每個數字稱為有效數字）
15200000 = 1.52×10⁷ 0.0010246 = 1.0246×10⁻³ 6.02×10²³ （亞佛加厥常數，1 莫耳粒子數） PM2.5 粒子直徑 2.5 微米 = 2.5×10⁻⁶ 公尺
延伸：科學記號的四則運算，要顧著有效數字

用科學記號做加減乘除時，係數部分維持「有效數字該有幾位就取幾位」，不要憑空多寫或少寫幾位小數：

2.30×10⁴ − 8.10×10³ = 2.30×10⁴ − 0.81×10⁴ = (2.30−0.81)×10⁴ = 1.49×10⁴ (5.10×10⁻²) × (4.50×10⁴) = (5.10×4.50)×10⁽⁻²⁺⁴⁾ = 22.95×10² ≈ 2.30×10³ （5.10、4.50 都只有 3 位有效數字，答案也只保留 3 位）

回到最初的問題：40 小時後細菌數量約為原本的 1.10×10¹² 倍——因為前面 2²⁰≈1.05×10⁶ 這個已知值只給了 3 位有效數字，答案也就只能誠實地寫到 3 位，不能假裝算得更精確。

換你動手做

1代數

化簡 (-3)⁻²×(-3)⁻³。

查看解答
(-3)⁻²×(-3)⁻³ = (-3)⁻⁵ = -1/243
2情境

某種細菌每半小時分裂成兩倍，經過「一小時又十五分鐘」（即 1.25 小時）後，數量是原本的幾倍？（提示：先寫成 2^(t/0.5) 的形式）

查看解答
倍率 = 2^(1.25/0.5) = 2^2.5 = 2²×2^0.5 = 4√2 ≈ 5.657（倍）
3代數

化簡 9^(3/2)×4^(1/2)，以及 (0.064)^(-1/3)。

查看解答
9^(3/2)×4^(1/2) = (3²)^(3/2)×(2²)^(1/2) = 3³×2 = 54 (0.064)^(-1/3) = (64/1000)^(-1/3) = ((4/10)³)^(-1/3) = (2/5)⁻¹ = 5/2
4情境

鈷-60 半衰期 5.2714 年，若一開始有 100 單位，經過 100 年後大約還剩多少單位？（提示：100/5.2714 個半衰期，可用計算機估算 2 的負次方）

查看解答
半衰期個數 = 100/5.2714 ≈ 18.97 剩下比例 = (1/2)^18.97 ≈ 1.94×10⁻⁶ 剩下量 ≈ 100 × 1.94×10⁻⁶ ≈ 1.94×10⁻⁴（單位）
5代數

化簡 3^√3 × 9^(-√3/2)。

查看解答
3^√3 × 9^(-√3/2) = 3^√3 × (3²)^(-√3/2) = 3^√3 × 3^(-√3) = 3⁰ = 1
6情境

地球到太陽的距離約 1.5×10⁸ 公里，光速約 3×10⁵ 公里/秒。陽光從太陽到地球大約要幾秒？

查看解答
時間 = (1.5×10⁸)/(3×10⁵) = 0.5×10³ = 5×10²（秒）＝ 500 秒 ≈ 8.3 分鐘
7代數

用科學記號表示並計算 (1.71×10⁻³) × (2.50×10⁻²)（結果取 3 位有效數字）。

查看解答
1.71×2.50 = 4.275 ≈ 4.28（取3位有效數字） (1.71×10⁻³)×(2.50×10⁻²) = 4.28×10⁻⁵
8情境

培養皿 A 中細菌數量約 8×10⁴ 隻，培養皿 B 中細菌數量約 2×10⁷ 隻，B 的數量是 A 的幾倍？

查看解答
B/A = (2×10⁷)/(8×10⁴) = (2/8)×10³ = 0.25×10³ = 2.5×10² = 250（倍）

給筱葳的話

指數的故事，是一路「把定義擴大」的故事：先是連乘 n 次（正整數），接著往回除逼出 0 與負指數，再用「連乘幾次才能拼回整數次方」逼出分數指數，最後用逼近的方式，連無理數次方都定義出來了。每一次擴大，之前的指數律都完好保留——這是數學裡很重要的一種思考方式：新定義不能推翻舊規則，只能讓舊規則適用的範圍更大。

而科學記號和有效數字，是指數最直接的日常用途：不管是細菌的數量、地球到太陽的距離，還是原子的個數，指數讓我們能誠實地寫下「大概有多大」，不多算，也不少算。
