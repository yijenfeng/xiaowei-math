簡單多項式函數及其圖形

從公園的對稱花圃、停車場的收費方式，到靠牆菜圃的最大面積，認識函數的圖形語言，並學會用配方法看懂二次函數的頂點與最大、最小值。情境例子為原創設計。

函數的圖形，說穿了就是把「輸入與輸出的關係」畫成一條線。這一節從公園的對稱設計出發，經過停車場的收費方式，最後用配方法解決一個「怎麼圍出最大菜圃」的實際問題。

坐標圖形的對稱與中點

公園的對稱花圃，要蓋在哪裡？

情境

社區公園以大門為原點畫坐標，一座景觀水池蓋在 P(4,3)（單位：十公尺）。設計師想沿著幾條步道對稱增建：沿東西向的 x 軸步道對稱、沿南北向的 y 軸步道對稱、沿一條 45° 斜對角步道（y=x）對稱，還有以中央噴泉（原點）為中心對稱。新水池分別該蓋在哪裡？

觀察 → 規律

畫圖觀察就會發現：沿 x 軸對稱，左右的 x 坐標不變，上下翻過去，y 坐標變號；沿 y 軸對稱則反過來；沿 y=x 對稱，就是把 x、y 坐標「互換」；而以原點為中心對稱，x、y 都變號。

公式
對稱方式P(a,b) 的對稱點
沿 x 軸對稱(a, −b)
沿 y 軸對稱(−a, b)
沿直線 y=x 對稱(b, a)
以原點對稱(−a, −b)
用一用：中點坐標

水池 P(4,3) 和涼亭 Q(−2,7) 中間要設一張長椅，長椅應該放在坐標平面上的哪一點？

兩點 P(a₁,b₁)、Q(a₂,b₂) 連線的中點公式：

M = ((a₁+a₂)／2, (b₁+b₂)／2)
M = ((4+(−2))／2, (3+7)／2) = (1, 5)

長椅應該放在 (1,5)。

函數的概念與圖形

停車場的收費表，就是一個函數

情境

社區地下停車場的計費看板寫著：清潔費20元，每停1小時再加收30元。停 x 小時，要付多少錢？

觀察 → 規律 → 公式

不管 x 是多少，代進公式後都只會算出「唯一」一個收費金額——這種「每一個輸入，對應唯一一個輸出」的關係，就是函數。

函數的概念
設 x、y 是兩個變數。若 x 每取一個值，y 都有唯一確定的值與它對應，就稱 y 是 x 的函數，記為 f，寫成 y=f(x)。

停車場的收費公式是 f(x)=30x+20（x：小時，f(x)：元）。代入幾個時數：

f(1) = 30(1)+20 = 50　（元） f(2) = 30(2)+20 = 80　（元） f(3) = 30(3)+20 = 110　（元）

把 (x, f(x)) 這些點畫在坐標平面上、連起來，就是 f 的圖形：

本節接下來會看到，f(x)=30x+20 這種「一條斜直線」的圖形，正是下一個主題要正式介紹的一次函數。

用一用

若停車場改成「不管停多久，月租都是2000元」，這個月租方案是不是 x（天數）的函數？

是。因為不管 x 取哪一天，輸出永遠是唯一確定的 2000 元——只是這個函數的值「固定不變」，這正是下一個主題要介紹的常數函數。

常數函數與一次函數

月租方案 vs. 時租方案，圖形差在哪？

觀察 → 規律 → 公式：常數函數

月租方案 f(x)=2000，不管 x 是多少，函數值永遠是 2000。這種函數叫常數函數：

f(x) = c　（c 為常數）——圖形是一條通過 (0,c)、平行 x 軸的水平線
觀察 → 規律 → 公式：一次函數

時租方案 f(x)=30x+20，圖形是一條斜直線，叫一次函數：

f(x) = ax+b　（a≠0）——圖形是過 (0,b) 的斜直線，a 決定傾斜方向與陡緩

a > 0 時，x 越大 f(x) 越大（線由左下往右上）；a < 0 時則相反。b 是「x=0 時」的函數值，也就是圖形跟 y 軸的交點——在停車場的例子裡，b=20 元就是「還沒開始計時」也要付的清潔費。

用一用

隔壁棟停車場的方案是 g(x)=25x+35。停 3 小時的話，兩個方案一樣嗎？停更久呢？

f(3) = 30(3)+20 = 110（元） g(3) = 25(3)+35 = 110（元）

停 3 小時兩者一樣；但 g 的斜率 25 小於 f 的斜率 30，代表每多停 1 小時，g 只多收 25 元、f 卻多收 30 元——停得越久，g 方案越划算。

二次函數的圖形與應用

用100公尺的圍籬，圍出最大的菜圃

情境

農夫家旁邊有一道長長的牆，他想用一段100公尺的圍籬，靠著牆圍出一個矩形菜圃（靠牆的那一邊不用圍）。要怎麼圍，面積才會最大？

觀察

設垂直於牆的那兩邊各長 x 公尺，剩下的圍籬長度就是平行牆的那一邊：100−2x 公尺。面積：

A(x) = x(100−2x) = −2x² + 100x

A(x) 是 x 的二次函數，而且首項係數 −2 < 0——代表它的圖形是一個開口向下的拋物線，會有一個「最高點」。

規律 → 公式：配方法找頂點

要找拋物線的最高點，用配方法把 A(x) 湊成「完全平方＋常數」的形式：

A(x) = −2x²+100x = −2(x²−50x) = −2(x²−50x+625−625) = −2(x−25)² + 1250
二次函數的配方法
f(x) = ax²+bx+c = a(x + b／2a)² + (4ac−b²)／4a　（a≠0）

頂點坐標就是 (−b／2a, (4ac−b²)／4a)，圖形以 x=−b／2a 這條鉛垂線為對稱軸。這裡頂點是 (25, 1250)：當 x=25（垂直牆的邊長25公尺）時，面積最大，最大面積是1250平方公尺。

因為首項係數 a=−2<0，圖形開口向下，頂點就是「最高點」，函數有最大值；如果 a>0，圖形開口向上，頂點是「最低點」，函數則有最小值。

用一用

如果圍籬改成80公尺，一樣靠牆圍矩形，最大面積是多少？

A(x) = x(80−2x) = −2x²+80x = −2(x²−40x) = −2(x²−40x+400−400) = −2(x−20)²+800

當 x=20 公尺時，面積最大，最大面積800平方公尺。

收進工具箱：3-2 簡單多項式函數及其圖形

從對稱、函數概念，到二次函數配方求極值，這些是判斷圖形形狀的基本功。

名稱內容
對稱點P(a,b) 對x軸(a,−b)、對y軸(−a,b)、對y=x(b,a)、對原點(−a,−b)
中點坐標M=((a₁+a₂)／2,(b₁+b₂)／2)
函數y=f(x)：x每取一值，y有唯一確定的值對應
常數函數f(x)=c，圖形為水平線
一次函數f(x)=ax+b（a≠0），圖形為過(0,b)的斜直線
二次函數配方f(x)=ax²+bx+c=a(x+b／2a)²+(4ac−b²)／4a
頂點與極值頂點(−b／2a,(4ac−b²)／4a)；a>0有最小值，a<0有最大值

練習題

1對稱與中點

點 P(−3,5)，求其對 x 軸、y 軸、原點的對稱點，並求 P 與 Q(5,−1) 的中點。

參考答案
對x軸：(−3,−5)　對y軸：(3,5)　對原點：(3,−5) 中點：((−3+5)／2,(5−1)／2) = (1,2)
2函數概念

停車場收費 f(x)=30x+20（x為小時），求 f(4)，並說明 f(0) 代表什麼意義。

參考答案
f(4)=30(4)+20=140（元）。f(0)=20，代表即使還沒開始計時，也要付的基本清潔費。
3常數函數與一次函數

判斷 y=2000 與 y=45x 哪一個是常數函數、哪一個是一次函數，並說明圖形差異。

參考答案
y=2000 是常數函數，圖形是水平線；y=45x 是一次函數（a=45,b=0），圖形是通過原點、由左下往右上的斜直線。
4二次函數配方

用配方法求 f(x)=−2x²+60x 的頂點坐標與最大值。

參考答案
f(x) = −2x²+60x = −2(x²−30x) = −2(x²−30x+225−225) = −2(x−15)²+450 頂點 (15,450)，最大值 450
5應用

若圍籬總長改為120公尺（一樣靠牆圍矩形），求最大面積。

參考答案
A(x) = x(120−2x) = −2x²+120x = −2(x²−60x) = −2(x−30)²+1800 當 x=30 公尺時，最大面積 1800 平方公尺

下一步：曲線也可能忽高忽低
