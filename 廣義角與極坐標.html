數學2・第四章 三角比的性質與應用・4-2

廣義角與極坐標

測量社這學期要辦一場「定向越野」活動，選手要靠「轉的角度」加上「走的距離」找到藏在校園裡的檢查點。這一節延續這個情境，把三角比的定義從0°~90°的銳角，擴展到任意大小、可正可負的「廣義角」，並認識用距離與方向描述位置的極坐標。情境例子為原創設計。

定向越野比賽規定：選手一律面朝東方出發（這是量角度的起點），逆時針轉向找路。有些選手為了閃避花圃，會刻意繞一大圈甚至轉超過一圈才對準檢查點方向——這樣的角度已經超過0°到360°的範圍，也可能因為順時針轉而變成「負的」。這種不受0°~180°限制、可正可負、也不限旋轉圈數的角，就是這一節要介紹的廣義角。

廣義角

角度不再限制在0°到180°之間

情境

選手小磊出發時面朝正東方（射線OA，稱為始邊），逆時針轉了150°後面朝檢查點方向（射線OB，稱為終邊），這個轉動所形成的角就記為150°。裁判規定：逆時針旋轉記為正角，順時針旋轉記為負角，而且不限制轉的圈數。

把角看成「始邊繞頂點旋轉到終邊」所形成的角，這樣的角叫做有向角。像小磊這樣由OA逆時針轉到OB形成150°角；如果換一位選手為了躲避積水，反而順時針繞了一大圈再轉到同一個方向，形成的角就是150°+360°=510°，或甚至順時針轉到同一方向形成−210°角——這些都是合法的廣義角。

觀察 → 規律

把廣義角放在坐標平面上，頂點放在原點，始邊放在x軸正向，這樣的角稱為標準位置角；終邊落在第幾象限，就稱這個角為第幾象限角。當兩個廣義角θ與φ有共同的始邊與終邊時，稱θ與φ互為同界角——換句話說，同界角就是終邊轉到同一個位置的角，彼此角度差是360°的整數倍。

同界角
θ與φ同界角　⟺　θ−φ = 360°・n（n為整數）

小磊轉了510°找到檢查點，隊友小雯則說她「只轉了150°」也找到同一個檢查點。驗證：510°−150°=360°=360°×1，兩人的角確實是同界角，難怪面對同一個方向。

用一用

(1) 寫出680°的一個介於0°~360°之間的同界角。 (2) 求−100°的兩個正的同界角。

(1) 680° − 360° = 320°　→　320°與680°同界 (2) −100°+360° = 260° −100°+720° = 620° 260°、620° 都與 −100° 同界
廣義角的三角比

用終邊上的一點，定義任意角的三角比

情境

定向越野的地圖上，起點是原點O，東方是x軸正向。檢查點的位置可以直接用坐標(x,y)表示——例如檢查點A的坐標是(-3,4)。選手轉向面對A點時所形成的標準位置角θ，該怎麼求它的三角比？

把銳角三角比的定義搬過來：取終邊上任一點P(x,y)，令 OP=√(x²+y²)=r（r>0），仿照直角三角形的邊角關係，把「對邊」換成y、「鄰邊」換成x、「斜邊」換成r，就能定義出任意廣義角θ的三角比：

廣義角的三角比
sinθ = y／r　　cosθ = x／r　　tanθ = y／x（x≠0）
用一用
r = OA = √((−3)²+4²) = 5 sinθ = y／r = 4／5 cosθ = x／r = −3／5 tanθ = y／x = 4／(−3) = −4／3

終邊上的點可以任意選取，因為x、y、r會等比例放大縮小，算出來的三角比不會改變——這也是廣義角三角比「跟選哪一點無關，只跟終邊方向有關」的關鍵原因。

觀察 → 規律：象限與正負號

因為r恆為正，三角比的正負完全由x、y的正負決定，而x、y的正負又由終邊所在的象限決定：

終邊所在象限第一象限第二象限第三象限第四象限
(x,y)(+,+)(−,+)(−,−)(+,−)
sinθ++−−
cosθ+−−+
tanθ+−+−

求 sin150°、cos150°、tan150° 的值。

150°為第二象限角，終邊與30°的終邊對地面呈鏡射關係，可取終邊上一點使r=2，得P(−√3,1) sin150° = 1／2 cos150° = −√3／2 tan150° = 1／(−√3) = −√3／3

當角度的終邊剛好落在坐標軸上（0°、90°、180°、270°）時，可以直接在終邊上取(1,0)、(0,1)、(−1,0)、(0,−1)這樣的點來計算，此時tanθ在90°、270°會因為x=0而沒有定義。

廣義角三角比的基本關係

對稱關係：-θ、180°-θ、90°-θ

觀察 → 規律

把終邊放在半徑為r的圓上，設終邊上一點為P(x,y)，由廣義角三角比定義可得圓上點坐標的公式，也能重新驗證商數關係與平方關係在任意角θ下依然成立：

圓上點的坐標 ／ 商數關係 ／ 平方關係
P(x,y) = (r cosθ, r sinθ)　　　　tanθ = sinθ／cosθ　　　　sin²θ + cos²θ = 1

接著討論θ與−θ、180°−θ、90°−θ的三角比之間的對稱關係。角θ與−θ的終邊對稱於x軸，角θ與180°−θ的終邊對稱於y軸，角θ與90°−θ的終邊對稱於直線y=x——由對稱點的坐標關係，可以直接推得：

對稱關係
sin(−θ)=−sinθ　　cos(−θ)=cosθ　　tan(−θ)=−tanθ
sin(180°−θ)=sinθ　　cos(180°−θ)=−cosθ　　tan(180°−θ)=−tanθ
sin(90°−θ)=cosθ　　cos(90°−θ)=sinθ
用一用

已知 cosθ=0.6，求 (1) cos(−θ) (2) cos(180°−θ) (3) sin(θ−90°) 的值。

(1) cos(−θ) = cosθ = 0.6 (2) cos(180°−θ) = −cosθ = −0.6 (3) sin(θ−90°) = sin(−(90°−θ)) = −sin(90°−θ) = −cosθ = −0.6
用一用：化為銳角求值

求 sin750° 的值。

sin750° = sin(360°×2+30°) = sin30°　　（同界角，轉了整數圈不影響） sin30° = 1／2 ∴ sin750° = 1／2

看到超過360°的角，第一步永遠是「先扣掉360°的整數倍」化成0°~360°之間的同界角；再視需要用 −θ、180°−θ、90°−θ的關係化成銳角，就能查表或用計算機求值。

直線的斜角

直線的傾斜程度，也可以用角度描述

情境

定向越野地圖上有一段路徑是直線，從x軸正向逆時針轉到這條路徑的方向，轉了60°。像這樣以x軸正向為始邊，直線向右上方（或右下方）的方向為終邊，且角度介於−90°到90°之間的有向角，稱為這條直線的斜角。水平方向的直線斜角規定為0°，鉛垂方向的直線斜角規定為90°。

設直線L不為鉛垂線，且通過原點與點P(x,y)，斜角為θ，由廣義角的正切定義可得：

直線斜角的性質
tanθ = 直線L的斜率
用一用

已知路徑L的斜角為60°，且通過點(3,−2)，求L的方程式。

m = tan60° = √3 L: y − (−2) = √3(x−3) y = √3x − 3√3 − 2
用一用：兩路徑的夾角

路徑L₁的斜角是45°，路徑L₂的斜角是30°，求兩條路徑的夾角。

兩路徑的夾角 = 45° − 30° = 15° （180°−15°=165°也是這兩條直線的夾角，通常取較小的那一個當作交叉角）

若改成路徑L的斜率為0.5，用計算機求L的斜角（取到小數點後一位）。

tanθ = 0.5 θ = tan⁻¹(0.5) ≈ 26.6°
極坐標

用「距離＋方向」描述位置

情境

裁判在對講機裡回報檢查點的位置，不是說坐標(x,y)，而是說：「檢查點在起點東偏北方向、距離40公尺處」，也就是「距離40公尺、標準位置角130°」。這種用「距離」與「角度」表示位置的方法，就是極坐標，記作 P[r,θ]。

極坐標
以O為極點、射線OL為極軸，P點與O的距離OP=r，OP與OL的夾角為θ（廣義角），則P點的極坐標記為 [r,θ]（r>0）
規律 → 公式：直角坐標與極坐標的轉換

由圓上點坐標的公式 (x,y)=(r cosθ, r sinθ)，可以互相轉換直角坐標與極坐標：

直角坐標與極坐標的轉換
由極坐標[r,θ]求直角坐標：(x,y) = (r cosθ, r sinθ)
由直角坐標(x,y)求極坐標：r = √(x²+y²)，cosθ = x／r，sinθ = y／r
用一用

(1) 檢查點P的極坐標為[8,120°]，求P的直角坐標。 (2) 檢查點Q的直角坐標為(5,−5√3)，求Q的極坐標（角度介於0°~360°之間）。

(1) x = 8cos120° = 8×(−1／2) = −4 y = 8sin120° = 8×(√3／2) = 4√3 P的直角坐標為 (−4, 4√3) (2) r = √(5²+(−5√3)²) = √(25+75) = √100 = 10 cosθ = 5／10 = 1／2，sinθ = −5√3／10 = −√3／2 θ落在第四象限，θ = 300° Q的極坐標為 [10, 300°]

同一個點的極坐標並不唯一——角度可以換成任何一個同界角，題目通常會限定角度的範圍（例如0°~360°）來要求唯一的答案。

收進工具箱：4-2 廣義角與極坐標

這一節把三角比的定義從銳角推廣到任意角，並用終邊上的點建立起坐標與三角比之間的橋樑，是4-3面積公式與正餘弦定理的重要基礎。

名稱內容
廣義角逆時針為正、順時針為負，不限旋轉圈數；同界角相差360°的整數倍
廣義角的三角比終邊上一點P(x,y)，r=OP，sinθ=y/r，cosθ=x/r，tanθ=y/x
對稱關係sin(−θ)=−sinθ；sin(180°−θ)=sinθ；sin(90°−θ)=cosθ
圓上點坐標(x,y)=(r cosθ, r sinθ)
直線斜角tanθ=直線斜率（−90°<θ<90°）
極坐標P[r,θ]；(x,y)=(r cosθ, r sinθ)

練習題

1同界角

求−80°的兩個正的同界角，並求940°介於0°~360°之間的同界角。

參考答案
−80°+360°=280°，−80°+720°=640° 940°−720°=220°
2廣義角的三角比

設θ為標準位置角，其終邊上一點為(6,−8)，求sinθ、cosθ、tanθ的值。

參考答案
r=√(6²+(−8)²)=10 sinθ=−8／10=−4／5，cosθ=6／10=3／5，tanθ=−8／6=−4／3
3對稱關係

求cos(−210°)的值。

參考答案
cos(−210°) = cos210°　（利用cos(−θ)=cosθ） 210°為第三象限角，與30°終邊對稱，cos210°=−cos30°=−√3／2 ∴ cos(−210°) = −√3／2
4直線的斜角

路徑L₁的斜率為−1，路徑L₂的斜率為√3／3，求兩路徑的夾角。

參考答案
L₁斜角：tanθ₁=−1 → θ₁=135° L₂斜角：tanθ₂=√3／3 → θ₂=30° 夾角 = 135°−30° = 105°（或180°−105°=75°也是夾角，通常取較小的75°為交叉角）
5極坐標

檢查點的直角坐標為(6,−6),求其極坐標(角度介於0°~360°之間)。

參考答案
r=√(6²+(−6)²)=6√2 cosθ=6／6√2=√2／2，sinθ=−6／6√2=−√2／2 θ落在第四象限，θ=315° 極坐標為 [6√2, 315°]
