數A 第四冊・第二章 空間中的平面與直線・2-2

空間直線方程式

燈光秀的最後一幕，每台無人機都沿直線飛行。安全組要回答三個問題：某台無人機什麼時候穿過布幕？兩台的航線會不會交叉相撞？觀眾席上一點離某條航線最近有多近？這一節寫出空間直線的參數式與比例式，並用它處理直線與平面、直線與直線、點與直線的問題。情境例子為原創設計。

空間中的直線不能用單一個方程式表示——ax + by + cz = d 是一個平面。描述直線最自然的方法是「從一個點出發，沿著一個方向走 t 倍」，這就是參數式：參數 t 可以想成時間，每個 t 對應直線上的一個點。

參數式與比例式

一個起點加一個方向，t 秒後在哪裡

情境

6 號無人機從 A(1, 2, 0) 起飛，每秒的位移是 v = (2, 1, 2)（公尺）。t 秒後它在哪裡？

t 秒後的位置 = A + tv = (1 + 2t, 2 + t, 2t) t = 1：(3, 3, 2)　　t = 2：(5, 4, 4)　　t = −1：(−1, 1, −2)（往回推一秒）
空間直線（過 (x₀, y₀, z₀)，方向向量 (a, b, c)）
參數式：x = x₀ + at，y = y₀ + bt，z = z₀ + ct（t 為實數）
比例式：(x − x₀)／a = (y − y₀)／b = (z − z₀)／c（a、b、c 皆不為 0 時）

比例式是把參數式的三個 t 都解出來令它們相等。若某個分量為 0，例如 b = 0，就寫成 (x − x₀)／a = (z − z₀)／c，y = y₀。

同一條直線的參數式不唯一：起點可以換成線上任一點，方向向量可以換成任何平行的向量。

用一用：過兩點的直線

寫出過 A(1, −1, 2)、B(3, 0, 5) 的直線。

方向向量 AB = (2, 1, 3) 參數式：(1 + 2t, −1 + t, 2 + 3t) 比例式：(x − 1)／2 = (y + 1)／1 = (z − 2)／3
直線與平面

什麼時候穿過布幕？

情境

後方新掛了一面布幕，平面為 2x + y + 2z = 22。6 號無人機沿 (1 + 2t, 2 + t, 2t) 飛行，第幾秒會碰到布幕？在哪裡碰到？

把參數式代入平面方程式，解 t：

2(1 + 2t) + (2 + t) + 2(2t) = 22 4 + 9t = 22 ⟹ t = 2 交點 = (5, 4, 4)，第 2 秒碰到布幕
規律：三種關係
直線（方向 v）與平面（法向量 n）
v・n ≠ 0 ⟹ 交於一點
v・n = 0 且線上一點不在平面上 ⟹ 平行
v・n = 0 且線上一點在平面上 ⟹ 直線在平面上
v ∥ n ⟹ 直線垂直平面

代入後若得到「0 = 非零數」，代表永遠碰不到（平行）；得到「0 = 0」，代表每個 t 都在平面上。

兩直線的關係

兩台無人機會不會相撞？

判斷步驟
兩直線 L₁、L₂ 的關係
1. 方向向量平行 → 平行或重合（取一點代入另一條檢查）
2. 方向向量不平行 → 令兩參數式相等，用兩個分量解出 t、s，再代入第三個分量檢查
　　第三式成立 → 相交；不成立 → 歪斜

兩條直線用不同的參數 t、s，因為它們在交點時「走的倍數」不一定相同。

情境

7 號航線 L₁：(1 + t, 2t, 3 − t)；8 號航線 L₂：(2 + s, 1 + s, 4 + s)。兩條航線會交叉嗎？

方向 (1, 2, −1) 與 (1, 1, 1) 不平行 x：1 + t = 2 + s y：2t = 1 + s 相減：t − 1 = −1 ⟹ t = 0，s = −1 z：3 − 0 = 3，4 + (−1) = 3 ✓ 成立 ⟹ 兩航線相交於 (1, 0, 3)

相交不代表一定相撞：7 號在 t = 0 時經過交點，8 號在 s = −1 時經過。如果 t、s 都代表「時間」，兩台在不同時刻經過同一點，不會撞上。這就是航管需要的分析。

用一用：歪斜
L₁：(1 + t, t, 0)，L₂：(s, 1 − s, 1) 方向 (1, 1, 0) 與 (1, −1, 0) 不平行 z：0 = 1 ⟹ 矛盾，沒有交點 ⟹ 歪斜
點到直線的距離

找垂足：連線和方向向量垂直

情境

觀眾席的貴賓座在 Q(5, 3, 0)。6 號無人機的航線 (1 + 2t, 2 + t, 2t) 離貴賓座最近是多少？發生在第幾秒？

最近的點 P 是 Q 在直線上的垂足，條件是 QP ⊥ 方向向量：

P = (1 + 2t, 2 + t, 2t)，QP = (2t − 4, t − 1, 2t) QP・(2, 1, 2) = 4t − 8 + t − 1 + 4t = 9t − 9 = 0 ⟹ t = 1 垂足 P = (3, 3, 2)，QP = (−2, 0, 2) 最近距離 = √(4 + 0 + 4) = 2√2 ≈ 2.83（公尺），在第 1 秒

這個方法同時給出垂足和距離。也可以用外積公式：距離 = |QA × v| ／ |v|（平行四邊形面積 ÷ 底），但找垂足的方法更通用。

收進工具箱：2-2 空間直線方程式

直線 = 一點 + 一個方向。和平面相交就代入解 t；和直線相交就解 t、s 並檢查第三式；求距離就找垂足。

名稱內容
參數式(x₀ + at, y₀ + bt, z₀ + ct)
比例式(x − x₀)／a = (y − y₀)／b = (z − z₀)／c
線與面代入解 t；v・n = 0 時平行或在平面上
線與線平行／重合／相交／歪斜；用兩式解 t、s，第三式檢查
點到直線垂足條件 QP・v = 0；或 |QA × v|／|v|

練習題

1寫直線

寫出過 (2, 0, −1)、方向向量為 (3, −2, 4) 的直線比例式，並判斷點 (8, −4, 7) 是否在線上。

參考答案
(x − 2)／3 = y／(−2) = (z + 1)／4 代入：6／3 = 2，(−4)／(−2) = 2，8／4 = 2 ⟹ 三者相等，在線上（t = 2）
2線與面交點

求直線 (1 + t, 2 − t, 3 + 2t) 與平面 x + y + z = 10 的交點。

參考答案
(1 + t) + (2 − t) + (3 + 2t) = 6 + 2t = 10 ⟹ t = 2 交點 (3, 0, 7)
3線與面關係

判斷直線 (t, 1 + 2t, −t) 與平面 3x − y + z = 5 的關係。

參考答案
方向 (1, 2, −1)・法向量 (3, −1, 1) = 3 − 2 − 1 = 0 ⟹ 平行或在平面上 線上一點 (0, 1, 0)：0 − 1 + 0 = −1 ≠ 5 ⟹ 平行
4點到直線

求點 Q(4, 1, 0) 到直線 (1 + t, t, 1 + t) 的垂足與距離。

參考答案
QP = (t − 3, t − 1, t + 1) QP・(1, 1, 1) = 3t − 3 = 0 ⟹ t = 1 垂足 (2, 1, 2)，距離 = |(−2, 0, 2)| = 2√2
5兩直線

判斷 L₁：(1 + t, 1 − t, 2t) 與 L₂：(3 + s, s, 1 + s) 的關係。

參考答案
方向 (1, −1, 2) 與 (1, 1, 1) 不平行 x：1 + t = 3 + s；y：1 − t = s 相加：2 = 3 + 2s ⟹ s = −1／2，t = 3／2 z：2t = 3；1 + s = 1／2 ⟹ 3 ≠ 1／2 ⟹ 歪斜

第二章完成：空間中的平面與直線

平面用「一點 + 法向量」，直線用「一點 + 方向向量」，兩者的交點、夾角、距離都化成向量的內積與外積計算。燈光秀圓滿落幕。下一章換一個完全不同的主題：在「已經知道某些資訊」的情況下，機率要怎麼更新？在 3-1「條件機率與獨立事件」，筱葳會從社團招生的數據開始。
