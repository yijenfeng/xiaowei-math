數A 第四冊・第二章 空間中的平面與直線・2-1

平面方程式

燈光秀正式演出前，安全組要確認每台無人機和斜掛的三角布幕保持至少 3 公尺距離。要算「點到布幕的距離」，得先把布幕寫成一個方程式。這一節用 1-4 的法向量寫出平面方程式，學會求兩平面的夾角，以及點到平面的距離。情境例子為原創設計。

平面上的直線可以用 ax + by = c 表示，其中 (a, b) 是它的法向量（數學1學過）。空間中的平面完全比照辦理：ax + by + cz = d，(a, b, c) 是垂直平面的法向量。只要記住「平面方程式的係數就是法向量」，這一節的所有公式都能自己推出來。

  • 2過三點的平面
  • 3兩平面的關係與夾角

點法式與一般式

一個點加一個法向量，就決定一個平面

觀察 → 規律

平面 E 過點 P₀(x₀, y₀, z₀)，法向量 n = (a, b, c)。P(x, y, z) 在 E 上，代表 P₀P 躺在平面裡，所以和 n 垂直：

n・P₀P = 0 ⟺ a(x − x₀) + b(y − y₀) + c(z − z₀) = 0
平面方程式
點法式：a(x − x₀) + b(y − y₀) + c(z − z₀) = 0
一般式：ax + by + cz = d，法向量 (a, b, c)

舞台地板是 xy 平面，地板上一個斜坡道過點 (2, 0, 0)，法向量為 (1, 0, 2)。寫出斜坡道所在平面的方程式。

1(x − 2) + 0(y − 0) + 2(z − 0) = 0 ⟹ x + 2z = 2

缺了 y 不代表錯：方程式裡沒有 y，表示平面和 y 軸平行（沿 y 方向一路延伸）。例如 z = 0 是 xy 平面，x = 3 是垂直於 x 軸的平面。

過三點的平面

先用外積找法向量

情境

三角布幕掛在 A(1, 0, 0)、B(0, 2, 0)、C(0, 0, 3) 三點（1-4 算過它的面積）。寫出布幕平面的方程式。

法向量 = AB × AC = (−1, 2, 0) × (−1, 0, 3) = (6, 3, 2) 過 A(1, 0, 0)：6(x − 1) + 3y + 2z = 0 ⟹ 6x + 3y + 2z = 6 檢查 B：0 + 6 + 0 = 6 ✓　檢查 C：0 + 0 + 6 = 6 ✓
截距式

把 6x + 3y + 2z = 6 兩邊除以 6，得到 x／1 + y／2 + z／3 = 1——分母剛好是平面和三軸的交點（截距）：

截距式（a、b、c 皆不為 0）
x／a + y／b + z／c = 1：平面交三軸於 (a, 0, 0)、(0, b, 0)、(0, 0, c)
兩平面的關係與夾角

看法向量，就知道兩平面的關係

規律
兩平面 E₁、E₂（法向量 n₁、n₂）
n₁ ∥ n₂ ⟹ 平行或重合（再看常數項）
n₁・n₂ = 0 ⟹ 兩平面垂直
其他情形交於一直線，夾角 θ 滿足 cosθ = ±(n₁・n₂)／(|n₁||n₂|)

兩平面相交會形成兩個互補的二面角（θ 與 180° − θ），所以 cosθ 前面有 ±。題目問「夾角」時，通常兩個都要寫，或依題意取銳角。

情境

布幕平面 6x + 3y + 2z = 6 和舞台地板 z = 0 的夾角（取銳角）是多少？

n₁ = (6, 3, 2)，n₂ = (0, 0, 1) cosθ = 2 ／ (7 × 1) = 2／7 ⟹ θ ≈ 73.4°

這和 1-1 用截面求帳篷二面角是同一件事，但這次完全不用找截面——法向量直接給答案。

點到平面的距離

無人機離布幕夠遠嗎？

規律 → 公式

點 P 到平面 E 的距離，就是 P 到平面上任一點 Q 的向量 QP，在法向量方向上的正射影長。整理後得到和數學1「點到直線距離」幾乎一樣的公式：

點到平面的距離
P(x₀, y₀, z₀) 到 ax + by + cz = d 的距離 = |ax₀ + by₀ + cz₀ − d| ／ √(a² + b² + c²)
情境

彩排時 5 號無人機停在 (2, 3, 4)。它和布幕 6x + 3y + 2z = 6 的距離夠 3 公尺嗎？

距離 = |6 × 2 + 3 × 3 + 2 × 4 − 6| ／ √(36 + 9 + 4) = |23| ／ 7 = 23／7 ≈ 3.29（公尺） 3.29 > 3 ⟹ 安全 ✓
用一用：兩平行平面的距離

布幕前方要再掛一層透光紗，平面為 6x + 3y + 2z = 20。兩層之間相距多遠？

兩平面法向量相同 ⟹ 平行 在 6x + 3y + 2z = 6 上取一點 (1, 0, 0)，到另一平面的距離： |6 − 20| ／ 7 = 2（公尺）
ax + by + cz = d₁ 與 ax + by + cz = d₂ 的距離 = |d₁ − d₂| ／ √(a² + b² + c²)

使用前要先把兩個方程式的 a、b、c 調成一模一樣，例如 4x + 2y − 4z = 11 要先除以 2。

收進工具箱：2-1 平面方程式

平面方程式的係數就是法向量。找平面 = 找一個點和一個法向量；過三點時用外積求法向量。

名稱內容
點法式a(x − x₀) + b(y − y₀) + c(z − z₀) = 0
一般式ax + by + cz = d，法向量 (a, b, c)
截距式x／a + y／b + z／c = 1
過三點法向量 = AB × AC

練習題

1點法式

求過點 (1, −2, 3)、法向量為 (2, 1, −1) 的平面方程式。

參考答案
2(x − 1) + (y + 2) − (z − 3) = 0 ⟹ 2x + y − z = −3
2過三點

求過 A(1, 1, 0)、B(2, 0, 1)、C(0, 1, 2) 的平面方程式。

參考答案
AB = (1, −1, 1)，AC = (−1, 0, 2) AB × AC = ((−1)(2) − 1 × 0, 1 × (−1) − 1 × 2, 1 × 0 − (−1)(−1)) = (−2, −3, −1) 取法向量 (2, 3, 1)，過 A：2x + 3y + z = 5 檢查 B：4 + 0 + 1 = 5 ✓，C：0 + 3 + 2 = 5 ✓
3距離

求點 (1, 2, 3) 到平面 2x − y + 2z = 10 的距離。

參考答案
|2 − 2 + 6 − 10| ／ √(4 + 1 + 4) = 4／3
4夾角

求平面 x + z = 1 與 y + z = 2 的夾角。

參考答案
法向量 (1, 0, 1)、(0, 1, 1)：cosθ = ±1 ／ (√2 × √2) = ±1／2 夾角為 60° 或 120°
5平行平面

求平面 2x + y − 2z = 1 與 4x + 2y − 4z = 11 的距離。

參考答案
第二式除以 2：2x + y − 2z = 11／2 距離 = |11／2 − 1| ／ √(4 + 1 + 4) = (9／2) ／ 3 = 3／2
