對數與對數律

筱葳幫單車社經營社群帳號，追蹤人數每個月大約變成 1.5 倍。社長問：「照這速度，幾個月後會變成現在的 10 倍？」這是一個「已知倍數、求次數」的問題。這一節把數學1的常用對數推廣到任意底數，學會對數律與換底公式，並用它們解出這類指數方程式。情境例子為原創設計。

指數回答「乘 x 次之後變多少」，對數回答「要乘幾次才會變成這麼多」。數學1學的 log 都是以 10 為底，因為我們用十進位。但生活中的「倍數」不一定是 10：減半是 1／2、每月成長 50% 是 1.5、翻倍是 2。這一節讓 log 接受任何正數當底數，並整理出三條對數律——它們把乘法變加法、除法變減法、次方變乘法，讓原本很難算的式子變得可以手算。

對數的定義

「a 要幾次方才等於 b？」答案叫 logₐb

情境

追蹤人數每月變成 1.5 倍，x 個月後變成原本的 1.5ˣ 倍。要變成 10 倍，就要解 1.5ˣ = 10。

1.5¹ = 1.5、1.5⁵ ≈ 7.6、1.5⁶ ≈ 11.4，所以 x 在 5 和 6 之間。這個「1.5 要幾次方才等於 10」的數，就記作 log1.510。

對數的定義
aˣ = b ⟺ x = logₐb
底數 a > 0 且 a ≠ 1，真數 b > 0

底數的限制和指數函數相同。真數必須是正數，因為 aˣ 永遠大於 0——不存在任何 x 讓 2ˣ = −4 或 2ˣ = 0。

用一用：直接翻成指數
log₂8 = 3　　　　因為 2³ = 8 log₃(1／9) = −2　　因為 3^(−2) = 1／9 log₄2 = 1／2　　　 因為 4^(1／2) = 2 logₐ1 = 0，logₐa = 1（任何合法底數 a）
兩條恆等式
指數與對數互相抵銷
a^(logₐb) = b　　logₐ(aˣ) = x

這兩條就是定義本身換個寫法：logₐb 是「讓 a 變成 b 的指數」，把它放回 a 的指數位置，當然得到 b。

對數律

乘變加、除變減、次方變乘

觀察 → 規律

設 logₐM = m、logₐN = n，也就是 aᵐ = M、aⁿ = N。用指數律：

MN = aᵐ・aⁿ = a^(m+n)　⟹ logₐ(MN) = m + n M／N = aᵐ ÷ aⁿ = a^(m−n) ⟹ logₐ(M／N) = m − n Mᵖ = (aᵐ)ᵖ = a^(pm)　　⟹ logₐ(Mᵖ) = pm
對數律（M、N > 0）
logₐ(MN) = logₐM + logₐN
logₐ(M／N) = logₐM − logₐN
logₐ(Mᵖ) = p・logₐM

對數律只是指數律「翻譯」過來的。常見錯誤：logₐ(M + N) ≠ logₐM + logₐN——對數律處理的是乘除，不是加減。

用一用
log₂12 − log₂3 = log₂(12／3) = log₂4 = 2 log 2 + log 5 = log 10 = 1 log₃√27 = log₃(3^(3／2)) = 3／2 已知 log 2 ≈ 0.3010，log 3 ≈ 0.4771： log 72 = log(2³ × 3²) = 3 log 2 + 2 log 3 ≈ 0.9030 + 0.9542 = 1.8572 log 1.5 = log(3／2) = log 3 − log 2 ≈ 0.1761

只背 log 2 和 log 3，就能用對數律算出 log 4、log 5（= 1 − log 2）、log 6、log 8、log 9、log 1.5……幾乎所有學測需要的值。

換底公式

任何底數的 log，都能換成以 10 為底

回到情境

x = log1.510 要怎麼算出數值？計算機和對數表只有以 10 為底的 log。把 1.5ˣ = 10 兩邊取常用對數：

log(1.5ˣ) = log 10 x・log 1.5 = 1 x = 1 ÷ log 1.5 ≈ 1 ÷ 0.1761 ≈ 5.68 ∴ 大約 5.7 個月（第 6 個月時）追蹤人數就會超過現在的 10 倍
規律 → 公式

同樣的做法用在一般的 logₐb：設 x = logₐb，即 aˣ = b，兩邊取以 c 為底的對數，得到 x・logc a = logc b：

換底公式（c > 0，c ≠ 1）
logₐb = logc b ／ logc a

由換底公式可以推出兩個好用的結論：

換底的推論
logₐb・logb c = logₐc（鏈鎖）
logₐb = 1 ／ logb a（倒數）
logaᵐ bⁿ = (n／m)・logₐb
用一用
log₂3・log₃8 = log₂8 = 3 log₄8 = log2² 2³ = 3／2 log₂5 = log 5 ／ log 2 ≈ 0.6990 ／ 0.3010 ≈ 2.32
解指數與對數方程式

化不了同底，就取 log；有 log，先看真數

情境：咖啡因降到 30 毫克

接續 2-1：200 毫克的咖啡因每 5 小時減半，幾小時後會降到 30 毫克？（log 2 ≈ 0.3010，log 3 ≈ 0.4771）

200 × (1／2)^(t／5) = 30 ⟹ (1／2)^(t／5) = 0.15 兩邊取 log：(t／5)・log(1／2) = log 0.15 log(1／2) = −log 2 ≈ −0.3010 log 0.15 = log(3／20) = log 3 − log 2 − 1 ≈ −0.8239 t／5 ≈ (−0.8239)／(−0.3010) ≈ 2.737 ⟹ t ≈ 13.7（小時）
用一用：對數方程式

解 log₂(x − 1) + log₂(x + 1) = 3。

先寫限制：x − 1 > 0 且 x + 1 > 0 ⟹ x > 1 對數律：log₂((x − 1)(x + 1)) = 3 ⟹ x² − 1 = 2³ = 8 ⟹ x² = 9 x = 3 或 x = −3（不符合 x > 1，捨去） ∴ x = 3

解對數方程式的第一步永遠是寫出真數大於 0 的限制。合併成一個 log 後，原本不合法的解（像 x = −3）會混進來，最後要靠這個限制把它剔除。

收進工具箱：2-2 對數與對數律

對數是指數的反問題。所有對數性質都由「aˣ = b ⟺ x = logₐb」和指數律推得，忘記時翻回指數想一遍就好。

名稱內容
定義aˣ = b ⟺ x = logₐb（a > 0，a ≠ 1，b > 0）
特殊值logₐ1 = 0，logₐa = 1，a^(logₐb) = b
對數律logₐMN = logₐM + logₐN；logₐ(M／N) = logₐM − logₐN；logₐMᵖ = p logₐM
換底公式logₐb = log b ／ log a
換底推論logₐb・logb c = logₐc；logaᵐbⁿ = (n／m)logₐb
常用值log 2 ≈ 0.3010，log 3 ≈ 0.4771，log 5 = 1 − log 2 ≈ 0.6990

練習題

1定義

求 log₅125、log₉3、log₂(1／16) 的值。

參考答案
log₅125 = 3（5³ = 125） log₉3 = 1／2（9^(1／2) = 3） log₂(1／16) = −4（2^(−4) = 1／16）
2對數律

化簡 log₆4 + log₆9。

參考答案
log₆4 + log₆9 = log₆36 = 2
3換底

求 log₂9・log₃32 的值。

參考答案
log₂9 = 2 log₂3，log₃32 = 5 log₃2 乘積 = 10・log₂3・log₃2 = 10 × 1 = 10
4估算

存款每年增加 20%，大約幾年會翻倍？（log 2 ≈ 0.3010，log 3 ≈ 0.4771）

參考答案
1.2ⁿ = 2 ⟹ n = log 2 ／ log 1.2 log 1.2 = log(12／10) = 2 log 2 + log 3 − 1 ≈ 0.6020 + 0.4771 − 1 = 0.0791 n ≈ 0.3010 ／ 0.0791 ≈ 3.8（約 4 年）
5對數方程式

解 log₃x + log₃(x − 8) = 2。

參考答案
限制：x > 0 且 x − 8 > 0 ⟹ x > 8 x(x − 8) = 9 ⟹ x² − 8x − 9 = 0 ⟹ (x − 9)(x + 1) = 0 x = 9 或 x = −1（捨去）⟹ x = 9

下一步：把 log 也畫成一條曲線

對數是指數的反問題，那 y = logₐx 的圖形和 y = aˣ 有什麼關係？在 2-3「對數函數及其圖形」，我們會發現兩條曲線剛好對稱於直線 y = x，並用對數函數的單調性比較大小、解不等式，最後整理出一套處理「按比例成長」問題的通用模型——從碳-14 定年到存款翻倍都適用。
