PART 1 ・ 有理數

分披薩，分出一個新概念

情境

三個好朋友合買了一個披薩，說好要平分。每個人可以吃到整個披薩的幾分之幾？

直覺不難：每人 1/3。那如果換成四個人平分呢？每人 1/4。

換算成小數，這兩個分數分別長什麼樣子？

觀察
1 ÷ 4 = 0.25 ← 除得乾淨，四位就結束 1 ÷ 3 = 0.333333…… ← 除不盡，3 一直循環下去

再追問下去：如果是七個人分呢？

1 ÷ 7 = 0.142857142857…… ← 循環節變成 6 位數，一直重複出現

不管是乾脆除盡，還是無限循環，這些小數都有一個共同的「出身」：它們原本都是整數除以整數，也就是一個分數。

規律 → 定義

幫這一類數字取個名字：只要能寫成 p/q（p, q 都是整數，且 q ≠ 0）的數，就叫做「有理數」（rational number，也就是「比例的數」），記作 ℚ。整數當然也是有理數（n = n/1），所以：

有理數 = 整數、有限小數、無限「循環」小數（都可以寫成「整數÷整數」）
再觀察：循環的部分怎麼寫？

像 1/3 = 0.333…… 這種永遠寫不完的小數，總不能每次都打一串刪節號。數學上的寫法，是在重複出現的那一段數字上面畫一條橫線，叫做循環節：

1/3 = 0.3　　　　1/7 = 0.142857

這條橫線就是在說：「底下這幾位數字，一直重複下去。」

反過來想：循環小數也能還原成分數

如果只看到 x = 0.27 = 0.272727…… 這樣的小數，能不能反推回原本的分數？

關鍵招式：把循環節「搬到小數點前面」，再兩式相減，循環的部分就會剛好完全抵銷：

設 x = 0.272727…… 兩邊同乘 100（循環節是 2 位數，就乘 10²）： 100x = 27.272727…… 用 100x 減去 x： 100x − x = 27.272727…… − 0.272727…… 99x = 27 x = 27/99 = 3/11

驗算一下：3 ÷ 11 = 0.272727……，完全吻合。這招對任何循環小數都管用——乘上「10 的循環節位數次方」，讓循環的尾巴對齊，相減就消失了。

延伸：有理數多到「找不到縫隙」

數線上任兩個不同的有理數之間，還能不能再找到一個有理數？譬如 1/3 和 1/2 之間呢？

最簡單的做法：取兩者的中點。

(1/3 + 1/2) ÷ 2 = (5/6) ÷ 2 = 5/12　　（介於 1/3 ≈0.333 與 1/2=0.5 之間）

而 5/12 一樣是「整數÷整數」，還是有理數。同樣的招式可以無限重複下去——不管兩個有理數靠得多近，中間永遠還擠得下另一個有理數。這個性質叫做有理數的稠密性：數線上任兩個相異的有理數之間，都存在無窮多個有理數。

小提醒：稠密性聽起來像是「有理數已經填滿整條數線」，但下一節會發現，數線上其實還藏著有理數完全碰不到的點——這就是無理數登場的原因。

PART 2 ・ 無理數

量一條對角線，量出一個新世界

情境

筱葳家的花園是一塊邊長 1 公尺的正方形。她想沿著對角線鋪一條石板小路，該訂多長的石板？

觀察

用畢氏定理算對角線長度的平方：

對角線² = 1² + 1² = 2　　→　　對角線 = √2

好，那 √2 到底是多長？用計算機十分逼近，可以得到一系列越來越準確的近似值：

1, 1.4, 1.41, 1.414, 1.4142, 1.41421, ……

驗算看看，這些近似值的平方離 2 有多接近：

1.4² = 1.96 1.41² = 1.9881 1.414² = 1.999396 1.4142²= 1.99996164 ……

不管加多少位小數，都只能「越來越接近」2，永遠對不準。更神奇的是：可以證明，不存在任何一個分數，平方後剛好等於 2。也就是說，這條對角線的長度，沒辦法用任何「整數÷整數」的形式寫出來。

規律 → 定義

這類數，小數位數不循環也不終止，稱為無理數（記作小數不循環、不終止的無限小數）。歷史上第一個被發現的無理數就是 √2——相傳畢氏學派原本深信「萬物皆數（皆比例）」，發現這件事後大受衝擊，數學史上稱為「第一次數學危機」。

圓周率 π = 3.14159265…… 也是無理數，古人取 3 當作近似值，現在通常取 3.14 或 3.14159 來估計。

延伸：一階一階量出更多無理數

量完 √2 之後，可以把它當作下一階的其中一股，再接一個直角三角形：一股是剛量出來的 √2，另一股是 1，斜邊平方 = (√2)²+1² = 2+1 = 3，量出 √3。這樣一階一階接下去，就能在數線上「作圖」量出 √2、√3、√4=2、√5……這種階梯狀的圖形叫做「泰奧多勒斯螺線」。

進階好奇：為什麼 √2 一定不是分數？（點開看證明）

用反證法：假設 √2 可以寫成最簡分數 p/q（p,q 是整數，且已經約到不能再約簡）。

√2 = p/q 兩邊平方：2 = p²/q² 移項： p² = 2q² ← 所以 p² 是偶數，p 也一定是偶數 設 p = 2k： (2k)² = 2q² 4k² = 2q² q² = 2k² ← 所以 q² 也是偶數，q 也一定是偶數

但 p、q 不是說好「已經約到不能再約」了嗎？現在卻發現兩個都是偶數，都還能再除以 2——矛盾！所以一開始的假設不成立，√2 不可能寫成分數。

PART 3 ・ 實數

把兩種數合成一條完整的數線

規律 → 定義

有理數與無理數合起來，稱為實數（記作 ℝ）。實數與數線之間有一個很重要的結論：數線上每一個點，恰好對應一個實數；每一個實數，也恰好對應數線上一個點——不多不少，一一對應，中間沒有縫隙。

為什麼要正式列出規則？

之後解方程式、解不等式，每一次移項、乘開、比大小，其實都在使用底下這幾條規則——只是我們平常寫得很快，沒有特別註明。先正式看過一次，之後才知道自己每一步「憑什麼可以這樣做」。

實數的運算性質（a, b, c 為任意實數）
交換律：a+b=b+a，ab=ba　　　結合律：a+(b+c)=(a+b)+c，a(bc)=(ab)c 分配律：a(b+c)=ab+ac 消去律：a+c=b+c ⟹ a=b；c≠0 時，ac=bc ⟹ a=b 單位元素：a+0=a，a×1=a
實數的大小關係（a, b, c 為任意實數）
三一律：a<b、a=b、a>b 三者恰有一個成立 遞移律：a<b 且 b<c ⟹ a<c 加法：a<b ⟹ a+c<b+c（兩邊同加一個數，不等號方向不變） 乘法：a<b 且 c>0 ⟹ ac<bc；a<b 且 c<0 ⟹ ac>bc（乘負數，不等號要反向！） 平方：a, b>0 時，a²>b² ⟺ a>b
用一用：把無理數估計出大小

√13 大概落在哪兩個整數之間？√8+√7 和 √10+√5 誰比較大？

因為 3² = 9 < 13 < 16 = 4²，由平方性質可知 3 < √13 < 4。 比較 √8+√7 與 √10+√5：兩邊都是正數，可以比較平方 (√8+√7)² = 15 + 2√56 (√10+√5)² = 15 + 2√50 因為 56 > 50，所以 (√8+√7)² > (√10+√5)²， 兩邊開根號（平方性質的逆推）：√8+√7 > √10+√5

這正是上面「平方」那條規則在發揮作用：兩個正數，比大小可以先比平方。

PART 4 ・ 分點公式

速度不同，會合點在哪裡？

情境

在一條筆直的道路上，以路口超商為原點（座標 0），筱葳家在座標 −2（公里），朋友家在座標 4（公里）。兩人同時出發、沿著這條路相向而行，準備在路上會合。筱葳騎腳踏車，朋友用跑的，兩人的速度比是 3 : 5。他們會在數線上哪個座標會合？

觀察

因為兩人同時出發、花的時間一樣，走的距離就跟速度成正比：筱葳走的距離、朋友走的距離，比例也是 3 : 5。設會合點為 P，也就是：

AP : BP = 3 : 5　（A＝筱葳家 −2，B＝朋友家 4）

朋友速度比較快，所以朋友走的路比較長，會合點應該比較靠近筱葳家（A）這一側——這跟直覺是吻合的。

推導

設 P 點座標為 x，則 AP = x−(−2) = x+2，BP = 4−x（假設 P 在 A、B 之間，所以這兩段長度都是正的）：

(x+2)/(4−x) = AP/BP = 3/5 交叉相乘：5(x+2) = 3(4−x) 5x+10 = 12−3x 8x = 2 x = 1/4

會合點在座標 1/4，也就是超商往筱葳家方向 0.25 公里處——確實比較靠近筱葳家（A 在 −2，比較近；B 在 4，比較遠）。

規律 → 公式

把座標換成一般的字母：數線上兩點 A(a)、B(b)（不妨設 a<b），P 點介於 A、B 之間，且 AP : BP = m : n，用同樣的交叉相乘可以推出：

P 點坐標 = (n·a + m·b) / (m+n)

這就是分點公式。特別注意：公式裡 A 的座標 a 配的是後面那個比例 n，B 的座標 b 配的是前面那個比例 m——因為離得比較「遠」的那一端，代表對方走得比較少，比例反而要交叉對調。

把公式套進剛剛的情境驗算一次：a=−2, b=4, m:n=3:5

P = (5×(−2) + 3×4) / (3+5) = (−10+12) / 8 = 2/8 = 1/4 ✓ 與剛剛推導的答案一致
特例：中點公式

如果 m:n = 1:1（也就是兩人速度相同，一定在正中間會合），代入公式：

AB 中點坐標 = (a+b) / 2
延伸：如果會合點不在中間，而在外側？

如果要找的不是「兩人之間」的點，而是在 B 的更外側，找一個點 Q，使得 AQ : BQ 仍然維持 3 : 5——這樣的 Q 在哪裡？

這種「跑到線段外面」的分法，叫做外分點。因為 Q 在 B 的外側，BQ 這段其實是「往回走」，方向跟 AQ 相反，所以式子裡要記得改成減法（或想成比例中出現負號）：

設 Q 座標為 x，AQ = x−(−2) = x+2， BQ = x−4（Q 在 B 右邊，x>4） 外分時 AQ : BQ 仍是 3 : 5，但 AQ 比 BQ 長，交叉相乘： 5(x+2) = 3(x−4) 5x+10 = 3x−12 2x = −22 x = −11

算出來 x=−11 其實落在 A 的左邊更外側——這提醒我們，外分點的位置需要配合圖形仔細判斷在哪一側，不能只套公式蠻算，學測考題通常會搭配數線圖或給定範圍來確認。

PART 5 ・ 區間的表示法

電影院的票價，是怎麼分年齡的？

情境

某電影院的票價規則是這樣的：未滿 3 歲免費入場；3 歲以上、未滿 12 歲是兒童票；65 歲以上（含）享敬老優惠。設觀眾的年齡是 x 歲，這三種身分該怎麼用不等式寫出來？

觀察

「未滿 3 歲」寫成 x<3；「65 歲以上（含 65 歲）」寫成 x≥65；「3 歲以上、未滿 12 歲」寫成兩段夾在一起：3≤x<12。每一種寫法背後，都在回答兩件事：往哪個方向延伸（還是兩邊都有限），以及端點本身算不算數（含或不含）。

規律 → 定義

把「不等式」直接寫成「一段範圍」的簡寫，就是區間表示法。端點有包含用方括號 [ ]，不包含用小括號 ( )；往正無窮或負無窮延伸的一端，永遠用小括號（因為無窮大不是一個實際的數，不可能被「包含」）：

不等式區間表示圖示
x ≥ 65[65, ∞)65 歲以上（含），敬老票
x < 3(−∞, 3)未滿 3 歲，免費
3 ≤ x < 12[3, 12)3 歲以上未滿 12 歲，兒童票
2 ≤ x ≤ 3[2, 3]兩端都包含，稱為閉區間
2 < x < 3(2, 3)兩端都不包含，稱為開區間
延伸：多段合併，用「聯集」符號

如果售票機要一次篩出「享優惠」的觀眾（免費或敬老，但不含一般兒童票），這個身分範圍該怎麼寫？

這時候的範圍是兩段互不相連的區間，中間用聯集符號 ∪ 連接：

x<3 或 x≥65　　⟺　　(−∞, 3) ∪ [65, ∞)

「或」對應「∪（聯集）」；「且」則對應區間的重疊部分（交集）。之後在絕對值不等式、分段討論裡，這套區間語言會一直重複出現。

PART 6 ・ 絕對值的應用

電梯裡的樓層，量出「距離」這個概念

情境

你在捷運共構大樓的 3 樓等朋友。第一個朋友在 7 樓，第二個朋友在地下 2 樓（−2 樓）。你跟這兩個朋友之間，各隔了幾層樓？

觀察

直覺算法是「大的樓層減小的樓層」：

你（3樓）到朋友甲（7樓）：7 − 3 = 4（層） 你（3樓）到朋友乙（−2樓）：3 − (−2) = 5（層）

但如果沒注意順序，隨手寫成 3−7=−4，樓層數變成負的——「隔了 −4 層樓」聽起來就很奇怪。距離這種量，不管往上還是往下數，答案都應該是正的。

規律 → 定義

把「去掉負號、只留下大小」這件事，寫成一個符號：

|7−3| = |4| = 4　　　|3−(−2)| = |5| = 5

正式定義：

|x| = x（x ≥ 0 時）　　|x| = −x（x < 0 時）

幾何意義：|x| 是 x 在數線上到 0 的距離；|x−a| 是 x 到 a 的距離——跟樓層問題完全是同一件事。舉例來說，|2+3| 可以看成 |2−(−3)|，表示 2 與 −3 在數線上的距離。

|x| ≥ 0　　　|x|² = x²　　　|xy| = |x||y|　　　|x/y| = |x|／|y|（y≠0）
應用一：含絕對值的方程式與不等式

螺絲工廠規定，螺絲長度標準是 10 mm，機器容許的誤差是正負 0.2 mm。品管員要怎麼用一個式子，寫出「這根螺絲合格」？

9.8 ≤ x ≤ 10.2 兩邊同時減 10： −0.2 ≤ x−10 ≤ 0.2

而「x−10 的值介於 −0.2 到 0.2 之間」，用距離的語言來說，就是「x 跟 10 之間的距離，不超過 0.2」：

|x−10| ≤ 0.2　　解集合寫成區間：[9.8, 10.2]
規律 → 公式
|x−a| < b　⟺　a−b < x < a+b　⟺　x ∈ (a−b, a+b)

反過來，品管員要挑出不合格的螺絲（超出容許範圍）：

x < 9.8 或 x > 10.2　　　即　|x−10| > 0.2
|x−a| > b　⟺　x < a−b　或　x > a+b　⟺　x ∈ (−∞,a−b) ∪ (a+b,∞)

而剛好卡在臨界值上（差一點就不合格）：

|x−a| = b　⟺　x = a+b　或　x = a−b
應用二：兩個絕對值加在一起

一條筆直的路上，超商 A 在座標 −2 的位置，超商 B 在座標 5 的位置。你想找一個地點 x，讓你走到 A 跟走到 B 的距離「加起來」剛好是 7。你會落在哪裡？

寫成算式：|x−(−2)| + |x−5| = 7，也就是 |x+2| + |x−5| = 7。這裡有兩個絕對值，不能直接套用剛剛的公式。

觀察①：為什麼要分段？

先看單獨一個 |x+2|：它到底等於 x+2，還是 −(x+2)，要看 x+2 是正是負——

如果 x+2 ≥ 0（也就是 x ≥ −2）：|x+2| = x+2 如果 x+2 < 0（也就是 x < −2）：|x+2| = −(x+2)

同樣道理，|x−5| 也有兩種寫法，切換點在 x=5。問題是：這一題兩個絕對值「切換的地方」不一樣（一個在 −2，一個在 5），所以沒辦法只切一刀，必須把數線切成三段，才能讓兩個絕對值在每一段裡都乖乖地只有一種寫法。

觀察②：找出分界點，切成三段

兩個分界點就是超商的位置本身：x=−2（超商 A）和 x=5（超商 B）。以這兩點為界，數線被切成三段：

觀察③：每一段先確認正負號

在動手解方程式之前，先搞清楚每一段裡 x+2 和 x−5 各是正是負。可以先挑一個段內的測試值代進去，直覺感受一下：

區間測試值x+2x−5|x+2| 等於|x−5| 等於
① x<−2x=−10−8（負）−15（負）−(x+2)−(x−5)
② −2≤x<5x=02（正）−5（負）x+2−(x−5)
③ x≥5x=1012（正）5（正）x+2x−5

小技巧：不確定某一段的正負號時，代一個段內隨便的數字進去試試看，比死記規則更不容易出錯。

觀察④：把每一段的寫法代進方程式

有了上面的表，原本的方程式 |x+2|+|x−5|=7 在每一段就變成一個「沒有絕對值」的普通方程式，可以直接解：

第①段（x<−2）：

−(x+2) − (x−5) = 7 −x−2−x+5 = 7 −2x+3 = 7 x = −2

但這一段的條件是 x<−2，解出來的 x=−2 不符合（−2 不小於 −2）。所以這段沒有解。

第②段（−2≤x<5）：

(x+2) + (5−x) = 7 x+2+5−x = 7 7 = 7

x 竟然自己消掉了，剩下「7=7」——這句話不管 x 是多少都成立！代表這一整段（−2 到 5 之間，含 −2）的每一個 x，全部都是解。

第③段（x≥5）：

(x+2) + (x−5) = 7 2x−3 = 7 x = 5

條件是 x≥5，x=5 剛好符合，是這段唯一的解。

把三段的結果收在一起：第①段沒有解，第②段整段都是解，第③段多一個 x=5（但 5 其實已經包含在第②段的範圍裡了）。合併起來：

−2 ≤ x ≤ 5　　寫成區間：[−2, 5]
規律：一個巧合，其實不是巧合

A 到 B 的距離本來就是 5−(−2)=7。只要 x 站在 A、B 中間，往左走到 A、往右走到 B 的距離加起來，當然就是整段 AB 的長度——這不是湊出來的，是「兩點之間直線最短」的另一種說法：繞路（分開走去 A 再去 B）不會比直接走 AB 短。

這正是絕對值裡「三角不等式」|x+y| ≤ |x|+|y| 的幾何意義：等號成立，剛好對應「x 站在中間，沒有繞路」的情況。

1情境

把 x = 0.418（也就是 0.41818181818……，循環節是 18）還原成分數。

查看解答
x = 0.41818…… 100x = 41.8181……　（先讓非循環的「4」對齊，乘 10 移一位） 1000x = 418.181818……　（再乘 10²，讓循環節對齊） 1000x − 10x = 418.1818… − 4.1818… = 414 990x = 414　⟹　x = 414/990 = 23/55
2情境

判斷 1+√2、√2×√2、(1+√3)+(1−√3) 各是有理數還是無理數。

查看解答
1+√2：無理數（有理數＋無理數＝無理數，可用反證法說明） √2×√2 = 2：有理數 (1+√3)+(1−√3) = 2：有理數（√3 互相抵銷）
3代數

判斷 √17 落在哪兩個相鄰整數之間。

查看解答
4²=16 < 17 < 25=5²　⟹　4 < √17 < 5
4情境

數線上 A 點坐標 −3，B 點坐標 7。P 在 AB 之間且 AP:AB = 1:4，求 P 的坐標。

查看解答
AP:PB = 1:3（因為 AP:AB=1:4，所以 AP:PB=1:3）：
P = (3×(−3)+1×7)/(1+3) = (−9+7)/4 = −1/2
5情境

用區間表示法寫出：5<x≤6，以及 x<4 或 x≥1。

查看解答
5<x≤6　⟹　(5, 6] x<4 或 x≥1　⟹　全體實數 ℝ（因為兩段區間重疊涵蓋了所有數）
6代數

解不等式 1≤|x|<3，並寫成區間聯集。

查看解答
|x|≥1 且 |x|<3 ⟹ (x≤−1 或 x≥1) 且 (−3<x<3) ⟹ x∈(−3,−1] ∪ [1,3)
7情境

某手工水餃包裝標示，每顆重量是 32 公克 ± 5%。設每顆水餃的實際重量為 x 公克，寫出 x 滿足的絕對值不等式。（提示：P公克±a%意指 P公克±P×a%公克）

查看解答
誤差範圍是 32×5% = 1.6 公克：
|x−32| ≤ 1.6
8代數

解方程式 |x|+|x−5|≥1。

查看解答
分界點 x=0, x=5，分三段討論：
x<0：−x−(x−5)≥1 ⟹ −2x+5≥1 ⟹ x≤2，配合 x<0 ⟹ x<0（全部符合） 0≤x<5：x−(x−5)=5≥1（恆成立）⟹ 這段全部符合 x≥5：x+(x−5)≥1 ⟹ 2x≥6 ⟹ x≥3，配合 x≥5 ⟹ x≥5（全部符合）
合併：x∈ℝ（所有實數都滿足，因為 0、5 兩點距離已經是 5，加起來一定 ≥1）。
9代數

解不等式 |2x−1|≤3。

查看解答
−3≤2x−1≤3 ⟹ −2≤2x≤4 ⟹ −1≤x≤2　⟹ x∈[−1,2]
10情境

P、Q 是數線上兩點，坐標分別是 2、12。R 在 P、Q 之間，且 PR:RQ=3:2，求 R 的坐標，並求 R 到 P、Q 的距離和。

查看解答
R = (2×2+3×12)/(3+2) = (4+36)/5 = 8 PR = |8−2|=6，RQ=|12−8|=4，PR+RQ=10=PQ ✓

給筱葳的話

這一節走了一趟完整的路：先認識有理數（分披薩），再發現無理數（量對角線），合併成實數，接著學會用分點公式精準定位數線上的任何一點，用區間表示法描述一段範圍，最後用絕對值量出「距離」。
