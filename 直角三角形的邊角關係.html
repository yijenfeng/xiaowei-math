數學2・第四章 三角比的性質與應用・4-1

直角三角形的邊角關係

筱葳加入了學校的「測量社」，這學期社團的任務是用簡單的工具，量出校園裡各種量不到的高度與距離。這一節先從最基礎的直角三角形出發，認識三角比的定義、基本關係，以及如何用計算機求值並應用在仰角、俯角上。情境例子為原創設計。

測量社的第一堂課，老師只發給每個人一條有刻度的繩子和一個量角器，說：「用這兩樣東西，就能算出攀岩牆的高度。」筱葳很疑惑——沒有捲尺，要怎麼量出高度？老師說，關鍵就在直角三角形裡，角度和邊長之間有著固定的比例關係，這就是這一節要學的「三角比」。

直角三角形的三角比

相似三角形裡，邊長的比例只跟角度有關

情境

測量社的攀岩牆有一根三角形的斜撐架，最小的那一副（教具模型）斜邊長6公分、和地面夾30°角；社辦倉庫裡還有大一點的斜撐架，斜邊12公分，同樣和地面夾30°角。兩副撐架大小不同，但形狀一模一樣（都是30°-60°-90°的直角三角形）。

因為兩個三角形相似，對應邊長的比例一定相同。量出小撐架的三邊是3、3√3、6，大撐架的三邊是6、6√3、12——不管撐架多大，「30°的對邊長：30°的鄰邊長：斜邊長」永遠是 1 : √3 : 2。

觀察 → 規律 → 公式

把這個「比例只跟角度有關、跟大小無關」的性質推廣到任意銳角 θ：在直角三角形中，固定 θ 之後，「θ的對邊長」「θ的鄰邊長」「斜邊長」這三邊兩兩的比值就固定下來了，分別定義為正弦、餘弦、正切：

直角三角形的三角比
sin θ = θ的對邊長 ／ 斜邊長　　（正弦）
cos θ = θ的鄰邊長 ／ 斜邊長　　（餘弦）
tan θ = θ的對邊長 ／ θ的鄰邊長　　（正切）

用小撐架驗算：sin30° = 3／6 = 1／2，cos30° = 3√3／6 = √3／2，tan30° = 3／3√3 = 1／√3 = √3／3。這三個值不會因為換成大撐架而改變。

用一用

社辦另一副斜撐架是等腰直角三角形（45°-45°-90°），兩股長都是5公分。求 sin45°、cos45°、tan45°。

斜邊 = √(5²+5²) = 5√2 sin45° = 5／5√2 = 1／√2 = √2／2 cos45° = 5／5√2 = √2／2 tan45° = 5／5 = 1

把 30°、45°、60° 這三個常用角的三角比整理成表格，之後會反覆用到：

cos θ√3／2√2／21／2
tan θ√3／31√3
用一用：一般的直角三角形

測量社在攀岩牆下方架設了一個三角形護欄，量出三邊長恰好是8公尺、15公尺、17公尺（8²+15²=17²）。設最短邊所對的角為 θ，求 sinθ、cosθ、tanθ。

斜邊（最長邊）= 17，θ的對邊 = 8，θ的鄰邊 = 15 sinθ = 8／17，cosθ = 15／17，tanθ = 8／15

三角比只是「兩邊長的比值」，所以不管三角形是用公分還是公尺量測，算出來的 sinθ、cosθ、tanθ 都是不帶單位的純數字。

反過來想：由三角比求邊長

護欄的另一根樑柱，已知斜邊長20公尺，且其中一個銳角A滿足 sinA=3／5，求A的對邊長。

sinA = 對邊 ／ 斜邊 3／5 = 對邊 ／ 20 對邊 = 20 × 3／5 = 12 公尺
三角比的基本關係

sinθ、cosθ、tanθ 之間藏著三條恆等式

觀察 → 規律：商數關係

設直角三角形中 θ 的對邊、鄰邊、斜邊分別為 a、b、c，則 sinθ=a／c，cosθ=b／c。把兩者相除：

sinθ／cosθ = (a／c)／(b／c) = a／b = tanθ
商數關係（0°<θ<90°）
sinθ／cosθ = tanθ
觀察 → 規律：平方關係

由畢氏定理 a²+b²=c²，兩邊同除以 c²：

(sinθ)² + (cosθ)² = a²／c² + b²／c² = (a²+b²)／c² = c²／c² = 1
平方關係（0°<θ<90°）
sin²θ + cos²θ = 1
觀察 → 規律：餘角關係

直角三角形的兩個銳角互為餘角（一個是θ，另一個就是90°−θ）。對90°−θ這個角來說，原本θ的對邊變成了它的鄰邊，原本θ的鄰邊變成了它的對邊：

餘角關係（0°<θ<90°）
sin(90°−θ) = cosθ　　cos(90°−θ) = sinθ

這正是「正弦（sine）」與「餘弦（co-sine）」這兩個名字的由來——餘弦就是「餘角的正弦」。

用一用

護欄斜撐的一個角θ滿足 sinθ=7／25，求 cosθ 與 tanθ 的值（θ為銳角）。

sin²θ + cos²θ = 1 cos²θ = 1 − (7／25)² = 1 − 49／625 = 576／625 cosθ = 24／25　（θ為銳角，cosθ取正值） tanθ = sinθ／cosθ = (7／25)／(24／25) = 7／24
用一用：綜合應用

已知 0°<θ<90°，且 sinθ−cosθ=7／17，求 sinθcosθ、sinθ+cosθ、sin³θ−cos³θ 的值。

(sinθ−cosθ)² = (7／17)² sin²θ+cos²θ − 2sinθcosθ = 49／289 1 − 2sinθcosθ = 49／289 sinθcosθ = 120／289 (sinθ+cosθ)² = 1 + 2sinθcosθ = 1 + 240／289 = 529／289 0°<θ<90°，sinθ、cosθ皆為正，故 sinθ+cosθ = 23／17 sin³θ−cos³θ = (sinθ−cosθ)(sin²θ+sinθcosθ+cos²θ) = (7／17)(1 + 120／289) = (7／17)×(409／289) = 2863／4913

遇到「已知sinθ±cosθ求其他式子」的題型，第一步幾乎都是「把已知條件平方」——平方後會自動出現sin²θ+cos²θ，馬上就能用平方關係化簡出sinθcosθ。

用計算機求三角比與角度・仰角與俯角

不是特殊角，就交給計算機

情境

30°、45°、60°這些特殊角很好算，但實際到攀岩牆下方測量時，量角器量出來的角度往往是35°、42°這種不整齊的角度。這時候就需要用計算機求出三角比的近似值。

使用計算機前，要先確認角度模式設定為「DEG」（degree，度），輸入角度後按下 sin、cos 或 tan 鍵，就能得到近似值；反過來，如果已知三角比要找角度，則要用 sin⁻¹、cos⁻¹、tan⁻¹（通常標示為 SHIFT+sin 等）。角度也可以用「度分秒」表示：1°=60′，1′=60″。

用一用

已知 tanθ=0.6，用計算機求θ的度數（取到小數點後兩位），並轉換成度分秒表示。

按 tan⁻¹(0.6) ≈ 30.96° 換算度分秒：0.96° × 60 ≈ 57.83′，0.83′ × 60 ≈ 50″ θ ≈ 30°57′50″（四捨五入取到秒）
情境延伸：仰角與俯角

從水平線往上看目標物的夾角，叫做仰角；從水平線往下看目標物的夾角，叫做俯角。測量社常利用仰角、俯角搭配已知的距離，求出量不到的高度。

測量社在距離攀岩牆底部12公尺處，用測角器測得牆頂的仰角為35°，求攀岩牆的高度（取到小數點後一位）。

tan35° = 高度 ／ 12 高度 = 12 × tan35° ≈ 12 × 0.7002 ≈ 8.4 公尺
用一用：俯角應用

筱葳站在社辦大樓二樓陽台，離地面高度8公尺，往下看操場上的一個記號，測得俯角為25°，求筱葳與記號之間的水平距離（取到小數點後一位）。

俯角與水平線平行時所形成的直角三角形中，25°角的對邊是陽台高度8公尺，鄰邊是水平距離 tan25° = 8 ／ 水平距離 水平距離 = 8 ／ tan25° ≈ 8 ／ 0.4663 ≈ 17.2 公尺

俯角的直角三角形，是把仰角的三角形「反過來看」——由於水平線互相平行，俯角在數值上會等於從下往上看的仰角，這是它們的內錯角相等。

三角比定義sinθ=對邊／斜邊，cosθ=鄰邊／斜邊，tanθ=對邊／鄰邊

練習題

1特殊角

求 sin45°cos45° + tan60°sin30° 的值。

參考答案
sin45°cos45° = (√2／2)×(√2／2) = 1／2 tan60°sin30° = √3 × 1／2 = √3／2 總和 = 1／2 + √3／2 = (1+√3)／2
2三角比定義

直角三角形兩股長為9、12，斜邊長為15，求最短邊所對角θ的sinθ、cosθ、tanθ。

參考答案
sinθ=9／15=3／5，cosθ=12／15=4／5，tanθ=9／12=3／4
3平方關係

設θ為銳角，若sinθ=5／13，求cosθ與tanθ的值。

參考答案
cos²θ=1−(5／13)²=144／169，cosθ=12／13（θ為銳角取正值） tanθ=sinθ／cosθ=(5／13)／(12／13)=5／12
4仰角應用

測量社在距離某建築物底部20公尺處，測得頂端仰角為40°，求建築物高度（取到小數點後一位）。

參考答案
高度 = 20 × tan40° ≈ 20 × 0.8391 ≈ 16.8 公尺
5綜合應用

設0°<θ<90°，若sinθ+cosθ=6／5，求sinθcosθ的值。

參考答案
(sinθ+cosθ)² = 1+2sinθcosθ (6／5)² = 1+2sinθcosθ 36／25 − 1 = 2sinθcosθ sinθcosθ = 11／50

下一步：角度不再只限於0°到90°

三角比的定義目前只適用於直角三角形裡的銳角，範圍是0°到90°。但現實中的角度常常超過這個範圍——體操選手轉體可以超過360°，方向也可以是任意角度。在4-2「廣義角與極坐標」，我們會延續測量社的故事，把三角比的定義擴展到任意大小的角，並學習用「距離＋方向」描述位置的極坐標。
