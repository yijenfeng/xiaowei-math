4-1

直線方程式及其圖形

從「坡道陡不陡」出發，一路推出斜率、直線方程式、直線的平移，以及兩條直線之間的關係。

直線的斜率

坡道多陡才合格？

情境

建築法規規定，公共場所的無障礙坡道，坡度不能超過 1/12（也就是每垂直上升 1 公分，水平長度至少要有 12 公分）。工地師傅蓋了一段坡道，起點在地面 (0,0)，終點在 (300,20)（單位：公分）。這段坡道合格嗎？

觀察

要判斷「陡不陡」，關鍵是「垂直上升量」跟「水平前進量」的比值。從 (0,0) 走到 (300,20)：

垂直上升量 Δy = 20 − 0 = 20 水平前進量 Δx = 300 − 0 = 300 坡度 = Δy／Δx = 20／300 = 1／15

因為 1/15 < 1/12（分母越大，坡度越平緩），這段坡道比法規要求更平緩，合格。

規律 → 公式：斜率

把「坡度」這個概念一般化，用坐標平面上任意兩點 A(x₁,y₁)、B(x₂,y₂)（x₁≠x₂）定義斜率：

m = (y₂−y₁) ／ (x₂−x₁)

斜率的正負與大小，直接對應圖形的陡緩與方向：

斜率 m圖形意義
m > 0由左往右上升（越大越陡）
m < 0由左往右下降（絕對值越大越陡）
m = 0水平線
不存在鉛直線（x₁=x₂，垂直地面）

法規講的「1/12」其實就是斜率的絕對值上限：|m|≤1/12。師傅蓋的坡道斜率 m=1/15≈0.067，比上限 1/12≈0.083 小，所以合格；斜率的分母越大（同樣上升高度，水平距離越長），坡道越平緩越安全。

用一用

另一段坡道從 (0,0) 到 (150,15)，合格嗎？

m = (15−0)／(150−0) = 15／150 = 1／10

1/10 > 1/12（分母較小，坡度較陡），超過法規上限，不合格，必須把坡道加長或降低高度。

直線方程式

怎麼寫出整條坡道的路徑？

情境

工地師傅想在圖面上，用一個方程式表示「恰好等於法規上限坡度」的坡道路徑，這樣只要代入任何一個水平位置 x，就能立刻查出這個位置的坡道高度該蓋多高，不用每次都重新畫圖。

觀察

已知坡道起點 (0,0)，斜率 m=1/12。坐標平面上任何一點 (x,y)，只要跟起點連線的斜率也是 1/12，就會落在同一條坡道上：

(y−0)／(x−0) = 1／12　　⟹　　y = x／12

更一般地，如果直線通過已知點 (x₁,y₁)、斜率為 m，同樣的推理給出：

規律 → 公式
點斜式（已知一點與斜率）
y − y₁ = m(x − x₁)

把點斜式展開整理，可以化成幾種常見形式：

斜截式（已知斜率 m 與 y 截距 b）
y = mx + b
一般式（a, b 不同時為 0）
ax + by + c = 0
截距式（已知 x 截距 a、y 截距 b，且 a≠0, b≠0）
x／a + y／b = 1

鉛直線（斜率不存在）沒辦法寫成斜截式或截距式（若鉛直線不過原點，它沒有 y 截距），但可以寫成一般式，例如 x=5 就是 1·x+0·y−5=0；這也是一般式比其他形式更「萬用」的原因。

用一用

另一段坡道通過點 (50,10)，斜率為 1/10，求它的方程式，並化成一般式；如果這條坡道的 x 截距是 −50、y 截距是 5，寫出它的截距式。

點斜式：y−10 = (1/10)(x−50) 展開：y−10 = x/10 − 5 斜截式：y = x/10 + 5 一般式：x − 10y + 50 = 0 截距式（x截距−50，y截距5）：x／(−50) + y／5 = 1
直線的平移

扶手要架在坡道正上方，方程式怎麼變？

情境

設計單位想在原本的坡道（y=x/12）正上方 1 公尺處，加裝一條同坡度的扶手；另外，整條坡道又計畫整體往右平移 2 公尺（起點從 (0,0) 移到 (2,0)）。扶手跟新坡道的方程式該怎麼寫？

觀察

把一條直線「垂直移動」，代表每個點的 y 坐標都加上同一個數；把它「水平移動」，代表每個點的 x 坐標都加上同一個數。扶手比坡道整體高 1，所以扶手上每一點的 y 都是坡道對應點的 y 再加 1：

坡道：y = x/12 扶手（往上移 1）：y = x/12 + 1

新坡道則是整條線往右移 2，也就是「原本 x 位置」現在要用「新 x 減 2」去代入：

新坡道：y = (x−2)／12　（起點：x=2 時 y=0，符合 (2,0)）
規律 → 公式

設 h,k>0，直線 y=mx+b：

平移方式新方程式
向上平移 ky = mx + b + k
向下平移 ky = mx + b − k
向右平移 hy = m(x − h) + b
向左平移 hy = m(x + h) + b

關鍵是：垂直平移直接對常數項加減；水平平移則是把方程式裡的 x 換成「x 減去（向右）」或「x 加上（向左）」平移量——很多人會弄反方向，可以代一個具體點驗證，例如新坡道令 x=2 應該要得到起點的 y=0。平移不會改變斜率，兩條直線仍然互相平行。

兩直線的關係

新路要跟主幹道平行，還是垂直？

情境

都市計畫中，主幹道的方程式是 y=2x+3。現在要規劃一條新的巷道，通過點 (4,1)，並且要跟主幹道垂直（方便設計十字路口）。新巷道的方程式該怎麼寫？

觀察

兩條直線的「平行」與「垂直」，本質上都是斜率之間的關係。想像把主幹道的方向繞原點旋轉 90°：斜率會從 m 變成 −1/m（正負對調、倒數）。可以驗證：主幹道斜率 2，垂直方向的斜率是 −1/2，兩者相乘 2×(−1/2)=−1。

規律 → 公式
兩線平行、垂直的判定（斜率 m₁、m₂ 皆存在時）
平行：m₁ = m₂　　　　垂直：m₁ · m₂ = −1

用這個規律解決一開始的問題：主幹道斜率 m₁=2，垂直的新巷道斜率 m₂=−1/2，再用點斜式代入通過的點 (4,1)：

y − 1 = −(1/2)(x − 4) y = −x/2 + 2 + 1 新巷道方程式：y = −x/2 + 3

如果兩條路的斜率都不存在（都是鉛直線），也視為互相平行；一條鉛直線與一條水平線則必定互相垂直，這兩種情況不能直接套用「m₁m₂=−1」，因為鉛直線沒有斜率。

4-2

直線方程式的應用

把「兩條路怎麼相交」翻譯成聯立方程式，把「離馬路多遠才安全」翻譯成點到直線的距離，再把「哪一邊可以蓋房子」翻譯成二元一次不等式。

聯立方程式的幾何意義

兩條路的交叉口在哪裡？

情境

承上一節：主幹道 y=2x+3，垂直的新巷道 y=−x/2+3。這兩條路會在哪一點交會，好規劃紅綠燈？

觀察 → 規律

交叉口同時滿足兩條路的方程式，也就是聯立方程式的解。解聯立方程式，幾何上就是在找「兩條直線的共同點」：

2x+3 = −x/2+3 2x + x/2 = 0 (5/2)x = 0　⟹　x = 0，代回 y = 2(0)+3 = 3 交點：(0, 3)

一般化來看，兩條直線 a₁x+b₁y=c₁ 與 a₂x+b₂y=c₂ 聯立後，會有三種可能：

斜率關係解的情況幾何意義
斜率不同恰有一組解兩線相交於一點
斜率相同，截距不同無解兩線平行不相交
斜率相同，截距也相同無限多組解兩線其實是同一條線（重合）
用一用

如果規劃單位改提議另一條巷道 y=2x+7，它會跟主幹道 y=2x+3 交會嗎？

兩式斜率皆為 2，但常數項不同（3 ≠ 7） ⟹ 無解，兩條路互相平行，永遠不會相交
點到直線的距離

消防栓離馬路夠遠嗎？

情境

消防法規要求消防栓距離主幹道（中心線）至少 5 公尺。有一個消防栓設在 (10,2)，主幹道方程式是 2x−y+3=0，這個消防栓的位置合格嗎？

觀察 → 規律 → 公式
點 (x₀,y₀) 到直線 ax+by+c=0 的距離
d = |a·x₀ + b·y₀ + c| ／ √(a²+b²)
d = |2(10) − 2 + 3| ／ √(2²+(−1)²) = |20 − 2 + 3| ／ √5 = 21 ／ √5 ≈ 9.39（公尺）

9.39 > 5，合格。

延伸：兩條平行路之間的寬度

如果想知道主幹道 2x−y+3=0 跟另一條與它平行、方程式為 2x−y−7=0 的輔助道路之間相距多遠，可以直接用「兩平行線距離公式」，不必先找一個點：

兩平行線 ax+by+c₁=0 與 ax+by+c₂=0 的距離
d = |c₁−c₂| ／ √(a²+b²)
d = |3−(−7)| ／ √(2²+(−1)²) = 10／√5 = 2√5 ≈ 4.47（公尺）
二元一次不等式

候診區要畫在分隔線的哪一邊？

情境

診所大廳要用一條分隔線 x+y=10（單位：公尺）把地板分成兩區：靠近門口的一側放候診椅，另一側留給服務櫃檯。已知門口在原點 (0,0) 附近，候診椅該畫在哪一個不等式所代表的區域裡？

觀察

一條直線 ax+by+c=0 會把平面切成兩半；每一半都可以用一個不等式表示，只要挑一個「不在線上」的點代入，看代入後是大於 0 還是小於 0，就知道那一側對應哪個不等式：

分隔線：x+y−10=0 代入門口 (0,0)：0+0−10 = −10 < 0 ⟹ 門口這一側滿足 x+y−10<0，也就是 x+y<10

所以候診椅要畫在 x+y<10 這一側。

規律 → 公式

一般地，設 a,b 不同時為 0，直線 L：ax+by+c=0 把平面分成兩個半平面：

不等式邊界線圖示
ax+by+c>0 或 <0不含邊界畫虛線
ax+by+c≥0 或 ≤0含邊界畫實線

判斷哪一側對應哪個不等式，最簡單的方法就是「代一個不在線上的點」（不在線上的原點通常最方便），代入後的正負號就是那一整側的正負號——因為同一側的點，代入 ax+by+c 的正負號都相同。多個不等式同時成立（像「候診椅要在門口那一側，同時又要在櫃檯的另一條界線內」）時，答案就是每個不等式代表的區域「疊」起來的共同部分。

用一用

候診椅除了要滿足 x+y<10，還必須在櫃檯圍欄 x−y=−2 靠近門口（原點）的那一側，寫出這一側對應的不等式，並說明候診椅區域是哪兩個不等式的共同部分。

圍欄：x−y+2=0，代入 (0,0)：0−0+2=2>0 ⟹ 門口這一側滿足 x−y+2>0 候診椅區域：{ x+y<10 且 x−y+2>0（不含邊界，用虛線）}
4-3

圓與直線的關係

從噴水池、廣場的涵蓋範圍出發，推出圓的方程式，再討論一個點、一條直線分別跟圓的位置關係，最後學會求圓的切線方程式。

圓的定義與方程式

灑水器能澆到多遠的花？

情境

公園中央的灑水器裝在坐標原點 (0,0)，出水射程是 8 公尺，只要花圃裡的花距離灑水器不超過 8 公尺，就澆得到水。花圃裡有一朵花種在 (5,6)，澆得到嗎？

觀察

灑水器能澆到的所有位置，就是「跟圓心距離恰好等於（或小於）半徑」的所有點——這正是圓的定義。設圓上任一點 (x,y)，圓心 (0,0)，半徑 8，用兩點間距離公式：

√(x²+y²) = 8　　⟹　　x²+y² = 64

那朵花在 (5,6)，距離灑水器：

√(5²+6²) = √(25+36) = √61 ≈ 7.81（公尺）

7.81 < 8，澆得到。

規律 → 公式

一般化：圓心在 (h,k)、半徑為 r 的圓：

標準式
(x−h)² + (y−k)² = r²

把標準式展開，可以化成另一種常見形式：

(x−h)²+(y−k)² = r² x²−2hx+h² + y²−2ky+k² = r² x²+y² + (−2h)x + (−2k)y + (h²+k²−r²) = 0
一般式（D=−2h，E=−2k，F=h²+k²−r²）
x² + y² + Dx + Ey + F = 0

一般式看起來跟標準式差很多，但只要用配方法「補回」被展開藏起來的 (x−h)²、(y−k)²，就能還原出圓心和半徑。若配方後右邊等於 0，圖形只是「一個點」；若右邊是負數，就沒有實際的圓存在——並不是每個 x²+y²+Dx+Ey+F=0 的形式都真的代表一個圓。

用一用

某電信基地台訊號涵蓋範圍是圓心 (3,4)、半徑 10 公里的圓。寫出標準式與一般式。

標準式：(x−3)²+(y−4)² = 100 展開：x²−6x+9 + y²−8y+16 = 100 一般式：x²+y²−6x−8y−75 = 0

反過來，已知一般式 x²+y²−6x−8y−75=0，求圓心與半徑。

配方：(x²−6x+9) + (y²−8y+16) = 75+9+16 (x−3)² + (y−4)² = 100 圓心 (3,4)，半徑 √100 = 10
圓與點的位置關係

工人站在爆破警戒圈的哪裡？

情境

工地進行爆破作業，安全規定要求半徑 50 公尺內（含邊界）都算危險區，警戒圈圓心設在爆破點 (0,0)。三名工人分別站在 (30,20)、(48,14)、(60,10)，誰的位置是安全的？

觀察 → 規律 → 公式

判斷一個點跟圓的位置關係，只要比較「這個點到圓心的距離」跟「半徑」的大小：

比較位置關係
距離 < r在圓內
距離 = r在圓上
距離 > r在圓外
警戒圓：x²+y²=2500（半徑 50） 工人甲 (30,20)：30²+20²=900+400=1300<2500 ⟹ 在圓內（危險） 工人乙 (48,14)：48²+14²=2304+196=2500=2500 ⟹ 在圓上（仍算危險，因為含邊界） 工人丙 (60,10)：60²+10²=3600+100=3700>2500 ⟹ 在圓外（安全）

如果圓是用一般式 x²+y²+Dx+Ey+F=0 給的，不需要先化成標準式：把點的坐標代入「x²+y²+Dx+Ey+F」這個式子，結果小於 0 表示在圓內、等於 0 表示在圓上、大於 0 表示在圓外——這跟直接比較距離和半徑的結論是一致的，只是省去先求圓心、半徑的步驟。

圓與直線的關係

步道會不會切過水池？

情境

公園裡有一座圓形水池，圓心在 (0,0)，半徑 5 公尺。園方想蓋一條筆直的步道，方程式是 x+y=8。這條步道會不會穿過水池？

觀察

關鍵在於比較「圓心到這條直線的距離」跟「半徑」的大小——這正好可以用 4-2 學過的點到直線距離公式：

直線：x+y−8=0（即 a=1, b=1, c=−8） d = |1(0)+1(0)−8| ／ √(1²+1²) = 8／√2 = 4√2 ≈ 5.66（公尺）

5.66 > 5（半徑），圓心到步道的距離比半徑還遠，步道不會穿過水池。

規律 → 公式

設圓心到直線的距離為 d，圓半徑為 r：

比較位置關係交點數
d > r相離0
d = r相切1
d < r相交2

除了「幾何判別法」（比較 d 與 r），也可以把直線代入圓的方程式，消去一個變數後得到一個一元二次方程式，再看判別式 D=B²−4AC 的正負：D>0 對應相交、D=0 對應相切、D<0 對應相離——這種「代數判別法」跟幾何判別法會得到完全一致的結論，遇到直線是鉛直線（不能用斜率）時特別好用。

用一用

如果園方改把步道規劃成 x+y=6，還有 x+y=5√2，這兩條步道分別跟水池是什麼關係？

x+y=6：d = |0+0−6|／√2 = 6/√2 = 3√2 ≈ 4.24 < 5　⟹　相交，會穿過水池 x+y=5√2：d = |0+0−5√2|／√2 = 5√2/√2 = 5 = r　⟹　相切，恰好碰到水池邊緣

相交代表步道會直接穿過水池中央區域，通常設計上會避開；相切則是「剛好貼著池邊」，實務上也常常會再留一點安全距離，不會真的設計成恰好相切。

圓的切線

沿著廣場邊緣走的路要怎麼設計？

情境

社區有一座圓形廣場，圓心 (2,3)、半徑 5 公尺。廣場邊緣的入口在 (5,7)（可驗證：(5−2)²+(7−3)²=9+16=25，確實在圓上），設計單位想從入口拉一條「恰好貼著廣場邊緣、不切進廣場內部」的步道，這條步道（也就是圓在入口這一點的切線）方程式該怎麼求？

觀察 → 規律：切線垂直半徑

圓上一點的切線，有一個很重要的幾何性質：切線必定垂直於「圓心到這一點」的半徑（因為切線是最貼近圓、但完全不切入圓內部的直線，唯一的接觸方式就是與半徑垂直）。先求圓心到入口的斜率，再用「垂直斜率乘積 −1」求切線斜率：

半徑方向斜率：(7−3)／(5−2) = 4／3 切線斜率：−1 ÷ (4／3) = −3／4

再用點斜式，代入切點 (5,7)：

y − 7 = −(3/4)(x − 5) 4(y−7) = −3(x−5) 4y − 28 = −3x + 15 切線方程式：3x + 4y − 43 = 0
延伸：從圓外一點拉切線

另一座圓形噴水池，圓心在原點、半徑 4 公尺。岸上有一座燈柱在 (0,5)（距圓心 5 公尺，因為 5>4 所以燈柱在池外），想從燈柱架兩條筆直的護欄，恰好貼著水池邊緣（也就是兩條切線），這兩條護欄的方程式是什麼？

這次不知道切點在哪裡，但可以設護欄的方程式為「通過 (0,5)、斜率 m」，再用「圓心到這條線的距離＝半徑」來解出 m：

護欄：y = mx + 5　⟹　mx − y + 5 = 0 圓心 (0,0) 到護欄的距離 = 半徑 4： |m(0) − 0 + 5| ／ √(m²+1) = 4 5 ／ √(m²+1) = 4 √(m²+1) = 5／4 m² + 1 = 25／16 m² = 9／16　⟹　m = ±3／4

所以兩條護欄分別是 y = (3/4)x + 5 與 y = −(3/4)x + 5（一個點在圓外，恰好可以拉出兩條不同的切線）。

4-1　直線方程式及其圖形

用途公式
斜率m = (y₂−y₁)／(x₂−x₁)
點斜式y−y₁ = m(x−x₁)
斜截式y = mx+b
一般式ax+by+c = 0
截距式x／a + y／b = 1
向上／向右平移y=mx+b+k（上移k）；y=m(x−h)+b（右移h）
平行m₁ = m₂
垂直m₁·m₂ = −1

4-2　直線方程式的應用

用途公式
聯立方程式的解斜率不同→一解；斜率同截距異→無解；完全相同→無限多解
點到直線距離d = |ax₀+by₀+c| ／ √(a²+b²)
兩平行線距離d = |c₁−c₂| ／ √(a²+b²)
二元一次不等式代一點入 ax+by+c 判正負，決定半平面

4-3　圓與直線的關係

用途公式
標準式(x−h)²+(y−k)² = r²（圓心 (h,k)，半徑 r）
一般式x²+y²+Dx+Ey+F = 0
點與圓位置關係距離<r 圓內；=r 圓上；>r 圓外
圓與直線關係d>r 相離；d=r 相切；d<r 相交
圓上一點的切線切線斜率 = −1 ÷（圓心到該點的斜率）
圓外一點的切線設過該點的直線，令圓心到直線距離＝半徑，解斜率

1情境

某段坡道從 (0,0) 到 (400,30)，是否符合「坡度不超過 1/12」的法規？

查看解答
m = 30/400 = 3/40 = 0.075 1/12 ≈ 0.083，0.075 < 0.083，合格
2代數

求通過 (2,−1)、斜率為 3 的直線方程式（化為一般式）。

查看解答
y−(−1) = 3(x−2) y+1 = 3x−6 一般式：3x−y−7 = 0
3代數

直線 y=3x 向下平移 2、再向左平移 1，求新方程式。

查看解答
向下移 2：y=3x−2 再向左移 1（x 換成 x+1）：y=3(x+1)−2=3x+1
4情境

主幹道方程式 y=−2x+5，另一條巷道要與它平行，且通過 (1,1)，求巷道方程式。

查看解答
平行，斜率相同：m=−2 y−1 = −2(x−1) y = −2x+3
5代數

求兩直線 x+y=4 與 x−y=2 的交點；並判斷 x+y=4 與 x+y=9 是否相交。

查看解答
兩式相加：2x=6 ⟹ x=3 代回：3+y=4 ⟹ y=1 交點 (3,1) x+y=4 與 x+y=9：斜率相同、常數不同 ⟹ 無解，兩線平行不相交
6情境

路燈規定要距離道路中心線（3x−4y+1=0）至少 2 公尺，某路燈設於 (1,2)，是否合格？

查看解答
d = |3(1)−4(2)+1| ／ √(3²+4²) = |3−8+1|／5 = 4／5 = 0.8（公尺） 0.8 < 2，不合格，路燈離道路太近
7情境

圖書館用分隔線 x−y=4 隔開閱覽區與走道，服務台在 (0,0) 這一側算走道，寫出閱覽區對應的不等式。

查看解答
分隔線：x−y−4=0，代入 (0,0)：0−0−4=−4<0（走道側） ⟹ 閱覽區（另一側）：x−y−4>0，即 x−y>4
8代數

寫出圓心 (−2,5)、半徑 6 的圓的標準式與一般式。

查看解答
標準式：(x+2)²+(y−5)² = 36 展開：x²+4x+4+y²−10y+25 = 36 一般式：x²+y²+4x−10y−7 = 0
9代數

已知圓 x²+y²+2x−4y−4=0，求圓心與半徑；並判斷點 (3,3) 在圓內、圓上還是圓外。

查看解答
(x²+2x+1)+(y²−4y+4) = 4+1+4 (x+1)²+(y−2)² = 9 圓心 (−1,2)，半徑 3 代入 (3,3)：9+9+2(3)−4(3)−4 = 18+6−12−4 = 8 > 0 ⟹ 在圓外
10情境

灑水器覆蓋範圍是圓心 (0,0)、半徑 6 的圓。一條步道方程式是 x=8，步道會被灑到水嗎？

查看解答
直線 x−8=0（a=1,b=0,c=−8） d = |1(0)+0(0)−8|／√(1²+0²) = 8 8 > 6（半徑），相離，步道不會被灑到水
11代數

圓 x²+y²=25 上有一點 (3,4)，求圓在這一點的切線方程式。

查看解答
半徑方向斜率：(4−0)/(3−0) = 4/3 切線斜率：−1÷(4/3) = −3/4 y−4 = −(3/4)(x−3) 4y−16 = −3x+9 切線：3x+4y−25 = 0
12代數

圓 x²+y²=9 外有一點 (0,6)，求從這一點所拉出兩條切線的方程式。

查看解答
設切線 y=mx+6，即 mx−y+6=0 距離 = 半徑：|6|／√(m²+1) = 3 √(m²+1) = 2　⟹　m²=3　⟹　m=±√3 切線：y=√3x+6 與 y=−√3x+6

給筱葳的話

這一章的核心心法是：先把生活中的圖形（坡道、道路、廣場、噴水池）抽象成「幾個關鍵數字」——兩點、一個斜率、一個圓心加半徑，再把幾何問題（陡不陡、平不平行、在不在圓內、切不切過、貼不貼著邊緣）翻譯成代數計算（比較大小、解方程式、算距離）。只要能穩穩做到「幾何 ↔ 代數」的雙向翻譯，這一章的題目大多是同一套方法反覆套用。
