直線與圓

依 108 課綱常見編排先行製作（尚未對照筱葳課本目錄，章節與小節編號可能之後調整）：從無障礙坡道的法規坡度出發，推出斜率與直線方程式；從道路規劃推出兩直線的關係；從灑水器與基地台的涵蓋範圍，推出圓的方程式與圓、直線的位置關係。

這一章把「數與式」學到的代數工具，搬到坐標平面上，用來描述兩種最基本的圖形：直線與圓。生活裡的坡道、道路、灑水範圍、基地台訊號，幾何上其實都是直線或圓，只要抓住幾個關鍵數字（斜率、圓心、半徑），複雜的空間問題就能變成代數計算。

PART 1 ・ 坐標平面與直線的斜率

坡道多陡才合格？

情境

建築法規規定，公共場所的無障礙坡道，坡度不能超過 1/12（也就是每垂直上升 1 公分，水平長度至少要有 12 公分）。工地師傅蓋了一段坡道，起點在地面 (0,0)，終點在 (300,20)（單位：公分）。這段坡道合格嗎？

觀察

要判斷「陡不陡」，關鍵是「垂直上升量」跟「水平前進量」的比值。從 (0,0) 走到 (300,20)：

垂直上升量 Δy = 20 − 0 = 20 水平前進量 Δx = 300 − 0 = 300 坡度 = Δy／Δx = 20／300 = 1／15

因為 1/15 < 1/12（分母越大，坡度越平緩），這段坡道比法規要求更平緩，合格。

規律 → 公式：斜率

把「坡度」這個概念一般化，用坐標平面上任意兩點 A(x₁,y₁)、B(x₂,y₂)（x₁≠x₂）定義斜率：

m = (y₂−y₁) ／ (x₂−x₁)

斜率的正負與大小，直接對應圖形的陡緩與方向：

斜率 m圖形意義
m > 0由左往右上升（越大越陡）
m < 0由左往右下降（絕對值越大越陡）
m = 0水平線
不存在鉛直線（x₁=x₂，垂直地面）

法規講的「1/12」其實就是斜率的絕對值上限：|m|≤1/12。師傅蓋的坡道斜率 m=1/15≈0.067，比上限 1/12≈0.083 小，所以合格；斜率的分母越大（同樣上升高度，水平距離越長），坡道越平緩越安全。

用一用

另一段坡道從 (0,0) 到 (150,15)，合格嗎？

m = (15−0)／(150−0) = 15／150 = 1／10

1/10 > 1/12（分母較小，坡度較陡），超過法規上限，不合格，必須把坡道加長或降低高度。

PART 2 ・ 直線方程式

怎麼寫出整條坡道的路徑？

情境

工地師傅想在圖面上，用一個方程式表示「恰好等於法規上限坡度」的坡道路徑，這樣只要代入任何一個水平位置 x，就能立刻查出這個位置的坡道高度該蓋多高，不用每次都重新畫圖。

觀察

已知坡道起點 (0,0)，斜率 m=1/12。坐標平面上任何一點 (x,y)，只要跟起點連線的斜率也是 1/12，就會落在同一條坡道上：

(y−0)／(x−0) = 1／12　　⟹　　y = x／12

更一般地，如果直線通過已知點 (x₁,y₁)、斜率為 m，同樣的推理給出：

規律 → 公式
點斜式（已知一點與斜率）
y − y₁ = m(x − x₁)

把點斜式展開整理，可以化成兩種常見形式：

斜截式（已知斜率 m 與 y 截距 b）
y = mx + b
一般式（a, b 不同時為 0）
ax + by + c = 0

鉛直線（斜率不存在）沒辦法寫成斜截式，但可以寫成一般式，例如 x=5 就是 1·x+0·y−5=0；這也是一般式比斜截式更「萬用」的原因。

用一用

另一段坡道通過點 (50,10)，斜率為 1/10，求它的方程式，並化成一般式。

點斜式：y−10 = (1/10)(x−50) 展開：y−10 = x/10 − 5 斜截式：y = x/10 + 5 一般式：x − 10y + 50 = 0
PART 3 ・ 兩直線的關係

新路要跟主幹道平行，還是垂直？

情境

都市計畫中，主幹道的方程式是 y=2x+3。現在要規劃一條新的巷道，通過點 (4,1)，並且要跟主幹道垂直（方便設計十字路口）。新巷道的方程式該怎麼寫？

觀察

兩條直線的「平行」與「垂直」，本質上都是斜率之間的關係。想像把主幹道的方向繞原點旋轉 90°：斜率會從 m 變成 −1/m（正負對調、倒數）。可以驗證：主幹道斜率 2，垂直方向的斜率是 −1/2，兩者相乘 2×(−1/2)=−1。

規律 → 公式
兩線平行、垂直的判定（斜率 m₁、m₂ 皆存在時）
平行：m₁ = m₂　　　　垂直：m₁ · m₂ = −1

用這個規律解決一開始的問題：主幹道斜率 m₁=2，垂直的新巷道斜率 m₂=−1/2，再用 PART 2 的點斜式代入通過的點 (4,1)：

y − 1 = −(1/2)(x − 4) y = −x/2 + 2 + 1 新巷道方程式：y = −x/2 + 3
延伸：兩直線的交點

如果兩條路不平行，它們一定會相交在一點——這一點同時滿足兩條直線的方程式，也就是解聯立方程式。求主幹道 y=2x+3 與另一條路 y=−x/2+3 的交點：

2x+3 = −x/2+3 2x + x/2 = 0 (5/2)x = 0　⟹　x = 0，代回 y = 2(0)+3 = 3 交點：(0, 3)
延伸：點到直線的距離

消防法規要求消防栓距離主幹道（中心線）至少 5 公尺。有一個消防栓設在 (10,2)，主幹道方程式是 2x−y+3=0，這個消防栓的位置合格嗎？

點 (x₀,y₀) 到直線 ax+by+c=0 的距離
d = |a·x₀ + b·y₀ + c| ／ √(a²+b²)
d = |2(10) − 2 + 3| ／ √(2²+(−1)²) = |20 − 2 + 3| ／ √5 = 21 ／ √5 ≈ 9.39（公尺）

9.39 > 5，合格。

PART 4 ・ 圓的方程式

灑水器能澆到多遠的花？

情境

公園中央的灑水器裝在坐標原點 (0,0)，出水射程是 8 公尺，只要花圃裡的花距離灑水器不超過 8 公尺，就澆得到水。花圃裡有一朵花種在 (5,6)，澆得到嗎？

觀察

灑水器能澆到的所有位置，就是「跟圓心距離恰好等於（或小於）半徑」的所有點——這正是圓的定義。設圓上任一點 (x,y)，圓心 (0,0)，半徑 8，用兩點間距離公式：

√(x²+y²) = 8　　⟹　　x²+y² = 64

那朵花在 (5,6)，距離灑水器：

√(5²+6²) = √(25+36) = √61 ≈ 7.81（公尺）

7.81 < 8，澆得到。

規律 → 公式

一般化：圓心在 (h,k)、半徑為 r 的圓：

標準式
(x−h)² + (y−k)² = r²

把標準式展開，可以化成另一種常見形式：

(x−h)²+(y−k)² = r² x²−2hx+h² + y²−2ky+k² = r² x²+y² + (−2h)x + (−2k)y + (h²+k²−r²) = 0
一般式（D=−2h，E=−2k，F=h²+k²−r²）
x² + y² + Dx + Ey + F = 0

一般式看起來跟標準式差很多，但只要用配方法「補回」被展開藏起來的 (x−h)²、(y−k)²，就能還原出圓心和半徑。

用一用

某電信基地台訊號涵蓋範圍是圓心 (3,4)、半徑 10 公里的圓。寫出標準式與一般式。

標準式：(x−3)²+(y−4)² = 100 展開：x²−6x+9 + y²−8y+16 = 100 一般式：x²+y²−6x−8y−75 = 0

反過來，已知一般式 x²+y²−6x−8y−75=0，求圓心與半徑。

配方：(x²−6x+9) + (y²−8y+16) = 75+9+16 (x−3)² + (y−4)² = 100 圓心 (3,4)，半徑 √100 = 10
PART 5 ・ 圓與直線的關係

步道會不會切過水池？

情境

公園裡有一座圓形水池，圓心在 (0,0)，半徑 5 公尺。園方想蓋一條筆直的步道，方程式是 x+y=8。這條步道會不會穿過水池？

觀察

關鍵在於比較「圓心到這條直線的距離」跟「半徑」的大小——這正好可以用 PART 3 學過的點到直線距離公式：

直線：x+y−8=0（即 a=1, b=1, c=−8） d = |1(0)+1(0)−8| ／ √(1²+1²) = 8／√2 = 4√2 ≈ 5.66（公尺）

5.66 > 5（半徑），圓心到步道的距離比半徑還遠，步道不會穿過水池。

規律 → 公式

設圓心到直線的距離為 d，圓半徑為 r：

比較位置關係交點數
d > r相離0
d = r相切1
d < r相交2
用一用

如果園方改把步道規劃成 x+y=6，還有 x+y=5√2，這兩條步道分別跟水池是什麼關係？

x+y=6：d = |0+0−6|／√2 = 6/√2 = 3√2 ≈ 4.24 < 5　⟹　相交，會穿過水池 x+y=5√2：d = |0+0−5√2|／√2 = 5√2/√2 = 5 = r　⟹　相切，恰好碰到水池邊緣

相交代表步道會直接穿過水池中央區域，通常設計上會避開；相切則是「剛好貼著池邊」，實務上也常常會再留一點安全距離，不會真的設計成恰好相切。

收進工具箱：直線與圓

上面每一條都已經自己推導過一次，收錄在這裡，需要時隨時查。

直線

用途公式
斜率m = (y₂−y₁)／(x₂−x₁)
點斜式y−y₁ = m(x−x₁)
斜截式y = mx+b
一般式ax+by+c = 0
平行m₁ = m₂
垂直m₁·m₂ = −1
點到直線距離d = |ax₀+by₀+c| ／ √(a²+b²)

圓

用途公式
標準式(x−h)²+(y−k)² = r²（圓心 (h,k)，半徑 r）
一般式x²+y²+Dx+Ey+F = 0
圓與直線關係d>r 相離；d=r 相切；d<r 相交

換你動手做

1情境

某段坡道從 (0,0) 到 (400,30)，是否符合「坡度不超過 1/12」的法規？

查看解答
m = 30/400 = 3/40 = 0.075 1/12 ≈ 0.083，0.075 < 0.083，合格
2代數

求通過 (2,−1)、斜率為 3 的直線方程式（化為一般式）。

查看解答
y−(−1) = 3(x−2) y+1 = 3x−6 一般式：3x−y−7 = 0
3情境

主幹道方程式 y=−2x+5，另一條巷道要與它平行，且通過 (1,1)，求巷道方程式。

查看解答
平行，斜率相同：m=−2 y−1 = −2(x−1) y = −2x+3
4代數

求兩直線 x+y=4 與 x−y=2 的交點。

查看解答
兩式相加：2x=6 ⟹ x=3 代回：3+y=4 ⟹ y=1 交點 (3,1)
5情境

路燈規定要距離道路中心線（3x−4y+1=0）至少 2 公尺，某路燈設於 (1,2)，是否合格？

查看解答
d = |3(1)−4(2)+1| ／ √(3²+4²) = |3−8+1|／5 = 4／5 = 0.8（公尺） 0.8 < 2，不合格，路燈離道路太近
6代數

寫出圓心 (−2,5)、半徑 6 的圓的標準式與一般式。

查看解答
標準式：(x+2)²+(y−5)² = 36 展開：x²+4x+4+y²−10y+25 = 36 一般式：x²+y²+4x−10y−7 = 0
7代數

已知圓 x²+y²+2x−4y−4=0，求圓心與半徑。

查看解答
(x²+2x+1)+(y²−4y+4) = 4+1+4 (x+1)²+(y−2)² = 9 圓心 (−1,2)，半徑 3
8情境

灑水器覆蓋範圍是圓心 (0,0)、半徑 6 的圓。一條步道方程式是 x=8，步道會被灑到水嗎？

查看解答
直線 x−8=0（a=1,b=0,c=−8） d = |1(0)+0(0)−8|／√(1²+0²) = 8 8 > 6（半徑），相離，步道不會被灑到水

給筱葳的話

這一章的核心心法是：先把生活中的圖形（坡道、道路、水池、訊號範圍）抽象成「幾個關鍵數字」——兩點、一個斜率、一個圓心加半徑，再把幾何問題（陡不陡、平不平行、澆不澆得到水、切不切過水池）翻譯成代數計算（比較大小、解方程式、算距離）。只要能穩穩做到「幾何 ↔ 代數」的雙向翻譯，這一章的題目大多是同一套方法反覆套用。
